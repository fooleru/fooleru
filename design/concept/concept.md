## 0. 一句话定位

> 一名退伍特种兵转行的快递员，在百层摩天大楼顶层送货时撞上变异灾变。他要带着刚救下的女人，从 100 层一路杀到 1 层逃出生天——**这是一场「末日搜打撤」：每一层都是程序化生成的死亡迷宫，你搜刮物资、杀出重围、沿楼梯间主通道（或在锚点瓦片自建逃生绳索）一路向下撤，最终退回第 100 层的玩家基地；每一发子弹、每一件战利品、每一口食物饮水，都在决定你能不能活到地面。**

**题材定位（R-26 拍板 · 全作最高约束）**：本作是一部**男频向的英雄救美末世逃生**作品。**主角为男性**（退伍特种兵转行的快递员），**10 名可救援 NPC 全部设定为「性感女性」**，全作主题从头至尾围&#x7ED5;**「英雄救美」**——每一位 NPC 的救援都是一次「美人遇险 → 玩家杀入 → 救出」的桥段；她们既提供情感锚点，也是基地 9 间救援解锁房间（R2–R10）的解锁钥匙（身份即职能，见 §7.3）。角色立绘采用**现代写实插画风**，**独立于游戏内的像素体系**（见 §6.5 与 art-bible 角色立绘规格）。

核心动词：**搜（loot）** ＋ **打（combat）** ＋ **撤（沿楼梯间主通道下行 / 自建逃生绳索 / 回基地）** ＋ **改（build）** ＋ **活（生存：食物饮水 + 基地经营 + NPC）**。

**搜打撤循环定义**：进入一层 → 搜刮容器与房间 → 与变异体/雇佣兵交火 → 沿**楼梯间主通道**（或玩家自建的**逃生绳索**次级通道）撤往下一层（受伤过重也可撤回第 100 层基地修整）→ 把战利品与材料带回归基地经营。第 100 层基地是「撤」的终极安全屋与经营中枢，也是玩家的大本营。**死亡不再是"物品清零"**——携带物留在死亡点尸体中可跑尸取回，惩罚只剩跑图消耗的食水/弹药与时间（D2 式捡尸）。

| 生成          | 程序化楼层（房间+走廊+楼梯间出口）；种子可复现；百层难度递进；生成后按存档永久固化                                                                                                                                                                        |
| **连接 / 基地** | **楼层以楼梯间主通道相连（楼梯间瓦片 = 主换图触发器，走到即切到相邻层；目标层不存在则当场生成）；玩家可在锚点瓦片（地板裂缝/电梯井/破损外墙/管道井）安装逃生绳索，自建通往 `下层同 cell 坐标` 的次级换图触发器（可多处、多脱出口）；第 100 层为玩家基地（安全屋 + 经营中枢），**&#x53EF;建造（R-31：房间建成即完整，无升级）**；基地电梯井（R-25）提供通往任意已探索层的速降传送** |
| **生存**      | **玩家与获救 NPC 的饱食/水分状态；食物饮料消耗与 debuff；断粮惩罚**                                                                                                                                                                        |
| **死亡 / 尸体** | **D2 式捡尸：死亡时携带物留在死亡点尸体中，玩家空手在基地复活，需跑尸取回**。**R-20：一次探索内敌人/物品不回位，回基地再出发时敌人（含精英/Boss）与物品恢复**；**迷雾 / 绳索 / 尸体 / 门锁 / 剧情进度持久**；**惩罚 = 消耗食水弹药 + 时间 + 重新肃清路径**                                                            |
| **NPC**     | **救援获救者；关键物品解锁；好感度；NPC 同样需食物饮水供给**                                                                                                                                                                                |
| 进度          | 单局 roguelite 进度（楼层/资源/build）；基地建造（**⚠ R-32：局外 meta 解锁已整体删除——无任何 meta 解锁树**）                                                                                                                                                                      |

### 1.2 Dynamics（动态层 — 机制在游玩中的涌现行为）

- **节奏张力**：俯视角受限视野 + 像素小尺寸，迫使玩家"探头—交火—翻滚—退掩体"的循环。**后坐力表现为准星漂移**（ZS 式），配合"**静止 + 持续瞄准收敛**"逼出"站定点射 vs 移动泼洒"的清晰决策。**R-19 再叠两层**：**伤害随距离变化**（射程曲线——贴脸霰弹 / 中距步枪 / 远距 DMR 各有归属）+ **敌人双轴感知**（僵尸靠听觉、雇佣兵靠视觉——"安静"与"掩体"是两套不同解法）。
- **搜刮→改造→强化的正反馈环**：清层 → 搜容器 → 拿到附件 → 改造武器 → 下一层更从容。这是 roguelite 的核心成瘾环（见 Aesthetics 的 Expression/Discovery）。
- **玩法翻转（前慢后快）**：前期丧尸慢，玩家用**近距枪械（霰弹）/ 手枪**即可压制（**无近战，R-12**）；后期雇佣兵持枪、利用掩体，迫使玩家转向走位与 peek 枪战，并**按敌人构成换弹种**（对变异体 HP、对雇佣兵 AP）。**R-19 的感知双轴让这个翻转更立体**：上层要"安静地摸"（躲听觉），下层要"切 LOS 地打"（躲视觉）——**同一套系统，两种通关姿势**。
- **资源枯竭压力**：弹药与药品不回填，越往下越"穷"；玩家必须在"贪搜"与"速降"间权衡——直接关联"逃生"主题的紧迫感。**回血只靠"带药"与"回基地睡床"（R-14）**，**R-19 的三轴药品（`hp` / `bleed` / 尸毒）再把它细化为"带哪种药"**——上层带绷带 + 抗毒血清、下层带急救包 + 护甲。"带多少药、带哪种药 = 能推进几层"成为新的撤退决策轴。
- **生存与经营压力（搜打撤的"撤"闭环）**：食物饮水随时间衰减，逼玩家在"贪搜"与"撤回报基地补给/经营"间权衡；基地建筑把单局 loot/材料沉淀为长期能力（维修/加工/扩容/治疗/NPC），形成「外出搜打 → 回基地经营 → 更强再出发」的元循环。
- **纵向规划与跑尸**：垂直骨架带来的贯穿井位（shaft cell）在相邻层严格同 (x,y) 对齐（**生成期坐标契约**，非空间贯通），玩家可据此自建逃生绳索、设计多条纵向脱出路线；死亡改为 D2 式捡尸后，"如何安全取回尸体 + 用绳索规划多条脱出口"成为新的空间规划玩法（见 §7.5 / vertical-traversal / death-and-corpse）。**R-25 补**：若尸体所在层**已探索**，可直接用**基地电梯井速降**该层跑尸（省去逐层换图），见 death-and-corpse §3.3。
- **肃清—重置循环（R-20 新增）**：**一次探索（离开基地 → 返回基地）内，敌人与物资不复位**；**再次出发时，整栋楼重新站岗、物资重新出现**。这制造一条新的节奏轴：**"回基地补给"从免费动作变成有代价的决策**——**撤 = 保住战利品但重开敌情**；**不撤 = 继续深入但风险累积**。同时给出三个体验收益：① **跑尸难度上调**（尸体附近乃至整条路线重新有敌）→ ② **逃生绳索从便利道具升为战略道具**（跨探索保留、可预铺、可跳过敌群）→ ③ **"大厦逃生"体验**（一次探索内从 100 层杀到 1 层 = 肃清一整栋楼）。与 D2"地图固化、怪每次重进刷新"的手感一致。
- **关联涌现**：救援 NPC 后需**满足供给**（→ 好感按 R-29 **每日结算**上升；**⚠ R-42：结算单位 = 游戏日，回到基地时按本趟游戏日数结算**）、经营好感、凑齐关键物品，NPC 才回馈情报/能力——把"带她活下去"变成可玩系统而非纯叙事。

### 1.3 Aesthetics（美学层 — 8 种趣味类型的定位）

依据 LeBlanc 的 8 类 fun，定位本作的主次趣味（★=核心，☆=辅助）：

| 类型                    | 定位 | 在本作的体现                                                          |
| --------------------- | -- | --------------------------------------------------------------- |
| Sensation（感官）         | ★  | 像素打击感、血液粒子、屏幕震动、后坐力镜头反馈；**现代写实立绘的视觉表现力**（R-26）                  |
| Fantasy（幻想）           | ☆  | **男频英雄幻想**：末世孤胆硬汉（退伍兵）逐个救出性感女性、带她们逃生的「英雄救美」叙事（R-26 明确方向）        |
| Narrative（叙事）         | ☆  | 序章救援→层层下行的悬念；**每位 NPC 的「美人遇险 → 玩家杀入 → 救出」桥段作为情感锚，从头至尾贯穿**（R-26） |
| **Challenge（挑战）**     | ★  | 百层难度递进、build 优化、Boss/精英、死亡即结算                                   |
| **Fellowship（社交/关联）** | ★  | 救援 NPC + 好感度 + 关键物品解锁，把"保护他人"做成系统（Relatedness）                  |
| **Discovery（探索）**     | ★  | 程序化地图、隐藏房间、战利品搜刮、楼层主题变化                                         |
| **Expression（表达）**    | ★  | 武器改造与 build 个性化（loot-to-build）+ 基地建造个性化                         |
| Submission（消遣/重复）     | ☆  | roguelite 重复刷取 + meta 成长 + 基地经营，提供"再来一局"                        |

**设计结论**：本作的主 fun 四角是 **Challenge + Discovery + Expression + Fellowship**，由 **Sensation** 提供即时爽感托底，叙事做情感包装。任何机制若不能服务于这五者之一，应砍掉或降级（见范围分层）。

> **⚠ 题材定位优先（R-26）**：**「男频 · 英雄救美」是凌驾于以上趣味配比之上的产品定位约束**——它不新增一个 fun 类型，而是**决定叙事、角色、美术与救援系统的方向**：Fantasy 与 Narrative 虽仍列为☆辅助，但其**具体呈现方式被题材钉死**（男性主角 / 全女性 NPC / 现代写实立绘 / 救援即桥段）。当某设计取舍在"玩法收益"与"题材一致性"之间冲突时，**题材一致性优先于边际玩法收益**，但**不得以牺牲 §P5（手感优先）与 §P2（搜刮即构建）为代价**。

## 2. 项目支柱 Pillars（可量化、可指导决策）

> 支柱不是口号，是"当设计冲突时用来拍板的尺子"。每条都给出可观测指标，便于 lean 节奏下用数据校验。

### P1 — 「百层下行」的紧迫逃生感

- 每一层的下行都应是"空间压迫 + 资源焦虑"的叠加，而非单纯刷怪。
- **量化指标**：单局平均时长 **25–40 分钟**（99 层含大量**快速过境层**，单层有效停留目标 **60–90s**，R-25 由 15–25s 上调——128×86 下单层最短路径已超 20s，原值物理上不可达）；整局死亡率监控（目标：新手首局约 70–85% 死于 40 层前）；"速降 vs 贪搜"路线差异可被数据区分。
  - **R-25 时长预算的达成路径（关键）**：单层变长**不改变**单局总时长，靠的是**基地电梯井直通已探索层**（见 §7.1）——把"重复过境已探索楼层"的时间从 O(层数) 压缩为 O(1)。即：**单层更久、往返更省**，两者抵冲。

### P2 — 搜刮即构建（Loot-to-Build）

- 玩家的强度来自**本局捡到并改造的东西**，而非固定线性成长。掉落是内容，改造是玩法。
- **量化指标**：平均每层产出 ≥ 2 件可用物资（武器/附件/消耗品）；改造附件出现率随层递增；单局可形成 ≥ 3 种可辨识 build 流派。


### P3 — 前慢后快的玩法翻转

- 前期（高层）丧尸肉搏、容错高；后期（低层）雇佣兵枪战、容错低。同一操作产生不同动态，避免 100 层同质化。
- **量化指标**：雇佣兵**成主力**于 ≤ 40 层（豪宅/突变层仅保留 ≥0 极低权重的彩蛋式遭遇，不代表"才登场"）；高层（99–71，豪宅层）应以**敌人贴身近战（丧尸扑咬）+ 玩家近距枪械**为主导交火形态；低层（≤40）应转为**远程枪战 + 掩体 peek** 主导，且**玩家带 AP 弹的比例**随深度上升（数据可观测）。

### P4 — 可重玩的程序化多样性

- 种子驱动、楼层主题递进（豪宅→突变→封锁→底层）；**按存档永久固化**（同一存档世界生成一次后永不变，跨死亡/跨 run 一致）；**垂直骨架（VerticalSkeleton）带来跨层空间结构**——贯穿井位在相邻层严格同 (x,y) cell 对齐，玩家可据此自建绳索、形成可预期的纵向捷径（见 vertical-traversal）。
- **量化指标**：同一存档世界永久固化（同 GlobalSeed 100% 复现，跨死亡/跨 run 一致）；可重玩性来自**开启新存档（新 GlobalSeed）**，不同存档间地图模板重叠率 < 40%；重玩意愿（留存/复开率）作为终极校验。

### P5 — lean 可落地的像素手感

- 在 solo 产能下，先把"射击/翻滚/命中/硬直"的反馈做扎实，再堆内容。**远程手感锚定《ZERO Sievert》**（口径契约见 `reference-alignment-zero-sievert.md`）；**近战整体不做**——正是为了把有限产能全押在"枪打起来对不对"上。
- **量化指标**：核心战斗帧数据可测；手感测试通过率（内部试玩"手感 OK"≥ 80%）；单局峰值实体数下的帧时间达标；**阶段 0 的 5 项 ZS 对齐验证**（投射物手感 / 准星漂移 / 静止收敛 / 弹药稀缺 × 无近战 / 卡壳节奏）全部通过。

### P6 — 「撤」即经营：基地安全网 + 生存 + NPC 关联

- 楼梯间是每一层的**固定主通道**（非"唯一撤点"——玩家另可自建逃生绳索作为次级通道，见 vertical-traversal）；第 100 层基地是「撤」的终点与安全网，把单局 loot/材料沉淀为可经营资产（维修/加工/扩容/治疗/NPC）。
- 生存（食物饮水）与 NPC（好感/关键物品）把"末日"做实，避免纯刷怪；NPC 关联提供情感与功能回报。
- **量化指标**：**起始 1 间（NPC#1 艾拉 + 双人床 + 储藏室）+ 9 间救援解锁房间（R2–R10，各 1 项科技建筑；R10 = 末日之源召唤器）** 可全程解锁；NPC 好感度可达解锁阈值并触发关键物品解锁；断粮 debuff 在数据中可观测；玩家「外出→回基地」循环占比可区分。

### P7 — 「英雄救美」题材主轴（R-26 新增）

- **定位**：本作风格定位为**男频**；**主角为男性**（退伍特种兵转行的快递员）；**10 名可救援 NPC 全部为「性感女性」**；**全作主题从头至尾为「英雄救美」**。这不是包装，是**贯穿全部救援内容的结构**——**每一位 NPC 的救援都是一次独立的「美人遇险 → 玩家杀入 → 救出」桥段**，且**角色的立绘（现代写实风）承担"美"与"情感回报"的表达职能**（立绘独立于游戏内像素体系，见 §6.5）。
- **与既有支柱的关系**：P7 **不新增玩法系统**，而是给 **P6（救援/经营）** 与 **§1.2 关联涌现** 提供**统一的叙事与视觉皮**；**保住经营（供给/好感/关键物品）与搜打撤核心循环（P1/P2/P5）不得因题材而让位**。
- **量化指标**：10 名 NPC 各有 1 套**独立立绘**（≥1 张主立绘 + 情绪差分）与 1 段**救援桥段脚本**；每位 NPC 的救援场景在设计上须可被描述为"她遇险 → 玩家介入 → 她获救"；**内容分级边界可核验**（性感但不越线，见 art-bible 立绘规格的可访问性/分级条款）。
- **⚠ 边界**：① **不引入恋爱线/分支结局等额外系统**（B 档待定，不进 T/M）；② **立绘只用于 UI 场景**（对话/图鉴/结算/救援演出/房间卡片），**游戏内世界物件与竞技场角色仍为像素风**，不得混用；③ **表现力预算优先级不高于 P5**——手感未达标前不为立绘额外扩产。

> 冲突裁决示例：若"加更多基地建筑（P6）"会拖慢"先把基础手感做扎实（P5）"，则 P5 优先，基地建筑进 M 档。

### 3.3 MVP 垂直切片建议（验证驱动）

> 原则：**先想清楚怎么测，再写机制。** 用最小可玩切片验证"手感 + build 环 + 生成多样性 + 搜打撤闭环"四件大事，再扩量。

**阶段 0 — 手感原型（不依赖生成）**

- 固定 1 张测试房：验证移动/瞄准/**ADS**/射击/**准星漂移**/翻滚/命中/硬直/**换弹**/**卡壳排障**手感。
- **必须同时跑 ZERO Sievert 对齐的 5 项验证**（见 `reference-alignment-zero-sievert.md §6`）：①投射物 vs hitscan 手感 ②准星漂移是否比固定散布更有"可控感" ③静止收敛是否形成策略分层 ④弹药稀缺 × 无近战是否过苛 ⑤卡壳节奏是否"有压力但不烦躁"。
- 验收：内部试玩手感通过率 ≥ 80%；上述 5 项全部有结论（通过 / 回退 / 调参）。

**阶段 1 — 前 10 层垂直切片（核心循环闭环）**

- 程序化生成仅 **9 层（楼层 99→91）**，加静态基地 100 层共 10 层切片；含僵尸 + 基础怪物；掉落 + 改造 + 背包可用；楼梯间下行生效；死亡结算（捡尸跑尸）+ 最简 meta（解锁 1 项）。
- **基地雏形 = 起始房间（双人床 + 储藏室 + NPC#1 艾拉）**；本阶段为尽早验证"基地经营手感"而放的**工作台/储藏室为临时占位（非正式解锁路径，正式版由救援解锁）**。
- 注：本阶段仅生成到第 91 层，**不含 90 层 Boss 及其正式救援路径**，故不会正式解锁工作台（工作台的正式来源见阶段 3 与 base-survival-npc §B.3.2）。
- 验收：单局可完整跑通"生成→战斗→搜刮→改造→沿楼梯间下行→死亡/通关切片"；build 环可感知；生成无死路。

**阶段 2 — 引入生存 + 基地雏形**

- 加入食物/饮水状态（玩家）；基地可&#x7528;**（临时占位的）**&#x5DE5;作台（修理/升级）+ 起始房间**储藏室**（扩容）；楼梯间作为**双向**回基地撤点生效；材料掉落入池。
- **临时占位建筑（同阶段 1）仅用于验证经营 UI/手感，非正式解锁路径**；正式版工作台/发电机/厨房等由救援 NPC#2–#10 解锁（base-survival-npc §B.3.2）。
- 验收：断粮 debuff 生效；回基地维修/扩容可用；搜打撤"撤"闭环成立。

**阶段 3 — 扩量到 25 → 50 → 100 层 + 补全系统**

- 逐段加入怪物层（雇佣兵 ≤40 层）、精英/Boss、隐藏房间。（**⚠ R-32：原列的「meta 解锁树」已整体删除**）
- **补全 9 间救援解锁房间（R2–R10）的映射与内容**：R2 工作室（工作台）、R3 厨房（炉灶）、R4 医疗室（实验台）、R5 电力间（发电机）、R6 通讯室（电台，=空投站功能）、R7 温室（室内培育装置）、R8 训练场（健身器材）、R9 研究室（电脑）、R10 末日之源召唤器（召唤器装置）各占一间（随救援 NPC#2–#10 解锁，见 base-survival-npc §B.3.2；**R-21：原「拓展宿舍」已改为空投站功能；R-27：房间顺序重排、军械库删除、弹药生产并入工作室**）；并补艾拉好感/关键物品解锁。
- 每扩一段跑一轮平衡与性能校验（见各 GDD 验收标准）。

## 4. 玩家心理应用（心流 + 自我决定论）

### 4.1 心流（Flow）— 难度曲线设计

- **挑战—技能平衡**（区段与 §6 / procedural-gen §3.2 一致；第 100 层基地单列，不计入战斗区段）：
  - 高层「豪宅层」（99–71）：丧尸慢、密度低 → 低威胁，让新手进入心流、学会翻滚与控枪。
  - 中层「突变层」（70–41）：怪物提速、密度升 → 中威胁，引入硬直管理与走位。
  - 封锁层（40–11）：雇佣兵远程 + 掩体 → 高威胁，逼出"peek—反击—翻滚脱困"的高技巧循环。
  - 底层（10–1）：混合精锐 + 终局压迫 → 最高威胁。
- **透明反馈**：每次命中、硬直、击杀都有即时可感反馈（粒子/音效/数字），维持"我在变强/在掌控"的流体验。
- **防焦虑断层**：用难度预算公式（见 procedural-gen）平滑每层增量，避免相邻层难度跳变打断心流。

#### 4.1.1 难度三段曲线（R-23 用户拍板 · 玩家侧 × 敌人侧对照）

> **设计原则**：难度上升由**玩家侧成长**与**敌人侧进化\*\*\*\*双向驱动**。三段各有明确的"技能要求"与"敌人形态"，**每一段是一种不同的玩法**，而非同一玩法的数值堆叠。

| 段位     | 楼层        | 玩家侧状态                     | 敌人侧形态                                                            | 玩家需掌握的核心技能                                      |
| ------ | --------- | ------------------------- | ---------------------------------------------------------------- | ----------------------------------------------- |
| **初期** | **99–71** | 武器攻击弱 · 血条短 · 操作不熟练       | **近战为主**：僵尸**慢 / 血厚 / 攻击高 / 数量少**（R-23 重定位）；无远程兵种                | **瞄准 · 走位 · 绕后**——靠单挑技术与空间感取胜                   |
| **中期** | **70–41** | 装备成型中 · 开始有护甲与弹种选择        | 近战**数量↑ 速度↑**；**新增远程兵种**（吐酸者 Spitter 等）                          | **地形利用 · 拉扯微操**——用掩体切断 LOS、分批拉怪                 |
| **后期** | **40–1**  | 需要更好装备（AP 弹 / 高 class 护甲） | 近战**数值↑**；**大量远程人类**（雇佣兵）**+ 机械敌人**（10–1）；**装备高等级护甲（class 4–6）** | **反应速度 · 战术能力 · 装备配置**——peek 枪战 + 换弹种破甲 + 抢背身窗口 |

- **三段转折的"手感差异"（设计检验点）**：
  - 初期的紧张来自"**打不死**"（血厚 + 数量少 → 单只缠斗时间长，但不能被包围）；
  - 中期的紧张来自"**被拉扯**"（远程 + 近战协同 → 不能站桩输出）；
  - 后期的紧张来自"**打不穿**"（护甲阈值 → 弹种不对就几乎无输出）。
- **⚠ 与 R-22「以死为师」的一致性**：本曲线**不设教学关卡**，玩家通过死亡自学上述技能。因此**每段的技能要求必须"失败可归因"**——例如后期打不穿护甲时，HUD 须给出明确反馈（**如"弹开"的视觉/音效 + 护甲等级提示**），**让玩家知道"我该换弹种"而不是"我枪法不行"**。见 ux-spec §3。
- **⚠ 玩家侧的"血条短"（初期）需界定**：初期玩家 HP 上限低 + 无护甲，而僵尸单只伤害已上调至 15–18 → **两层打击下即濒死**。**护栏**：保证初期存在**明确的脱战手段**（楼梯间回撤 / 翻滚 iFrame / 拉开距离），使"打不过能跑"始终成立（呼应 P6 撤）。**不得**让初期出现"被 2–3 只僵尸围住必然死亡"的局面——这与"数量少"的设计意图矛盾。
- **⚠ 曲线数值全部为 ⚠待调**：本表描述**形态与方向**，具体数值（HP/伤害/密度/护甲阈值）须阶段 0 原型实测标定。**当前所有敌人强度参数尚未实测**，现在修订成本最低。

## 5. 叙事与世界观

### 5.1 世界观 baseline

- **时代**：近未来都市，资本与生物技术高度集中。
- **灾变**：亿万富翁私宅爆发"变异"事件——初期表现为住户/佣人的僵尸化（生物污染），后期出现持现代武器的雇佣兵，暗示**军方/私人安保已介入封锁大楼**（玩法翻转的叙事支点）。
- **灾变真源「末日之源」**：来自**地底的恶魔**。富翁的生物科技实验意外凿穿了地底封印，灾变由此泄漏至大楼；终局揭示一切变异与封锁皆为掩盖此源头。**（⚠ R-39 补注 · 研究链条的源头）**：**那套"能凿穿封印的技术"并非富翁原创**——**它源自一位导师（Key Figure）在「军方生物防御项目」时期的秘密研究，后被富翁资助 / 收编进私人实验室**。**导师是"释放者"而非"制造者"**（**末日之源本身仍是地底恶魔，此设定不改**）；**他的两名学生——林晞（NPC#9，选了退出、被其灭口未遂）与伊芙琳（NPC#10，选了留下、后亲手杀死被感染的导师）——是终局拼出这块真相的两块关键拼图**。详见 `design/concept/npc-characters.md §12.5`。
- **主题**：在资本巨兽的遗骸里，一个最普通的"送货人"成了真正的幸存者。逃逸即反抗。**R-26 定调**：本作是一部**男频向英雄救美**作品——**男性英雄（玩家）在末世绝境中逐个救出被困的性感女性，带她们逃出生天**；"逃逸即反抗"由此具体化&#x4E3A;**"救出她们、把她们带回家"**。

### 5.2 序章关卡设计（落地开场剧情）

> 序章即"教学 + 叙事钩子"，建议作为固定（非程序化）的楼层 100 剧本关，并自然过渡到基地。
>
> **叙事说明（P2-14）**：序章发生地（富翁豪宅）与玩家基地**同为第 100 层**——这是刻意设定：灾变正是从这一层爆发，玩家逃生途中撤至此层后将其改造成安全屋。**"灾变发生地 = 基地同层"** 既解释序章与基地的空间连续，也让"回到起点"具备叙事重量（同一空间"灾变现场 → 安全屋"的视觉过渡由 art-bible 基地主题处理）。

**节拍（Beat）设计：**

1. **送达**：玩家（男性主角·快递员）乘电梯到 100 层，走到豪宅门前按铃，HUD 提示"送货任务"。
2. **开门**：门开，**性感妖娆的女子**探身签收，气氛暧昧轻松（建立角色与反差，**她即全作第一位"待救美人"**）。
3. **异变**：女子签收时，屋内传来非人嘶吼；她脸色骤变，夹杂恐怖情绪的呼救。
4. **抉择/冲入**：玩家可自由移动靠近；靠近门口触发"冲入房间"脚本（教学：移动+交互）。
5. **救援（首个"英雄救美"桥段）**：房间内富翁已变异，扑向女子；**玩家（男性英雄）**&#x62D4;出随身**老旧手枪**射击将其击退（教学：**首次射击 / ADS 与换弹**）。救下女子即完成**首位 NPC 救援**（接入 NPC 系统），并**立下全作"英雄救美"的桥段范式**——后续 9 名 NPC 依次复现该结构。
6. **爆发**：救下女子瞬间，整栋楼警报与变异扩散——灾变开始；女子随玩家撤入**第 100 层基地**（安全屋）。
7. **下行起点**：电梯失效，**楼梯间**成为唯一下行主通道（玩家后续可在锚点瓦片自建逃生绳索作为次级通道）；镜头下摇，"沿楼梯间从 100 层杀到 1 层"目标确立，进入程序化循环；基地作为可返回的「撤」安全网（**楼梯间为双向连接**，可上行回撤，回撤代价见 §7.1）。

**教学映射（R-22 修订：教学内容全部收敛在序章，楼层 99 起不承担教学）**：序章顺带教"移动→交互→**射击（含 ADS / 换弹）**→首次救援→目标确立→回基地"，零额外 UI 负担。

> **教学边界（R-22 用户拍板）**：**楼层 99–1 不设任何强制教学 / 引导步骤**。序章（第 100 层）已覆盖**全部基础操作**（移动、交互、射击、救援、回基地）；此后玩家**通过死亡与跑尸自行学习**中后期机制（绳索安装、撤退时机、库存管理、精英/Boss 打法、现金买卖、深层压力）。**设计理由**：本作核心张力来自"搜打撤"的**风险自担**——用强制教程把"什么时候该撤"讲明白，等于**替玩家做了那个决定**，会削弱 P6（撤）与 P1（逃生）的体验；**以死为师**（死亡代价 = 消耗食水弹药 + 时间 + 重新肃清）本身就是学习回路。**交付约束**：① 楼层 99–1 **不得插入模态教程弹窗 / 强制高亮引导 / 锁操作步骤**；② 允许**非阻塞式**提示（如锚点附近的 `[E] 安装绳索` 上下文键提示、HUD 常驻键位提示）——**提示"能做什么"，不教"该做什么"**；③ 绳索、现金、空投站等新机制的"首次接触"允许一次性的**轻量字幕**（可跳过、不中断游戏），但**不得阻断操作或强制等待**。

### 5.3 核心角色设定（背景 / 动机 / 玩法意义）

> **R-26 题材约束（适用本节全部角色）**：本作定位**男频**——**主角为男性**，**10 名可救援 NPC 全部为「性感女性」**，**全作主题为「英雄救美」**。以下每位 NPC 的设定均须符合该方向；**其职业身份（决定解锁哪间房）刚性不变**（见 §7.3 / base-survival-npc §B.3.2）。**角色立绘采用现代写实风**（见 §6.5）。
>
> **⚠ R-38 新增 · 人物简介与性格设定落点**：10 名 NPC 的**完整人物简介 / 性格设定 / 说话方式 / 与主角关系基调 / 剧情钩子 / 群像关系网 / R-37 挽救剧情台词**，见 **`design/concept/npc-characters.md`（R-38）**。**权威分工**：该文档 = **叙事设定权威处**；**`base-survival-npc.md §C.9` = 机制侧名录**（姓名 / 房间 / 职业 / `AffinityInit` 数值 / 赠礼归属）。**二者冲突时——机制数值以 §C.9 为准、性格叙事以 `npc-characters.md` 为准。** 本节以下内容为**顶层概念**（角色定位与玩法意义），**具体人物刻画以该文档为准**。

#### 角色一：快递员（玩家主角 · **男性**）

- **性别**：**男性**（R-26 明确）。退伍特种兵出身，体格健壮、沉默寡言，是「英雄救美」叙事中的**英雄位置**——**玩家即英雄，代入对象固定为男性硬汉**。**⚠ R-34：主角个性刻意弱化（参照 ZS 的沉默 / 无面主角）——不做可解锁 / 可切换角色（「角色解锁 B 档」已删除，见 progression §3.2），玩家代入的是"一个幸存者"而非有成长弧光的主角**；与 R-30「无玩家数值成长」同向。
- **背景**：前特种部队成员，因战后创伤/现实压力转行做高端快递。体力与枪感仍在线，但"civilian 身份"让他初始装备寒酸（**仅一支老旧手枪 + 少量弹药**）。
- **动机**：本能救人 → 求生 → "带她下去"。
- **玩法意义**：**全能但不满载**的起点。基础属性均衡；强度完全靠本局 loot/build 补齐（呼应 P2）。是玩家代入的"空白画布"。同时是基地经营者（建造中枢的操作者〔⚠ R-31：已无建筑升级；⚠ R-32：meta 解锁树亦已删除，建造仅耗材料〕）。

#### 角色二：妖娆女子（艾拉 / 暂定名）— NPC#1 / 共 10 名 NPC（**全女性**）

- **性别**：**女**（R-26）。
- **背景**：富翁的情妇/被软禁者，表面光鲜实则人质；灾变前正欲逃离。**性感、妖娆，是"美"的第一张脸**——她的立绘是全作视觉定位的样板。
- **动机**：求救 → 求生 → 可能藏有灾变线索（她知道富翁在做什么）。
- **救援桥段（R-26 · 全 10 名 NPC 的统一结构）**：**美人遇险 → 玩家杀入 → 救出**。以她为例：她在门口签收时屋内异变爆发、被变异富翁扑向 → 玩家拔枪冲入击退 → 救出后随玩家撤入基地。**其余 9 名 NPC 各有一段同结构的独立桥段**（见 §7.4）。
- **玩法意义（NPC 系统落地）**：
  - 序章被救后入住基地**起始 NPC房间**（双人床+储藏室），成为首位可经营 NPC；为基地初始房间入住者。
  - 另 9 名 NPC（#2–#10）**均为女性**，其出现/救援条件**待定**（后续按开发进度、难度、剧情设置；**击败 Boss 只是其中一种触发方式**），每位解锁 1 间救援解锁房间（R2–R10）；其中**最终 NPC（军方女科学家 · NPC#10 伊芙琳·斯特恩）**&#x4E3A;终局关键（见角色四）。
  - 需玩家持续供给**食物/饮水**（见生存系统，消耗随 NPC 人数上升），否则好感下降、功能失效。
  - **好感度（R-29 双通道）**：救援获得时 = **60%**；**回到基地时按本趟游戏日数结算**（满足 +1%/天、饥渴 −2%/天；**⚠ R-42 已改：原「每局回基地结算」**）+ **专属赠礼首次交付 +10%（一次性）**（**⚠ R-32：赠礼非全世界唯一、仅"稀少"可重复获得；游戏内不提示该送给谁；送错人不加好感且物品消耗掉**）；好感经 `EffectMult`（60% → ×1.0 基准）驱动其对应房间效率；达 80% **表白（一次性）**、100% **亲密举动（一次性）**、跌破 40%/20%/0% **哭泣/抑郁/崩溃（可重复）**〔以上 = **轴 A 情绪/关系事件**〕；另有**轴 B 能力/剧情解锁**（与轴 A **共用 0–100 刻度但语义不同、并列触发**）：达到阈值 + 交付**关键物品**（如富翁实验室密钥）解锁其能力/叙事（如提供情报、小额 buff、真相支线）——**同一刻度可同时命中两轴**（艾拉 80% 处「表白」与「进阶解锁」并列，属有意设计；见 base-survival-npc §C.4 / ux-spec §3.5）。
  - 她是"关联(Relatedness)"的可玩载体，把情感动机转为系统回报（见 base-survival-npc §C）。


#### 角色三：变异富翁（灾变源头 / 序章 Boss 原型 · **男性**）

- **性别**：男。**他是"英雄救美"桥段中的反派位置**——正是他把女性角色置于险境（软禁艾拉、变异后扑向她），玩家击退他 = 完成首次英雄救美。
- **背景**：掌控生物科技财阀的顶层权贵，自认为能"驾驭进化"，却在自家豪宅成为首个完全变异体。
- **动机**：失控的变异本能（序章）；作为"灾难起点"的象征。
- **玩法意义**：
  - 序章的**首个敌人/弱 Boss**，教学**首次射击**（R-12：原"教学近战击退"已改为射击，玩家侧无近战）。
  - 叙事上确立"灾变源于资本妄为"的基调；其遗留的**关键物品（实验室密钥/图纸）**&#x53EF;成为艾拉解锁与基地高级升级的触发器〔⚠ R-31：建筑升级已取消，该"高级"内容现走「R9 研究室解析关键物品」渠道〕。
  - 设计上可作为后期 Boss 机制的雏形（阶段切换：人形→变异态），详见 enemies-ai 的 Boss 建议。

#### 角色四：幸存的军方女科学家 **伊芙琳·斯特恩 Evelyn Stern** — NPC#10 / 房间 R10（末日之源召唤器）（**女性**）

- **性别**：**女**（R-26 定为女性，纳入"10 名 NPC 全为女性"口径）。**定位为"才貌兼备的知性御姐"**——与其余 NPC 的"性感"气质形成层次差异（不是所有女性角色同一种味道）。
- **背景**：军方生物防御项目的幸存研究员，困于大楼底层；深知"末日之源"的真相与封印法，也是雇佣兵封锁行动的知情人。**（⚠ R-39 补注 · 同门师姐妹）**：**她是林晞（NPC#9）的同门师姐**——两人**同出师门**；当林晞发现导师秘密研究危害人类的科技、选择退出、并因此被导师灭口（未遂）时，**她选择了留下、继续参与研究**；**直到导师被自己的研究产物感染，她不得不亲手杀死导师——那一刻她才明白：她留下就等于共犯，而清算是她自己的手**；**此后她一直在努力挽回**（把导师留下的东西做一次"了结"）。她的"罪"由此改写为**双重身份：「她选择留下 = 共犯」+「她亲手结束导师 = 清算者」**。详见 `design/concept/npc-characters.md §11 / §12.5`。

- **救援桥段**：**她是全作最后一位被救者**——玩家在 1 层击败第 10 个楼内 Boss 后杀入，救出她；**这是"英雄救美"主轴的收束**（救出最后的美人 = 拿到终局的钥匙）。
- **玩法意义**：为 10 名 NPC 之一（**最终 NPC = NPC#10**）；出现/救援条件待定（**建议**由击败 1 层 Boss 触发）；解锁**正式房间 R10「末日之源召唤器」**&#x53CA;其**召唤器装置**，是终局战的钥匙；其关键物品/情报解锁真相支线。

## 6. 视觉锚点（供美术成员 art-director 参考）

> 以下为策划视角的美术需求摘要，最终以 art-bible 为准（已对齐 tile = 16 px、正俯相机 + 可读 3/4 精灵）。

- **风格**：2D 像素风，参考《ZERO Sievert》的 16 px 角色、俯视角等距感（正俯相机 + 可读精灵）。
- **视角构图**：正俯视角，单位尺寸小（tile = 16 px），镜头略拉近以维持"压迫感"；鼓励"门缝/拐角探头"的构图。
- **氛围关键词**：`潮湿锈蚀` `霓虹残光` `血迹斑驳` `末世衰败` `垂直纵深` `冷调恐怖` `富贵废墟`（顶层奢华 vs 底层破败的对比贯穿百层）。
- **分层主题（供程序化生成配色/瓦片）**：
  - 楼层 99–71「豪宅层」：金、大理石、暖残光 → 突变血污侵入。
  - 楼层 70–41「突变层」：生物组织、黏液、破败。
  - 楼层 40–11「封锁层」：军用、混凝土、警示标识、弹孔。
  - 楼层 10–1「底层」：地下车库/机房、黑暗、终局压迫。
- **基地（第 100 层）视觉**：安全屋、暖光、整齐，与下层冷恐形成强烈反差；是玩家每次「撤」回来的心理锚点。基地初始仅 R1 起始房间为**已建成**态（艾拉 + 双人床 + 储藏室）；另有 9 间房间（R2–R10）按「救援 → 结束该局回基地解锁 → NPC 告知材料 → 集材建造」四步推进——视觉上以**三态**区分进度：`态 0 未解锁`（黑暗/上锁）→ `态 1 已解锁·空房`（NPC 在场、房内装置未建）→ `态 2 已建成`（装置就位、功能生效；**R-31：态 2 即完整状态，无 Lv / 无升级**）。三态视觉规范详见 `art-bible.md` §3.4.1（A-20），机制口径详见 `base-survival-npc` §B.3.2。
- **楼梯间**：连接各层的**主通道**下行节点，需高可读标识（逃生箭头/绿灯），在像素尺度下必须一眼可辨（不再表述为"唯一撤点"）。
- **逃生绳索锚点瓦片**（地板裂缝/电梯井/破损外墙/管道井）：玩家可安装绳索自建次级通道，需与楼梯间主通道可读地区分（见 vertical-traversal）。
- **可读性优先**：敌人轮廓、玩家准星、可交互容器、楼梯间出口必须在像素尺度下高可读（影响战斗可读性，属 P5 硬指标）。

### 6.5 角色立绘规格（R-26 新增 · 独立于像素体系）

> **⚠ 核心口径**：**立绘不是像素资产，是高清现代写实插画**。二者**并存但不混用**——这是本作唯一一处"跨画风共存"的设计，须有明确边界，规范详见 `art-bible.md` 角色立绘规格章节。

- **画风**：**现代写实插画**（写实人体比例、写实光影与材质；非日系、非像素、非美式卡通）。**主角为男性硬汉**；**10 名 NPC 全部为性感女性**，各自气质分层（妖娆 / 知性 / 干练 / 冷艳 …），避免同质化。
- **使用场景（封闭白名单，只在这五类 UI 出现）**：
  1. **对话场景**（NPC 交谈/好感事件）；
  2. **NPC 图鉴**（已救援名录 + 未救援剪影）；
  3. **结算画面**（救援成功/死亡/通关）；
  4. **救援演出**（"美人遇险 → 玩家杀入 → 救出"桥段的立绘插入）；
  5. **房间卡片头像**（ux-spec §3.5 基地建筑卡片内的 NPC 头像）。
- **⚠ 禁止使用场景**：**游戏内世界一切物件与角色**（玩家角色、NPC 在场实体、敌人、场景）**一律保持像素风**（tile = 16 px、内部分辨率 320×180）；**不得**把写实立绘贴进竞技场/楼层世界。
- **视觉调和规则**：立绘所在 UI 面板须以**像素风的 UI 框架 + 写实立绘**共存——面板边框/图标/字体走 art-bible §7 的像素 UI 规范，立绘以独立图层嵌入，**不缩放像素 UI 元素来迁就立绘分辨率**。
- **内容分级边界**：**性感但不越线**——着装与姿态须通过 Steam 分级与主要平台的内容审核（不做裸露/性暗示越界内容）；具体红线与可访问性条款见 art-bible 立绘规格章节。
- **产能提示（对齐 P5）**：立绘属**表现力预算**，**优先级不高于核心手感**（§P5）；数量按阶段推进（阶段 0/1 仅需艾拉 1 张打样，验证画风与 UI 共存效果）。

## 7. 基地·生存·NPC 系统概述（详见 base-survival-npc.md）

> 这三套系统把"末日搜打撤"做实，是 v0.2 相对 v0.1 的核心增量。以下为概念层概述，机制/数值/验收见 `design/gdd/base-survival-npc.md`。

### 7.1 楼层结构与连接

- **第 100 层 = 玩家基地**：静态安全屋（序章后即开放；**序章豪宅即本层**，见 §5.2），是「撤」的终点与经营中枢，**可建造（R-31：房间建成即完整状态，无升级）**。
- **楼层 99–1 = 程序化生成区**：按规则（种子 + 楼层区段 + 难度公式）生成；**按存档永久固化**（同一存档世界生成一次后永不变，跨死亡/跨 run 均复用同一布局，不再重新随机）。可重玩性来自开新存档。
- **楼梯间（主通道）**：每一层**固定的主连接节点，且为双向连接**——既可下探下一层（未探索），也可**上行回撤**至已探索的上一层，乃至逐步撤回第 100 层基地。是搜打撤的"主撤点"。**R-20 注**：楼梯间是**会被"复活敌群"重新堵住的那个通道**——这正是绳索价值上升的原因（见下条）。
  - **回撤代价（P2-02 立 · R-20 显著加重）**：① **探索内**上下移动**不重置敌人、不回补库存**；② **但一旦撤回基地，下次出发敌情与物资全部重置**（③ 层复位）——**这是回撤最大的代价**：补给必须回基地，而回基地就意味着**重新肃清**；③ 游戏内时间**在楼层内按现实比例推进**（**⚠ R-42：基地内时间静止**），故探索期间基地 NPC 的食物/饮水消耗随楼层时间流逝（见 §7.2 / base-survival-npc §A / **§0**）。因此"跑回基地补给"**不是免费**——且 R-20 后它变成一条**明确的取舍**：**保住战利品 vs 保持已清地形**。生存张力（P6）与「撤即经营」由此被显著强化。
- **垂直通道 / 逃生绳索（次级通道 · R-20 升为战略道具）**：玩家可在**锚点瓦片**（`floor_crack` 地板裂缝 / `elevator_shaft` 电梯井 / `exterior_breach` 破损外墙·窗 / `utility_shaft` 管道井）上**安装逃生绳索**，形成通往**下层同 (x,y) cell** 的通道。绳索**双向**可攀爬（**上行 −50% 速度**，保全主通道价值）；可**多处安装** → 多个脱出口。已安装绳索属 **② 存档级持久层**、跨死亡/**跨探索**永久保留，**为永久标记**（**⚠ R-45 已改（原：R-44「载体 automap 已随本批移除 → 承载方式 ⚠ 待用户拍板」）**：**承载方式【落定 = `M` 键「地图界面」】**——**"永久标记、仅坐标不透视"的设计意图保留**；**跨层查看 = 在地图界面点选左侧楼层按钮，只列已探索层**）。风险回报：落点可能通往下层安全区，也可能直落敌群/Boss（由生成器决定）。**R-20 价值跃升**：由于敌人**随探索复活**而绳索**跨探索保留**，绳索成为**唯一能"跳过楼层、绕过复活敌群"的手段**——它是① **跑尸的首选路线**（避开复活路径，直取尸体）、② **可预铺的长期基础设施**（多次探索复用）、③ **深潜捷径**。详见 `vertical-traversal.md` §3.6/§3.8。
- **基地电梯井枢纽（R-25 新增 · D2 小站式"换图传送" · ⚠ 不是"垂直交通"）**：**第 100 层基地的电梯井**在满足条件后成为**传送控制台**，提供通往**任意已探索楼层**的**速降**。**⚠ 定位（R-25 二次拍板，务必理解）**：电梯井**不属于"垂直交通系统"**——它是 **D2 小站式的地图流转切换器**（读档点 → 读档点），与"玩家在楼层内如何垂直移动"无关。**本作是单层常驻载入**（同时刻只有当前一层；楼梯间瓦片 = 换图触发器，目标层不存在则当场生成），故**楼梯间、绳索、电梯井三者都是"换图触发器"，都不是"空间通道"**。**解锁三要素**：① 已制作出逃生绳索（`RopeCrafted`）→ ② 在基地电梯井**安装绳索**开启井道（消耗 `RopeCable ×1`，一次性、存档级永久）→ ③ 目标楼层已探索（`floor ∈ ExploredFloors`，口径 = **玩家抵达过该层电梯井锚点**）。**⚠ 能力非对称（R-25 关键）**：**基地端**可**指定目的层速降**；**99 及以下楼层的电梯井只能脱出（返回基地），不能选择目的地、不能跳到其他楼层**。**流程**：玩家经楼梯间下探新楼层 → 探索该层（抵达其电梯井）→ 回基地 → 该层自动解锁 → 之后可从基地**速降**该层 → 并可在**该层电梯井直接返回基地、结束当前一局**（**⚠ R-25 三次：返回不再瞬发，须坚守等候 `(100 − floor) × 1.0 s`，见 §7.1 倒计时段**）。**未探索楼层仍可选择前往**，但提示「该楼层未经探索，贸然前往太过危险！」（**非阻塞警告**，遵守 R-22「以死为师」边界）。**设计目的**：解决"重复探索高楼层"的时长问题（把**换图次数**从 O(层数) 压缩为 O(1)），服务 §P1 单局 25–40 分钟。**✅ 风险已消解（R-25 二次拍板）**：因**楼层端不能选目的地**，"清一层 → 回家 → 直接下来继续"的循环**不成立**——"下来"必须从基地出发，而**离开基地即触发敌情重置**，R-20 的「回基地 = 重开敌情」取舍**完整保留**（详见 `vertical-traversal.md` §3.9.7）。详见 `vertical-traversal.md` §3.9 / §3.10。
- **⚠ 脱出不是"紧急按钮"（R-25 三次新增 · 倒计时）**：楼层端脱出**不是瞬发**——玩家须在**电梯井锚点邻域坚守 `(100 − floor) × 1.0 s`**（99层=1s、50层=50s、**1层=99s**），期间**可被攻击、可开火、必须自卫**，**一旦离开锚域则取消**（vertical-traversal §3.9.5）。HUD 以**递减米数**呈现：「（NPC某某）正在降下逃生绳，还剩 XX 米到达。」——**给玩家"回家的路正在被铺出来"的期待感**，而不是干等。**设计含义**：**"撤"的最后一段被做成一场小型防御战**——你可以随时开始脱出，但你必须**活着等到绳子放完**；**越深等越久**，与 R-23「越深越难」同向。**⚠ 终局广场战（末日之源）没有脱出口**——那是全作唯一"必战"地图。见 `vertical-traversal.md` §3.9.5。
- **终局路径**：楼层 1 有第 10 个楼内 Boss（Boss 仅为 NPC 出现条件之一，见 base-survival-npc §C.3）；击败 → 救出**军方女科学家 伊芙琳·斯特恩（NPC#10）** → 基地解锁**正式房间 R10「末日之源召唤器」**（R-27 由"最终建筑"升级为正式房间）→ 召唤**末日之源**至**楼外广场**（最大地图）进行终局战。

### 7.2 生存系统（Survival）

- 玩家与获救 NPC 各有**饱食度 / 水分**两条状态（0–100），随时间与行动衰减。
- **负重（R-46 新增 · 玩家第三条量）**：玩家维护 `CurrentLoad`（= Σ 物品 `weight` × 数量；统计范围 = **背包格 + 装备栏**；储藏室 / 暂存槽不计）与 `CarryCapacity`（负重上限，**固定常数**，默认 **40 wg ⚠待调**）；**超重两档惩罚**——**轻度**（`1.0 < r ≤ 1.2`）**移速 −15%** / **重度**（`r > 1.2`）**移速 −30% + 禁冲刺 + 体力自然恢复 ×0.5**（**保留翻滚**），**只影响移动维度、仅楼层内生效、基地内豁免**。**与「背包格（20 格）」为两套独立限制、同时生效**（"装得下"与"背得动"分别判定）。**冲刺（Sprint）持续消耗 `Stamina`**（R-46 补齐）。**权威见 `base-survival-npc §A.3.1`；物品重量见 `weapons-loot §3.15`；冲刺耗体力 / 超重结算见 `combat §4.9`。**
- **回血渠道只有两条（R-14 硬约束 · R-19 补三轴）**：① **使用药品消耗品**（**三轴** `hp`/`bleed`/`rot`，5 品种；背包内即时，有**用药耗时**）② **基地双人床休息回血**（只回 `hp`，不止血 / **不解尸毒感染**——**⚠ R-36：感染唯一解除 = 战胜最终 boss**）。**医疗室不治疗**——它是**制药工坊**（药物原料 → 药品），与厨房（食材 → 食物）同构。**没有任何"回基地一键回满血"的建筑**。**⚠ R-32：药品 4 品种（绷带 / 急救包 / 医疗包 / **抗毒血清**〔⚠ R-36 由抗尸毒剂改名并改职能：恢复 MaxHP 上限、不解毒〕）全部平级、无品阶（无"高阶 / 低阶"概念）；治疗效果唯一放大渠道 = NPC 好感**（R9 `ResearchBonus = Aff`；`药品回复量 = 基础 × (1 + Aff)`）。**⚠ R-34：原「强效药剂」已删除，由「医疗包」替大回血槽（HP 回血轴 = 3 容量档：绷带 +20 / 急救包 +40 / 医疗包 +60）；消毒绷带已删（现 4 品种）。**
- 低于阈值触发 debuff（移速下降、**回血效率下降**〔药品与双人床同减〕、极低时持续掉血）；食物/饮料恢复，厨房可将食材加工为更优补给。
- 把"末日"从口号变为**每时每刻**的生存压力（**⚠ R-42：时间按现实时间比例流逝（1 游戏日 = 6 现实分钟）；基地内时间静止**——生存压力不再以"每局"为单位）。**✅ R-43：衰减率已按游戏日重估**——`Satiety` **65 点/游戏日**、`Hydration` **80 点/游戏日**（换算锚点 = 1 游戏日 = 6 现实分钟；**数值 ⚠待调**）；**新增存档级世界时间字段 `CurrentGameDay` / `CurrentTimePhase`**（基地内静止、离开基地后按现实比例流逝）。见 base-survival-npc §A.4 / §0.5、progression §4.1.1 / §8 AC38。

### 7.5 视野与战争迷雾 + 失败惩罚（详见 fog-of-war.md / death-and-corpse.md）

- **战争迷雾（探索三态）**（**⚠ R-44 已改**：原表述"暗黑破坏神2 式自动地图（automap）"**去专指术语**——避免读者以为仍存在小地图；**三态机制保留**）：每层初始全黑；探索过区域显示灰暗地形；视线内显示全彩地形 + 敌人 + 物体。探索进度**按楼层持久化**，死亡保留。因布局按存档永久固化，探索进度跨死亡/跨探索保持一致。**尸体**与**已安装绳索口**为**永久标记**（仅坐标，不透视地形）——**⚠ R-45 已改（原：R-44「原载体 automap 已随本批移除，承载方式 ⚠ 待用户拍板」）**：**承载方式【落定 = `M` 键「地图界面」（独立全屏浏览器）】**——**"永久标记、仅坐标不透视"的设计意图保留**；**地图界面 UI = 左上角当前时间 / 左侧各楼层按钮（带垂直滚动条）/ 右侧选定楼层地图**；**跨层查看 = 点选楼层按钮，仅列已探索层**（`ExploredFloors`；本作**单层常驻载入**，未生成层无数据）。**HUD 左上仍无常驻小地图**（全局信息走 `M` 键地图界面）。**R-20 注**：迷雾属**② 持久层**，是跑尸"认路、挑少怪路线"的依据。
- **失败惩罚（D2 式捡尸 · R-07 立 · R-20 改）**：死亡时**携带物（背包 + 装备栏武器/护甲）全部留在死亡点的「尸体」中，不消失**；玩家在**基地（第 100 层）空手复活**，需**返回死亡点取回尸体**（corpse run），出发装备来自**基地储藏室**。**迷雾探索进度保留**。**已救援 NPC 与已完成的剧情进度属持久层，不因死亡撤销**。
  - **⚠ R-20 关键改动（世界状态三层）**：地图物品与敌人**不再是"永久不回位"**，而是**按探索重置**——**同一次探索内**敌人死亡 / 物品拾取**不回位**（避免来回跑动反复重刷）；**回基地后再次出发（= 新一次探索）时，敌人（含精英 / Boss）与地面物品、容器全部恢复为 seed 初始态**。**属持久层、永不重置的**：**迷雾 / 已安装绳索 / 尸体 / 门锁 / 救援·剧情·Boss 击败里程碑**。
  - **后果（用户明确接受）**：**跑尸难度显著上升**——尸体附近甚至整条回程路线上的敌人重新站岗，跑尸从"散步"变成"**再杀一遍**"。因此**惩罚不再只是"消耗食水/弹药 + 时间"，而是"消耗 + 再肃清"**。
  - **这一改动服务三个体验目标**：① **凸显逃生绳索的价值**——楼梯间会被重新堵住，而绳索**跨探索保留**、可**跳过楼层绕过敌群**，成为跑尸与深入的核心捷径（同时也是"唯一能绕过复活敌群"的手段）；② 提供"**大厦逃生**"体验——一次探索内从 100 层一路杀到 1 层，是"肃清一整栋楼"的马拉松式推进；③ 强化「撤即经营」（P6）的取舍：**回基地 = 保住战利品但重开敌情；不回 = 继续深入但风险累积**。
  - 详见 `death-and-corpse.md` §3.3/§3.4、`procedural-gen.md` §3.1（三层世界状态）。
- **策略循环（跑尸规划）**：死亡不再永久损失装备，但**跑尸本身消耗食水/弹药与时间**，**且（R-20）路径上的敌人已复活**，尸体又可能位于敌群/Boss 附近——鼓励玩家**用储藏室装备谨慎推进、以楼梯间主通道 + 自建绳索规划多条脱出口**安全取回尸体，而非"用最差装备无脑探图"。基地储藏室是跑尸装备的来源与跨局保险箱。与 P2（搜刮即构建）、搜打撤节奏强绑定。
- **回撤代价（与 §7.1 联动 · R-20 加重）**：**探索内**上下移动不重置敌人，但**一旦撤回基地，下次出发敌情全部重置**（③ 层复位）；且回撤**不回补库存**（补库存必须回基地，而回基地就意味着重新肃清）；游戏内时间**在楼层内按现实比例推进**使基地 NPC 消耗继续（**⚠ R-42：基地内时间静止，停留时库存不消耗**）——"跑回基地"不是免费补给。
- 效果：尸体可追回（缓解挫败），但**取回过程本身成为一场小型行动**（R-20）——"跑尸 + 多脱出口规划"把风险节奏变成**可规划的空间策略**（绳索、少怪路线、迷雾记忆），而非纯随机惩罚。

   - ④ **R-30 新增数值均标 ⚠待调**：R8 `TrainerMod` 上限 / 斜率、林晞「初次见面即发脾气」专属剧情文本、薇拉 55% 与林晞 20% 之外的其余 NPC 初始值（当前默认 60%）、R8↔R9 配对放大的联合标定（血池 ↔ 药品回复量）。

   - ② **ZS 武器数值的采纳方案 A/B/C**（`reference-zero-sievert-weapon-data.md` §8）——⚠ **当前最大的一块未决**：本作 `WeaponDamage / 射速 / 精度 / 工效 / 附件槽` **仍是 R-15 推定值**，与 ZS 真值有 6 项事实性差异；**且 R-19 的"改加减"落地后更紧迫**（若采纳方案 A 改 **0–100 绝对值**轴，附件数值须同步换算）；
   - ③ **型号命名策略**——ZS 用化名规避商标（`EC 101` / `N4o1` / `Skop H`），本作现用真枪名（AK-47 / M4A1 / SCAR-H）；**上架 Steam 前必须决策**；

   - ⑥ **投掷物升为 T 档**（补偿近战移除后的"省弹 / 贴身应急"职能；若不做投掷物需另找替代）。

8. **药品与状态轴相关（R-14 立 · **R-19 改三轴** · **R-21 两处定案**，余项待复核）**（详见 weapons-loot §3.10 / combat §6.13）：
   - ① **药品三轴数值**（`hp`：绷带 **+20** / 急救包 **+40** / 医疗包 **+60**（强效药剂已删、消毒绷带已删，R-34）；`bleed`：三 HP 药均 −1 级；**⚠ R-36：`rot` 由「0–100 累积计量」改为「二值感染态 `RotInfected`」**（变异体攻击且造成伤害时 **20% 几率**，幂等；不可药解、**唯一解除 = 战胜最终 boss**）；**抗尸毒剂 → 抗毒血清**：恢复 MaxHP 上限 **+20**（R9 放大至 **+40**），**不解毒**；**HP 数值为 R-34 暂定、待阶段 1 校准**）与**用药耗时**（1.5–3.0s）为暂定，待阶段 1 试玩校准；

9. **探索级重置相关（R-20 立 · **R-21 大部分已拍板**）**（详见 procedural-gen §3.1 / death-and-corpse §3.4 / enemies-ai §3.7 / progression §6#14）：
   - ① ✅ **已定（R-21 用户拍板）**：Boss 重复击杀的掉落 = **D2 式**——**掉落概率与物品等级固定，具体掉落物随机**（每次击杀走**同一张掉落表**：概率不变、等级档不变，"抽中什么"随机）。**不采用"首次保底高价值 / 重复普通表"护栏**（原 ⚠建议作废）；普通敌人同样无特殊护栏。见 enemies-ai §3.7；
   - ② ✅ **已定（R-21 用户授权"按推荐"）**：玩家主动扔在地面的物品**在探索级复位时统一清除**——**既不保留、也不恢复**，避免垃圾永久堆积在楼层里。见 death-and-corpse §6-12；
   - ③ ✅ **已定（R-21 用户拍板）**：**不做浅层豁免**——**全局重置，与暗黑破坏神2 一致**（"只重置已深入到的深度以下"或"前 N 层不重置"均**不做**）。理由：规则最简、手感对齐 D2；
   - ④ **跑尸难度的手感校准**（R-20 最大的体验风险）——需在阶段 0/1 实测："**重新杀穿 vs 用绳索绕过**"的实际比例；**若绝大多数玩家选择硬打（绳索用不上）→ 说明绳索铺设成本过高或密度不足**；**若跑尸普遍被放弃（尸体不要了）→ 说明惩罚过重**，需回调（如提高绳索供给、降低浅层敌人密度）；
   - ⑤ **物资恢复的"可重复搜集"是否造成经济失衡**——三重护栏已给（同 seed 同批物资、同深度物资总量恒 0〔原 `ΔCredits_floor`，⚠ R-32：`Credits` 已删除〕、深层掉率更低）；**R-21 追加**：**现金**（空投站货币）同属"可重复搜集"物资，须一并纳入本项实测（护栏见 progression §6#15）；
   - ⑥ ✅ **已定（R-21 用户拍板）**：**通关后允许继续探索**——可继续下潜**刷极品物品**；**后续开发可加入隐藏 Boss 等挑战**（作为通关后内容）。通关流程本身不变（Victory → 回基地）。
