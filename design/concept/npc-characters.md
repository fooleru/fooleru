## 1. 总览：题材定位与设计原则

### 1.1 题材定位（R-26 · 最高约束）

- **男频向 · 英雄救美末世逃生**。**主角为男性**（退伍特种兵转行的快递员，沉默硬汉——是"英雄"位置）。
- **10 名可救援 NPC 全部为女性**，气质分层、**禁止同质化**（art-bible §11.2 十层气质表）。
- 每位 NPC 各有一段**独立的「美人遇险 → 玩家杀入 → 救出」救援桥段**——这是**叙事与关卡包装**，**不新增 escort / 护送玩法系统**（见 base-survival-npc §C.3）。
- 她们既提供**情感锚点**，也是基地 9 间救援解锁房间（R2–R10）的**解锁钥匙**（**身份即职能**，刚性对应，§B.3.2）。
- 立绘为**现代写实插画**，**独立于游戏内像素体系**（art-bible §11）。

### 1.2 设计原则（本文件的方法论）

**原则 A —— 性格必须从职业长出来（本文件的核心方法）。**
写作三步：① 先问"**这份职业每天在做什么、见过什么、最恨什么、最擅长什么**"；② 由此推导她的**价值观、说话习惯、职业性创伤**；③ 让她的**情感表达方式也是职业的延伸**（护士的温柔是临床磨损过的、电工的关心是"先看电路图再动手"、教官的在意是训练要求）。
- **反例（禁止）**：把"急诊护士"写成一个通用"温柔治愈系"——那是**萌属性**，不是**人**。本文件每位 NPC 的性格关键词都必须能**回溯到职业**。

**原则 B（底线一）—— 每名 NPC 必须有专业尊严与独立人格，不做纯花瓶。**
她们在基地里是**有产出、有判断、有主见**的人；感情线是"两个成年人之间慢慢建立的关系"，**不是"救回来即归你"的奖励道具**。她可以拒绝、可以瞧不起你、可以有自己的目标排在"跟你在一起"之前。

**原则 C（底线二）—— 性感体现在气质与关系张力，不做低俗描写。**
遵守 art-bible §11.5「**性感但不越线**」。性感 = **自信、距离感、暧昧张力、专业能力带来的魅力**；**不做**（也不写）**裸露 / 性暗示越界的描写**；设置项提供「立绘内容强度」开关（标准 / 保守）。

**原则 D —— 性格 ↔ 数值必须自洽。**
好感弧线（**起点 `AffinityInit` → 阈值事件 → 终点 100%**）与性格、职业**一一对应**：低起步必有**叙事理由**（林晞 20% / 薇拉 55% 见 §4.3 / §9.3），高终点必有**关系兑现**（100% = 亲密举动，一次性）。**不得**出现"数值说低好感、文案却写她一见钟情"。

**原则 E —— 情感弧线锚定既有阈值档位（对齐 §C.4 轴 A）。**
每位 NPC 的**态度变化弧线**（起点 → 中段 → 终点）必须**落在既有 5 档阈值事件**上，不得自造节点：

| 档位 | 事件（轴 A · 全 10 名通用） | 语义 |
|---|---|---|
| **100%** | **做亲密举动**（**一次性**，持久不回退） | 关系终点：主动的、明确的情感兑现 |
| **80%** | **向玩家表白**（**一次性**，持久不回退） | 关系转折：她先开口 |
| **40%** | **哭泣**（可重复，同档 ≥1 天冷却） | 信任已建立、防线松动 |
| **20%** | **抑郁烦躁**（可重复，同上） | 仍在"警告"档之下（`<20` 才触发） |
| **0%** | **精神崩溃**（可重复，同上） | 断供 / 极端压力下的崩溃 |
| **`AffinityInit`** | **不触发任何阈值演出**（初始值非"跌破"） | 起点只决定"她一开始怎么看你" |

> ⚠ **`</≤` 口径（R-30 收口）**：阈值事件 = "**跌破 < 阈值**（严格小于）"、状态色带 = "**`[下限, 上限)`** 左闭右开"。故 **`Aff = 20%` 是「警告」档，不是「抑郁烦躁」**；**初始值落在档内不触发演出**。

## 2. NPC#1 · 艾拉·维恩 Ella Vane（R1 起始房间 · 富翁情妇 / 被软禁者 · 妖娆性感 · 60%）

> **机制锚点**：`AffinityInit = 60%`（默认）｜ 房间 R1（起始房间，开局即态 2）｜ 专属赠礼 = 性感睡衣 ｜ **R-37 挽救剧情：排除**（见 §13.4）

### 2.1 人物简介

艾拉·维恩曾是这栋楼顶层最耀眼也最不自由的女人——富翁的"情妇"，实为被软禁的人质。她住着最好的房间，戴着最贵的首饰，却连电梯都出不去；灾变前，她已经把逃离的路线记在心里，只是没来得及走。灾变当天，她正在门口替富翁签收一件快递——箱子打开时，屋内的东西已经"变了"。她被变异富翁扑向，第一反应不是尖叫，而是抓起了手边的拆信刀，然后看见了你。被困的这些天，她靠一具漂亮皮囊和一副好脑子活着：把能吃的都匀成小份、把能锁的门都锁上，用"被需要"换"被留下"。被救出后，她住进了你的起始房间，成了基地里第一个"人"。**她道谢、她微笑、她把自己收拾得体面——但她的手始终没真正松下来。** 被救是自由，可自由她从来没有过；她怕的不是末日，是又一次被谁"留下"。

### 2.2 性格设定

**核心人格（3–4 关键词）**
- **早熟的通透**——在察言观色里长大，一眼能看穿一个人想要什么。这是她活下来的本事，也是她不敢对人卸下的防备。
- **表演性的温柔**——她的体贴、她的笑意、她递过来的水，都带着分寸感；不是假，是她**只敢用"表演"来接近人**。
- **对自由的执念与恐惧**——她最想要自由，又**最怕自由**：从没为自己做过主的人，突然自由，等于突然悬空。
- **"被需要"的警惕**——她清楚自己"好看"能换来什么，也清楚**那不等于被爱**；所以她**抗拒被当作"奖励"**。

**说话方式**
- 语气特征：**软、缓、带一点点拿捏过的调笑**；把重话包在轻话里；从不大喊，也用不着大喊。她的句子常有"**留白**"——说一半，剩下的一半要你自己听出来。
- 台词范本（**首句为 §C.9 既有"建筑功能文案"，其后为可衔接的新写**）：
  1. "别把我一个人留在这儿。"
  2. "你救我的时候……枪声比我想象的响。我居然一点都不怕。"
  3. "这屋子以前比这儿大十倍，可我现在睡得踏实多了——你说奇不奇怪。"
  4. "别对我这么好，先生。被惯着的人，会忘了怎么自己走路的。"
  5. "我不是花瓶。花瓶碎了就碎了——可我还没活够呢。"

**行为模式**
- **日常（基地内）**：她是"**基地的门面与人情中枢**"。会记得每个人的口味与忌口，会替 newcomers 铺床、会劝架；把 R1 的房间收拾得像样；用她的**洞察力**替玩家留意谁不对劲（对应其"情报提示 / 小幅 buff"的房间功能）。她**从不参与战斗**，但**极擅长在人与人的缝隙里周旋**。
- **态度弧线（对齐阈值档位）**：
  - **起点（60%）**：**感激 + 礼貌的距离**。她把你当"一个可以暂时依靠的人"，但**保留着随时能退场的身段**——她用魅力筑墙，墙内不见人。
  - **中段（40%→80%）**：某天夜里她**先崩了一次**（**40% 哭泣**）——不是因为饿，是因为"无事可做、无人需要"的空。之后她**第一个向你说出口**（**80% 表白**），但表白也带着她的方式：像玩笑，又不像玩笑。
  - **终点（100%）**：**亲密举动**——她**第一次不问回报地靠近你**（不是交易、不是生存），对她而言，这是比"被爱"更难的一步：**主动**。

**弱点 / 恐惧**
- **恐惧**：再一次被谁"留下来"（被拥有 / 被控制）；以及**"美貌失效"的那一天**——皮囊是她唯一的资本，她怕被人发现壳里其实什么都没有。
- **弱点**：在感情上**不会"要"**。她擅长给，不擅长索取；一旦关系需要她"提出要求"，她会本能地退回到"没关系，我都行"。

**欲望 / 执念**
- 她**真正想要的**是**"为自己活一次"**——做一件**只因为自己想、而不是因为能换到什么**的事。此外，她想**弄清富翁到底在楼里做了什么**（她是唯一近距离观察过他的人）。

### 2.3 与主角的关系基调

**起点 60% → 终点 100%。** 为什么是 **60%**：她是**序章第一位被救者**，**感激是真实的**（+ 她天生善于对"有用的人"释放善意），所以起点**不低**；但**60% 恰好是"基准"——她停在"我很感谢，但我们还不熟"的位置**，因为她**被"拥有"过一次，不会再轻易交出自己的信任**。她与玩家的关系**先当成"一笔人情"来经营**，直到她自己都分不清哪句是真心。**终点的 100% 对她意义特殊：那是她人生第一次主动。**

### 2.4 剧情钩子

1. **富翁的秘密**：她近距离见过富翁的账本 / 会客名单，知道"哪些人上过顶楼、谈过什么"——**真相支线的第一把钥匙**（对应其轴 B 进阶：交付[实验室密钥] + 80%）。
2. **旧世界的债**：她的"身份"可能引来外部的**雇佣兵或旧买家**（与伊芙琳口中"封锁行动"呼应）；她**认识某个不该认识的人**。
3. **善良的代价**：她**洞悉人心**的副作用是——她会先看出**其他 NPC 藏着的事**，而说破它 = 得罪人。这埋下"她与某位 NPC 关系破裂"的支线。

### 2.5 群像关系（详见 §12）

- 与**诺拉**：**同类相知**——两个都懂"表演"的人，彼此一眼看穿，既是唯一能放松相处的人，也最容易彼此戳破。
- 与**林晞**：**轻蔑与反轻蔑**——林晞看不起"靠脸活着"的她，她则一眼看出林晞的嘴硬；两人是"最该和好、最难和好"的一对。

### 2.6 R-37 挽救剧情适配

**排除（见 §13.4）**。**叙事理由**：艾拉是**唯一开局就在主角房间里的 NPC**——她与玩家的关系**不靠"下潜救援"换来**。若让她来救你，等于说"白送的感情也能救命"，会**削掉整个系统"救人 → 经营 → 回报"的正反馈**。**机制上排除她（`AffinityInit` 60% 的通用 NPC 也不构成"白送"——但她的特殊性在于"零救援成本"）**：这份回报**必须靠主动下潜与长期经营挣来**。她在此剧情中**不出现**（可在其他结局 / 台词中被提及——如"要是她在，一定会说点什么"）。

### 3.1 人物简介

蕾娜·哈特是大楼的维保技师——灾变发生时，她正在检修电梯，工具箱就放在脚边。楼梯间的消防门在她身后落下时，她第一反应是骂了一句脏话，第二反应是**把工具箱抱进怀里**：**别的东西都能再找，吃饭的家伙不能丢**。被困的这些天，她**把这一层当成了要修的活儿**：用电梯井的钢缆做陷阱、用配电箱的继电器给应急灯"续命"、用一根撬棍换来半箱罐头。她救不了所有人，但她**从不让"坏掉"的东西烂在那儿**——能修的，她全修。被主角从"工作台旁围上来的变异体"里救出后，她做的第一件事不是道谢，而是**蹲下检查你枪的枪管**："**这玩意儿再打两梭子就要卡壳了，你是想死在门外吗？**" 到了基地，她立刻占了工作室，理由简单：**这栋楼，总得有人让它重新转起来。**

### 3.2 性格设定

**核心人格（3–4 关键词）**
- **实用主义**——她**用"能不能修"衡量一切**，包括人：能干的留下，光会说的靠边。不虚头巴脑，不客套。

**说话方式**

  2. "站直了。你这一身伤，是舍不得子弹还是舍不得命？"
  3. "……行。你这枪我收下了，两天后还你一把'听话'的。"
  4. "别谢我，谢你自己没死在门外——我要修的东西，不许自己报废。"
  5. "东西坏了不丢人，烂在那儿才丢人。人也一样。"

**行为模式**
- **日常**：工作室是她的领地。她把子弹一枚枚拆开重装、把破护甲一处处补、把绳索一节节编；**"改装 / 修理 / 绳索合成"全经由她手**（对应 R2 工作台的三项主动操作）。她会**默默把玩家的枪擦好**——不打招呼，也不图夸。
- **态度弧线**：
  - **起点（60%）**：**并肩干活的关系**。她**尊重能干的人**，所以起点不低；但她的"好"是**工头式的**——先看你能不能用，再决定要不要多管你。
  - **中段（40%→80%）**：她**第一次在你面前失手**——某件"她本可以修好"的东西坏了，她蹲在原地没起来（**40% 哭泣**，她哭都哭得无声）。之后她把这份脆弱交给你（**80% 表白**），说得像派活儿："**我这儿缺个搭手的，你要是……不嫌，就一直搭下去吧。**"
  - **终点（100%）**：**亲密举动**——她**把手艺交到你手里**（教你修那把你们"一起救回来"的枪），在她的世界里，这比任何情话都重。

**弱点 / 恐惧**
- **恐惧**：**不可逆的失败**——她**怕修不好的东西**。灾变当天，她眼睁睁看着电梯把她不认识的一个人关在了外面，那是她这辈子的"修不好"。

**欲望 / 执念**
- 她**真正想要的**是**"让这栋楼重新运转起来"**——把混乱修回秩序。她也在找**她带过的那个学徒 / 工友**（下落不明）；那件事比她自己重要。

### 9.3 与主角的关系基调（**55% 的叙事解释 · 重点**）

## 10. NPC#9 · 林晞 Lin Xi（R9 研究室 · 富翁实验室助理研究员 · 清冷书卷·傲娇易怒 · 20%）

### 10.1 人物简介

林晞曾是**一位天才导师手下最有前途的学生**——她和师姐**伊芙琳（NPC#10）同出师门**，那位导师早期就挂靠在「军方生物防御项目」上。她从小就是那种"别人家的孩子"，**把研究看得比命重**。直到她**读懂了导师那些"不该给人看"的数据**：那不是防御，那是**一把钥匙**——一把能凿穿地底封印、把某种东西放出来的钥匙。**她选择了退出。** 而导师的选择，是**灭口**——一次被伪装成"事故"的灭口，就发生在泄漏源的近旁；她**侥幸逃了出来**，从此**对任何人都竖起了最高等级的戒心**：**"先别信"，成了她的默认设置**。她的师姐伊芙琳，则**选择了留下**。

此后，导师的研究被**富翁**资助、收编进私人实验室。林晞为了查清"导师、富翁、那件事"之间的账，**设法以"助理研究员"的身份混进了富翁的实验室**——**这一次她不是为了科学，是为了证据**。可她也**一直是"助理"**：脏活累活她做，署名功劳归老板。灾变发生时，她**正在记录一组异常数据**——那组数据后来被证明，正是"末日之源"泄漏的起点；她**看着导师留下的那项研究，变成了眼前这场灾难本身**。被困的这些天，她**守着实验室、守着那些"不是给人看的"数据**，靠一台电脑和一箱营养剂活着；当泄露的样本终于"活"过来、开始寻找出口时，她**没有跑，她把硬盘拔下来揣进了怀里**——**她宁可死，也不让那些数据落进任何人手里**。被主角从"样本泄漏"里拽出来时，她**第一句话不是谢，是警告**："**别碰那个箱子。**" 到了基地，她**被"安排"进了研究室**——**这件事本身就让她火大**：**她凭什么听你的？她又不是你的什么人。** 于是她**从进门第一天起，就在闹脾气**。

### 10.2 性格设定

**核心人格（3–4 关键词）**

- 语气特征：**尖刻、学究、爱纠正别人**；**爱用"首先 / 显然 / 你应该知道"开头**；**句子里常常带刺，但刺下面藏着试探**；**被说中心事时会突然拔高音量**。

  2. "我不用你安排。……你别以为救了我，我就要听你的。"
  3. "那个箱子——我说了别碰。你听不懂人话吗？"
  4. "你才不会看这个。……算了，放下吧，我自己来。"
  5. "我留下来，是因为数据需要我。……不是因为你，别想多了。"

**行为模式**
- **日常**：研究室是她的堡垒。她**守着电脑、解析关键物品、解锁进阶科技**（对应 R9）；她**把房间弄得像实验室**、**把资料按只有她懂的方式分类**；她**不战斗**，但**她掌握"真相"的一半**。她**不主动找人说话**，**却会偷偷观察每个人**。
- **态度弧线（关键 · 与 20% 对齐）**：
  - **起点（20%）**：**防御性的敌意 + 智识优越 + 情感笨拙**（**落在「警告」档，非「抑郁烦躁」**）——**详见 §10.3**。她**一进基地就闹脾气**（**专属初见剧情，用 `sullen` 差分**）。
  - **中段（40%→80%）**：她**在某个"她的东西终于被认可"的瞬间松了防线**（**40% 哭泣**——她会为一句"这研究是你的吧"而失态）。之后她**用"施恩"的姿态表白**（**80% 表白**）："**我把数据给你看。……只给你。看完不许笑，也不许谢我。**"

**弱点 / 恐惧**
- **恐惧**：**再信错一次**——她这辈子**把信任完整地交给过一个人（导师），而那个人差点要了她的命**。所以她怕的**不是"被否定"，是"自己又一次看错了人"**；她也**怕自己动心**，因为她**根本不会处理感情**。（次要：她仍**怕研究"一文不值"、怕"再被抢走"**——那是"戒心"的延伸。）

- 她**真正想要的**是**两件事**——① **弄明白"末日之源"的真相**：**那是导师留下的东西，是一笔必须有人去结的账**（也仍是她的赎罪方式）；② **把导师的罪，钉在所有人面前**——**她要的不是"被承认"，是"被清算"**。

## 11. NPC#10 · 伊芙琳·斯特恩 Evelyn Stern（R10 召唤器 · 军方生物防御项目研究员 · 知性御姐·军方气质 · 60%）

### 11.1 人物简介

伊芙琳·斯特恩曾是**一位导师手下最忠诚的学生**——她是**林晞（NPC#9）的师姐**，同出师门；那位导师早期挂靠在「军方生物防御项目」上（**她今天的"军方生物防御项目研究员"身份，正来自这段师承**）。当师妹林晞**发现导师在秘密研究危害人类的科技、选择退出、并因此被"灭口"时**，她做的是相反的选择：**她选择了留下，继续参与研究**——她告诉自己，那是"为了科学"、"再等等、再看看"，**她不想承认自己跟错了人**。**直到导师被自己的研究产物感染。** 是**她**——**不得不亲手杀死自己的导师**。**那一刻她才明白：她留下，就等于共犯；而清算导师的那一下，是她自己的手。** 从那以后，她**一直在努力挽回**：她把自己钉进这个项目，把能封的封、能毁的毁，试图给那项研究，做一次"了结"。

灾变发生时，她**正随队封锁这栋楼**；当封锁彻底失败、同袍一个个倒下、她**奉命留下处理"最后的数据"**时，她**选择了留下，也选择了活着**——因为她知道，**关于"末日之源"的真相与封印法，全世界可能只剩她一个人记得**。被困的这些天，她**靠军人的纪律和一点储备活了下来**：**记录、加密、毁掉不该留下的**；当"召唤器装置暴走"、整层楼被失控的能量吞没时，她**没有逃，而是试图把它关掉**——**那是导师与她的项目留下的东西，她有责任让它停下来**。被主角从暴走现场救出时，她**先看的是装置，然后才看你**，说了一句**不像道谢的道谢**："**你终于来了。**"——**她的语气不是获救者的，是等待者的**。到了基地，她接管了 R10 召唤器；她的目标**从头到尾只有一个**：**"召唤它，然后了结它。"** ——**她把你，看作她完成这件事所必需的、唯一的合作方。**

- **把温柔藏进"专业判断"**——她**不寒暄、不煽情**，她的关心**常常伪装成一句冷静的评估**（"**你还活着，很好，我们需要你。**"）。

  4. "我欠这栋楼一次了结。这不勇敢，这是我的账。"

### 13.2 设计意图（一句话）

> **这是「英雄救美」的反向兑现**——**下潜救回她们、经营感情，最终会在你要"没了"的时候，把你捞回来。** **排除艾拉**意味着：**这份回报不白送，必须靠主动救援与长期经营换来。** 它与"感染 = 硬倒计时"互为张力：**要么打赢 boss，要么攒一段满感情换一次续命。**
