## 1. 概述（Overview）

本规格定义《百层逃生》从**启动到结算**的全部关键界面与交互流程，是美术（视觉落点）、程序（节点/信号接口）、音频（提示音）三方对齐的接口契约。覆盖 9 个关键屏幕：**主菜单 / 核心 HUD / 暂停 / 存档界面 / 基地建筑交互 UI / 楼梯间·垂直通道交互提示 / 尸体取回交互 / 死亡结算界面**（含锚点安装绳索提示并入"楼梯间·垂直通道交互提示"），并统一定义输入映射与可访问性落点。

设计原则：**极简、末世像素风、一眼可读**（art-bible §7）。UX 的首要职责是把"搜打撤"的高压节奏与"撤回来经营"的安全感做成两种截然不同的界面气质——**基地暖、亮、静；楼层冷、暗、紧**（art-bible §6 光语反差）。

## 2. 目标（Goal）

- G1：核心 HUD 在受限视野（fog-of-war）下仍能提供**公平的威胁感知**（HP/弹药/生存/受威胁方向），不漏读、不遮挡。**⚠ R-44 已改**：原含"迷雾小地图"，随小地图移除删去（**该公平感知目标不变，仅去掉小地图一项**）。
- G2：所有交互提示**含实际键名**且跨层一致（键位可读，Basic 硬指标）。
- G3：基地经营（救援解锁 / 建造）与终局推进（召唤器）在 UI 上**主线清晰**：一眼知道"救谁 → 解锁哪间 → 能造什么"（**R-31：无"升级"环节**）。
- G4：死亡结算**透明传达**惩罚与保留项（**尸体位置 + 跑尸指引**、保迷雾、**"敌人会随探索复活"**、NPC 进度不撤销、储藏室安全），缓解挫败。
- G5：全屏对齐 art-bible §8 Basic，可访问性不回退。

## 3. 核心机制（Core Mechanics）

### 3.1 主菜单（Main Menu）
- 布局：中央竖排（像素字体整数倍字号，见 §4）：`继续 CONTINUE`（有存档才亮）/ `新存档 NEW SAVE` / `存档 SAVES` / `设置 SETTINGS` / `退出 QUIT`。

### 3.3 暂停（Pause）

### 3.4 存档界面（Saves）

  - **只接受该装置清单内的建材类别**（`weapons-loot §3.12` Construction 8 类中属于该装置的）；**其他物品一律拒绝**。
  - **逐材料行三段显示（硬约束）**：`材料类别 ｜ 需求 M ｜ 持有（背包 + 储藏室 + 暂存槽）｜ 其中暂存 N/M`。
  - **寄存交互**：可在该卡片内**直接存入 / 取回**（**不必开背包**）；**可随时取回，无惩罚 / 无损耗**（防误存卡死）。
  - **🔒 材料锁定给"该房间该装置"**——**不可被其他房间 / 其他装置消耗**；**建造时优先消耗暂存槽**，不足再从背包 / 储藏室扣。
  - **达标态**：某材料 `暂存 = 需求 M` → 该行显示「**已备齐**」（**形 + 色双编码**，**不得只靠颜色**，对齐 art-bible §8）；**全部达标 + 建造前置满足 → 建造按钮高亮**；**前置未满足 → 按钮置灰 + 给原因**（R-28 已有，见上条建造按钮）。
  - **锁定提示**：须让玩家看得出**暂存槽内的料是"锁给这间房这个装置的"**（例：**行尾小锁形角标 + tooltip**「已预留给本装置，不可被其他装置使用」）。
  - **持久性提示**：暂存内容**属 ② 存档级持久层**——**不因死亡 / 探索级重置清空**（tooltip 一句话说明）；**建成（态 2）后清零**。
  - **⚠ 寄存槽 ≠ 房间功能**：**不产出 / 不加工 / 不交易 / 不修理 / 不制药 / 不解析**——**态 1 仍不得出现任何房间功能入口**（与 §6.34 / AC19 一致）。**"预购寄存"是"态 1 无房间功能"的**唯一例外，且它本身**不属房间功能**。
  - **不提供扩容 / 升级入口**（R-31 已取消建筑升级）。

### 3.6 楼梯间 / 垂直通道 / 尸体交互提示（Stairwell / Vertical / Corpse）
- 楼梯间是每层**固定主通道**（**双向**，可上行回撤；回撤代价见 concept §7.1 / procedural-gen §3.3）。**非"唯一撤点"**——玩家另可自建逃生绳索作为次级通道（vertical-traversal）。
- 视觉：**逃生箭头 + 通行绿 `#4fd06a` 绿灯 + 脉冲动效**（非闪烁；「减弱闪烁」开启时转静态高亮），楼层 1 出口语义改为"大厦大门/广场"（art-bible §7 A-02）。
- 交互：靠近显示 `[E] 下行` / `[E] 上行（回撤）`，**并明确回撤代价提示**（**R-20 改**：**探索内**上下移动**不重置敌人**；但**回到基地后再次出发，敌人与物资会全部恢复**，不回补库存，时间推进 = 基地 NPC 消耗继续）。**不做"免费回城"暗示**。
  - **R-20 硬要求**：**在基地的"出发 / 下行"入口处，必须给一次明确的确认或提示**——如"**离开基地将重置全楼敌情与物资**"（可设"不再提示"开关）。**不得让玩家在不知情的情况下触发重置**（否则"我清了 3 层怎么白清了"会造成强烈困惑）。
- 过层时给**极短**转场（<0.5s，可跳过），保持下行节奏（concept P1 过境层口径）。
- **锚点安装绳索（vertical-traversal）**：
  - 玩家站在锚点**所在格**（`elevator_shaft` 为不可行走空腔，站其**相邻格**即可；见 vertical-traversal §3.3.1）→ 提示 **`[E] 安装绳索`**（含实际键名）。
  - **无绳索绳缆时置灰**并显示"需绳索绳缆"；**非锚点瓦片不显示该提示**。
  - 已安装绳索：**`[E] 下行` / `[E] 上行（−50% 速度）` / `[E] 回收绳索`**；**已安装绳索口 = 永久标记**（**⚠ R-45 已改**：原"在 automap 永久标记"的载体随小地图移除而消失〔R-44〕→ **R-45 结清：载体 = `M` 键「地图界面」（§3.2.1）**；**"永久标记、仅坐标不透视"的设计意图保留**）。
  - 楼层 1 锚点**禁用下行**（提示"已到底层"）。
- **尸体取回（death-and-corpse）**：
  - 靠近尸体 → 提示 **`[E] 取回物品`**；打开尸体（**等同容器**，逐件 / 一键取回，受背包容量限制）。
  - 取空后尸体消失、对应**永久标记清除**；**未取回尸体 = 永久标记**（**⚠ R-45 已改**：原"在 automap 永久标记"的载体随小地图移除而消失〔R-44〕→ **R-45 结清：载体 = `M` 键「地图界面」（§3.2.1）**；**"永久标记、仅坐标不透视"的设计意图保留**）。**⚠ 本批新增「任务地点」标记类型**（与尸体 / 绳索口同走地图界面，**数据源待文策渊定义**）。
- **护甲弹开反馈（R-23 新增 · combat §4.1 ④ / enemies-ai §4.5）**：
  - **触发**：玩家子弹命中敌人护甲且 `Pen < ClassThreshold`（**被挡下**，非穿甲）。
  - **必须给出的反馈（三通道，缺一不可）**：
    1. **视觉**：命中点**火花 / 弹开**特效（区别于"血肉命中"的常规血花）——**形状差异而非仅颜色差异**（色盲安全，art-bible §8）。
    2. **音效**：**金属弹开音**（清脆、短促），与普通命中的闷响形成对比。
    3. **文字提示**：命中点附近**短暂显示护甲等级**（如 `Class 5`）——**这是"玩家该换弹种"的关键线索**。
  - **设计目的（关键）**：让玩家能**归因** —— "我打不动"的原因是**弹种不对**，而非**枪法不行**。**这是 R-22「以死为师」能否成立的前提**：玩家必须能从失败中读出**正确的原因**，否则死亡只会带来困惑而非学习。
  - ⚠ **不得**只在伤害数字上体现（数字太小、战斗中不可读）；⚠ **不得**用与普通命中相同的反馈（会造成"我明明打中了却没伤害"的挫败）。
  - **首次弹开时的强化提示（一次性，非模态）**：第一次被弹开时，可附一条**轻量字幕**（"**该目标护甲等级较高，换用高穿透弹药可能更有效**"，可跳过、不中断游戏）——**提示"能做什么"，不教"该做什么"**（对齐 R-22 教学边界）。

- **基地电梯井枢纽交互（R-25 新增 · vertical-traversal §3.9）**：
  - **未开启态**：靠近基地电梯井 → 提示置灰 **`[E] 开启电梯井（需绳索绳缆 ×1）`**；无绳缆时显示该置灰文案，**不阻塞其他玩法**。
  - **开启读条**：`[E]` → **1.5s 读条** → 井道开启（**视觉事件**：灯光亮起 + 青色描边 `#45d4e0` 出现，art-bible §10.2），**存档级永久**。
  - **已开启态 · 楼层选择面板（⚠ 基地端专属 · 只在第 100 层出现）**：
    - **面板内容**：**已解锁楼层列表**（`floor ∈ ExploredFloors`）+ **当前所在层**（基地）标记；每行显示**楼层号**与（可选）**该层空间风格标签**（若已探索到）。
    - **主操作**：选中某已解锁层 → **`[E] 前往`** → **2.0s 转场**（与绳索 1.2s 区分的"电梯"读感）→ 落点 = 该层 `elevator_shaft` 锚点相邻格。
    - ⚠ **面板不是模态阻断**：移动键仍可用（玩家可走开不坐电梯）；**不锁输入**。
  - **⚠ 楼层端（99–1 层）的电梯井交互 —— 只有一个动作 · 且需要等候（R-25 硬约束 · R-25 三次改倒计时）**：
    - 玩家站在**任意 99–1 层的电梯井锚点**旁 → 显示 **`[E] 脱出 · 降下逃生绳`** → 进入**脱出倒计时**（`(100 − floor) × 1.0 s`，见下「脱出倒计时 HUD」）→ 倒计时走完 → **2.0s 转场** → 基地 → **结束当前一局（RunEnd 结算）**。
    - **⛔ 楼层端禁止出现楼层列表 / 目的层选择 / "前往其他层"入口**（那是**基地端专属**）——楼层电梯井是**单向脱出点**，不是传送台（vertical-traversal §3.9.1 / §6.15）。
    - **与楼梯间提示并存**：楼梯间的 `[E] 下行` / `[E] 上行（回撤）` 是**换图触发器**（逐层移动，可上可下）；电梯井的"脱出"是**一键回家（需等候）**。二者**语义不同、同时存在**（如玩家站在同一房间），**不互相替代**、**不互相隐藏**。
- **脱出倒计时 HUD（R-25 三次新增 · vertical-traversal §3.9.5）**：
  - **触发**：玩家在**任意 99–1 层**的电梯井锚点旁按 `[E] 脱出 · 降下逃生绳` → 立即进入倒计时态。
  - **形态（关键 · 对齐"翘首期盼"的叙事）**：屏幕**下方偏中**（准星下方、不遮挡角色与准星）出现一条**极简的绳索提示条**：
    ```
    （蕾娜·哈特）正在降下逃生绳，还剩 73 米到达。
    ▓▓▓▓▓▓▓▓░░░░░░░░░░░░  ← 进度条（随倒计时填充/消退）
    ```
  - **⚠ 数值单位（硬约束）**：**只显示"米"，不得同时显示"秒"**——"米"是**叙事皮**（`显示米数 = 剩余秒数 × 1.0`），双单位会立刻暴露"米是编的"，破坏叙事（vertical-traversal §3.9.5）。
  - **递减口径**：数字**随时间递减**（**非递增**——"还剩 73 米" → "还剩 72 米"）；刷新率 ≥1 Hz；亚秒刷新时**按整米跳变**，**禁小数**（如禁止"73.4 米"）。
  - **NPC 名字（R-25 三次）**：**存则显示具体人名**（「蕾娜·哈特」→「玛雅·索恩」→ 其余已救出 NPC），**一个 NPC 都没救时用中性变体「（基地）」**。⚠ **NPC 只改名字，不改时长**（与 base-survival-npc AC16 一致）。
  - **进度条**：**形先于色**，用**绳索下放**的视觉隐喻（可做成"绳结逐格下落"）；颜色用**功能青 `#45d4e0`**（与电梯井同族，art-bible §10.2.2）。
  - **⚠ 倒计时期间玩家完全可战斗**：**可被攻击、可开火、可换弹、可翻滚、可用药、可在锚域内移动**——**这不是 combat §6.9 的转场不可攻击态**（HUD **不得**给出"无敌 / 安全"的错误暗示）。**HUD 可给一条极淡的提示语**「离开锚点范围内将收回绳索」。
  - **锚域边界可读性**：倒计时期间，锚点周围地面出现**极淡的青**色**缓慢脉冲边界圈**（半径 3 tile，art-bible §10.2.2）——让玩家知道"我还能走多远"。⚠ **必须极淡**（不可压过战斗可读性），且**不得暗示"圈内安全"**（圈内仍会被打）。
  - **取消反馈（必须可读、不静默）**：玩家走出锚域 → 提示条**淡出** + 文案「**已离开锚点，逃生绳回落。**」+ 绳索**上收动画** + **卷扬机音效**。⚠ **不得静默消失**。
  - **可重试**：取消后回到锚点可**立即 `[E]` 重新开始**（**无冷却、无消耗**，`HubTravelCost = 0` 不变）。
  - **与「减弱闪烁」开关的兼容**：边界脉冲在开启该开关后转**静态高亮**（≤2Hz 或静态，art-bible §8）。
  - **基地端不出现该 HUD**：**基地速降（基地 → 已解锁层）没有倒计时**（`HubTravelDuration = 2.0s` 瞬发）——**进入危险不需等候，离开危险才需要**（vertical-traversal §6.23）。
  - **未探索楼层的保护提示（R-25 关键 · 非阻塞）**：
    - 玩家在**基地端面板**选中**未探索楼层**时，该行**必须仍可选中并确认前往**，同时显示警告：**「该楼层未经探索，贸然前往太过危险！」**
    - **⚠ 硬约束（对齐 R-22「以死为师」/ AC27）**：警告**只能是文案 + 警示图标**（如行内 ⚠），**禁止**：禁用该选项 / 二级确认弹窗 / 阻止前往。玩家**应当**能够"贸然前往并因此死亡"——**这正是设计意图**。
  - **不预告的内容**：楼层选择面板**不显示**目标层的敌情 / 战利品 / 是否为 Boss 层（保住迷雾张力，对齐 §3.6 风格预告口径与 fog-of-war §3.2）。
  - **落点迷雾**：从基地直达的落点区域**仍为未探索态**（不得因"坐电梯到达"而出卖地形），玩家落地后须自探（vertical-traversal §6.11）。
- **楼层空间风格预告（R-24 新增 · procedural-gen §4.8）**：
  - **触发时机**：玩家**站在楼梯间/绳索口，尚未下行**时（即 §3.6 显示 `[E] 下行` 的**同一交互点**）；**仅在向下**时预告（上行回撤不需预告）。
  - **已探索过的楼层不预告**——若目标层**已探索到该层**（迷雾已点亮过），则玩家已知其空间形态，**预告降级为极简风格标签**（避免重复信息）。**ⓘ 这是与 R-22「以死为师」一致的处理**：首次进入的未知楼层才需要预告，重复进入的信息已由空间记忆提供。
  - **预告内容（极简三元素）**：
    1. **风格名 + 一句话特征**（如「**开阔层 · 大平层**」/「**短视距 · 蜂窝格状**」）；
    2. **空间尺度徽记**（形先于色，art-bible）：**窄密（S1/S5）/ 中距（S2）/ 长廊（S3）/ 开阔（S4）** 四枚图形；
    3. **武器建议一行**（如「**建议：狙击 / DMR**」或「**建议：霰弹**」）——**给建议，不给命令**（不锁武器、不阻止下行）。
  - **⚠ 不得做成"必须换枪才能下去"的门禁**：玩家可以**无视预告直接下行**（哪怕带错枪）。**风格预告是情报，不是约束**——这既是 R-24 的玩法落点（策略性备战），也必须守住 R-22 的教学边界（"提示能做什么，不教该做什么"）。
  - **叠加位置**：预告面板**复用楼梯间交互提示的浮层**（不新开全屏面板、不阻塞移动），在 `[E] 下行` 提示旁**展开一行**风格信息；**按键提示仍是主体**（预告是附属信息）。
  - **不预告的内容**：**不显示敌情（敌人类型/数量）、不显示战利品、不显示是否为 Boss 层**（保住迷雾与伏击张力，对齐 fog-of-war §3.2）。
  - **与迷雾的关系**：风格预告**只给风格**，**不给布局**——玩家仍须自行探索（**迷雾靠走过点亮**；**⚠ R-44 已改**：原"automap 靠走过点亮"改为中性表述"迷雾靠走过点亮"——保留三态机制、去掉小地图专指术语）。

### 3.7 死亡结算界面（Death / Run-End）
- 触发：HP ≤ 0 或主动放弃（progression §6.5）。**先落库再展示**（progression §6.1）。
- 结算清单（**透明传达**，**R-07 立 · R-20 改写**）：
  - 💀 **携带物留在死亡点「尸体」中**（背包 + 装备栏武器/护甲 **+ 现金**）——**不会永久损失**，可跑尸取回。**R-21 / R-32 注**：`现金` 是**本作唯一货币**，故**随尸体掉落**（**未取回前不能在交易面板消费**）；**⚠ R-32：原局外货币 `Credits` 已整体删除——死亡结算只需列示现金一项，不再并列第二货币**。
  - ✅ **保留楼层迷雾探索进度**（跨死亡，**② 持久层**）。
  - ⚠️ **（R-20 新增·必须显式说明）** **本次探索已结束**：**下次离开基地时，敌人（含精英与 Boss）与地面物品、容器将全部恢复** —— 结算界面须给**明确的一句提示**（如"**回基地后再出发，本层敌人将重新站岗**"），**不可静默**，否则玩家会误以为"已清空的层永远安全"。
  - ✅ **永久保留的**：**迷雾 / 已安装绳索 / 尸体 / 门锁 / 已救援 NPC 与剧情进度**（跨探索、跨死亡）。
  - ✅ 基地储藏室物品安全（**跑尸装备来源**）。
  - 🧭 **尸体位置提示**（楼层 + 方位）+ **跑尸指引**（**R-20 更新**：从储藏室取装备 → **优先沿自建绳索绕过已复活的敌群**，否则走楼梯间主通道**重新打通**前往尸体层）。
- 本局收益结算（**R-11 改里程碑增量制**）：仅当本局抵达深度**超过存档历史最深** `MaxFloorReached` 时，按**增量**结算楼层项（`(MaxFloorReached − FloorReached) × C1`），**同深度重复死亡/放弃不产出楼层结算项**（**⚠ R-32：`Credits` 已删除，本结算不再产出任何货币**）；击杀项 `Kills×C2` 与战利品项 `LootValue×C3` 仍按本局实得（progression §4.1，**R-20 后论证前提更新、制度保留**）。击败终局 Boss（通关）额外 ×1.5，并走 Victory 变体（金色调、无"尸体"行）。结算界面**明示"已刷新最深纪录 / 未刷新（不再重复结算）"**，让里程碑规则可读。
- 操作：`返回基地` / `再开一局` / `主菜单`。
- **⚠ R-37 新增：尸变结算变体（RotEnding · Game Over · 与上述"死亡结算"严格区分）**：**触发 = 每日结算后 `MaxHP ≤ 0` 且尸变判定成立**（**≠ HP 归零死亡**）。**界面内容**：**明确的"尸变"失败结局呈现**（**不再有"尸体可跑尸"语义**）+ **两个必含选项**：**「读取进度」**（回退到之前的存档，**存档回退粒度 ⚠待确认 #③**：最近双人床存档点 / 自动存档）与 **「开新档」**。**反例断言**：尸变变体界面**不得**出现 `[跑尸]` / `[返回基地]` / `[再开一局]` 语义（尸变后**不可继续本局、整个存档终止**）。尸变结局是**本作唯一真正的失败结局**，与 `Victory` 变体并列为**两条终局分支**（见 §5 / progression §5 / §4.1.1）。

## 6. 边界与异常（Edge Cases）

1. **屏外威胁**：受威胁方向提示**只给方向、不给位置/轮廓**；无威胁时不显示，避免"雷达"化破坏迷雾张力（fog-of-war §3.2）。
2. **暂停中存档**：仅基地双人床或安全点可存档；战斗中暂停可打开菜单但**不可存**（防存档刷层，progression §6.5）。**⚠ R-42：双人床存档发生在基地（时间静止）内**——存档为纯进度快照、不做任何结算；**基地内不推进游戏日**（基地静止），"回合"与"每日结算"只在**楼层内流逝时间 / 回基地结算**时发生（§6.42）。
3. **「减弱闪烁」开启**：所有脉冲/警示（楼梯间动效、低血闪烁、受威胁楔形）转**静态高亮**或降频 ≤2Hz；不丧失可读性。
4. **色盲**：危险/出口/威胁全部**色 + 形双编码**（红=禁、绿=行/出口、楔形=威胁），不单靠颜色。
5. **文本缩放 L 档**：HUD 元素按网格重排，**不与准星/角色重叠**；禁用分数缩放。
6. **HUD 遮挡**：**生存条**在极端紧凑布局下可折叠（**（暂定，待用户复核）**），准星与 HP 不可隐藏。**⚠ R-44 已改**：原"小地图可折叠"**整项撤销**（小地图 automap 已整体移除、元素不存在）；原 R-43 注（"折叠常驻小地图 ≠ 关闭地图界面"）**亦作废**（当时地图界面已撤销）。**⚠ R-45**：新增的「地图界面」（`M`）是**独立全屏层、非 HUD 元素**——本条（HUD 遮挡）**不适用于地图界面**；**HUD 左上仍不新增元素填空**。
7. **死亡与暂停竞态**：同帧 HP≤0 且按 Esc → 以死亡优先，不进入暂停。
8. **多 NPC 供给告警**：NPC 越多消耗越快（base §A.4）；库存临界时基地 UI 与 HUD 各给一次提示，不刷屏。
9. **手柄热插拔**：切换设备后所有提示键名即时更新（键位可读）。
10. **无存档启动**：`继续`/`存档`置灰，仅 `新存档`可用。
11. **尸体/绳索/任务地点持久标记（⚠ R-45：载体已定 = 地图界面）**：尸体、已安装绳索口、任务地点为**永久标记**、**仅给坐标、不透视地形/敌人**；取回后对应尸体标记清除（death-and-corpse §3.6）。**⚠ R-45 结清：载体 = `M` 键「地图界面」（§3.2.1）**——按楼层切换、在对应楼层的地图上显示该层的标记。（**⚠ R-45 已改 · 原 R-44「原载体 = automap（小地图），随小地图移除而消失 → 承载方式 ⚠ 待用户拍板——候选：① 世界主视角内可见〔同层〕② 挂背包界面 ③ 挂死亡结算界面 ④ 取消标记」）。** **保留设计意图**：「尸体 / 绳索 = 永久标记、仅坐标不透视」是**跑尸与绳索功能的可行性前提**，**不削弱意图**。
12. **多尸体**：**同时标记所有未取回尸体**（**⚠ R-45：载体 = 地图界面〔§3.2.1〕，按尸体所在楼层显示**），玩家可任选路线逐具取回；不叠加为单一标记。
13. **锚点交互边界**：无绳缆时提示置灰、非锚点瓦片无提示、楼层 1 禁用下行——三者均给原因文案，不静默失效。
14. **无近战手段（R-12 新增）**：玩家侧无近战，弹药耗尽时**必须给出明确提示**并高亮可用手段（投掷物 / 备用武器 / 撤退）；**不得出现"近战键无反应"这类静默失效**。
15. **卡壳 UI（R-12 新增）**：卡壳时 HUD 出醒目 `JAMMED` + 排障键提示；卡壳 **不遮挡准星**（玩家仍需瞄准判断处境），但需在准星附近给出可读的不可射击反馈（如准星变色 + 音效）。
16. **弹种辨识（R-12 新增）**：弹种标签须**色 + 文字双编码**（PS / HP / BP / Sub），不可仅靠颜色；色盲安全（art-bible §8）。
17. **改装入口（R-12 新增）**：野外**不存在**配件改装入口（不显示灰态按钮，避免"为何点不动"的困惑）；改装 UI 只在基地工作台出现。
18. **房间图标辨识（R-13 新增）**：①图标**不得**脱离文字单独承担房间辨识——世界门楣与房间卡片**必须字母同现**；②未解锁房间图标**不得**与已解锁态混淆（冷灰蓝底板 + 去饱和 + 锁标三重）；③**图标不得被房门/暖光/其他 UI 遮挡**——世界内门楣挂于门框上方居中、与门框留 ≥2px 间距；④同一房间在图示三处（总览/门楣/卡片）**必须用同一枚图**，不得换形。
19. **图标悬停（R-13 立 · R-16 定案）**：PC 鼠标悬停图标 **0.15s** → **仅 tooltip**（首行房间名 + 次行一句话职能），**不放大**、图标规格在悬停时不变；tooltip **不得遮挡**菜单文字/按钮（**与文字间距 ≥4px，下方空间不足翻到上方**）、离开 **0.3s** 淡出（非瞬隐）；**无鼠标设备**以"靠近房门自动显示房间名"替代——**信息不得只依赖悬停**。（对齐 ZS：ZS 近期官方补丁专门修过"tooltip 遮挡菜单文字"与手柄下 tooltip 位置，本作直接规避。）
20. **用药耗时与打断（R-14 新增 · R-19 补三轴）**：使用药品期间**准星转灰 + 不可开火**，移速 ×`speed_mult`（普通药 0.5；**抗毒血清 = 0，完全定住**）；**被打断（受击/主动取消）→ 消耗不返还、效果不生效**，需明确反馈（进度条断裂 + 音效），**不静默吞药**。断粮 `<15` 时用药耗时 ×2（**仅 `hp` 轴效率 −50%，不影响 `bleed` / `rot`**，base §A.3 / weapons-loot §3.10）。
21. **用药被拒（R-14 立 · R-19 扩为三轴 · R-34 订正）**：按**作用轴**判定并给原因——**回血类**（消毒绷带 / 急救包 / 医疗包）在 **HP 已满**时拒绝："生命已满"；**止血类**在 **`BleedLevel = 0`** 时拒绝："未出血"；**⚠ R-36：抗毒血清不解毒、故不再有「未感染」拒绝条件**（其拒绝条件改为「MaxHP 上限已达当前可达最大值」）；原「抗毒血清在 **`RotLevel = 0`** 时拒绝："未感染尸毒"。**⚠ R-36：抗毒血清不解毒（只恢复 MaxHP 上限）；**注意：抗毒血清（`hp`=0）不受"HP 已满"限制**——HP 满时仍可用（"解毒"与 HP 无关）。**⚠ R-34：普通绷带现 `hp`=+20（归 `hp`>0 档），故「HP 已满」时不再豁免、会被拒——原「普通绷带 `hp`=0 满血仍可用」豁免已作废**（与消毒绷带 / 急救包 / 医疗包同列）。被拒时快捷栏对应格显示不可用灰态，**给原因、不静默**。
22. **药物原料误用（R-14 新增）**：对「药物原料」执行"使用"→**拒绝**并提示"需在医疗室加工"；背包**材料与药品分列**不同分区，避免误选（weapons-loot §6.15）。
23. **断药状态提示（R-14 新增）**：玩家药品数 = 0 时，HUD 常驻一个**低频、非闪烁**的"无药品"提示（图标 + 文字，≤2Hz 或静态），并在基地医疗室面板给"原料够不够做药"的提示——**不阻塞操作、不刷屏**。
24. **医疗室误解防护（R-14 新增）**：医疗室面板顶部常驻"医疗室不做治疗"说明；**进入医疗室不显示任何回血相关按钮/读数**，避免"为何不给回血"的困惑。
25. **三轴可辨识（R-19 新增）**：药品 UI **必须同时给出"作用轴角标 + 作用轴文字（tooltip / 详情）"**，**不得仅靠颜色区分 `hp` / `bleed` / `rot`**（色盲安全，art-bible §8 / 禁忌 20）；背包**药品可按作用轴分组/筛选**（可选，⚠待定）。
26. **修理入口与维修包（R-19 新增）**：野外**不存在**修理入口（同 §6.17 改装纪律，不显示灰态按钮）；基地工作台（R2）修理界面**必须显式显示所需维修包大类**（轻武器 / 制式 / 重武器 / 护甲）；**维修包不匹配或无包 → 置灰并给原因**；修理后耐久**只到 `condition_max`（修不满）**且**界面须说明这一点**（避免"修了怎么没满"的困惑）。
27. **探索级重置的告知（R-20 新增 · 硬约束）**：**重置必须"可预期"**——① **出发入口**给一次明确提示（"离开基地将重置全楼敌情与物资"，可记忆不再提示，§3.6）；② **死亡结算界面**明示"本次探索已结束、下次出发敌情重置"（§3.7）；③ **存档界面**用"永久 / 会重置"二分法说明（§3.4）。**禁止静默重置**——玩家在完全不知情时被"清了 3 层却白清"会严重挫败。
28. **不可"刷重置"（R-20 新增）**：**重置只在"离开基地"时发生**，**在基地内反复进出房间 / 存档 / 休息（推进时间）不触发重置**（**⚠ R-42 已改**：原「消磨时间」已并入双人床「休息」）。断言：玩家在基地停留、整理、休息后回楼层查看，**敌人仍是已死状态**；**只有真正再次出发**才复位。（防"下楼 1 层即回"这类无效操作产生困惑，也防 UI 状态闪烁。）**⚠ R-42 追加**：**基地内时间静止**——在基地休息推进时间**不触发探索级复位**（复位的触发条件恒为"离开基地"，与时间流逝无关）。
29. **尸体标记跨重置有效（R-20 新增）**：尸体的**持久标记**（**⚠ R-45：载体 = 「地图界面」（按 `M` 打开，§3.2.1）；R-44「待拍板」已结清**）**跨探索保留**（尸体属 ② 持久层）；**复位不改变尸体标记**。玩家可**跨多次探索**持续追同一具尸体。
30. **通讯室（空投站功能）交易的边界（R-21 新增 · R-27 迁至 R6）**：① **现金不足** → 购买项置灰 + 显示差额（"需 现金 ×120，当前 ×80"）；② **背包 / 储藏空间不足** → 拒绝并提示"先腾出空间"，**不可超载**；③ **未解锁空投站**（**NPC#6 无线电员**未救援）→ 只显示"需救援：无线电员（NPC#6）"，**不显示商品与价格**（不剧透），且此时**现金只增不减**；④ **任务关键物品不可卖** → 列表内以角标标记 + 卖出被拒给原因（防卡关）；⑤ **通讯室只做买卖**——**不含回血 / 修理 / 改造 / 制药**入口（各归其建筑，避免"功能越界"造成误读）。
