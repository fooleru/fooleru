## 1. 概述（Overview）
探索模型类比《**暗黑破坏神2**》的**探索记忆（D2 automap 的"已点亮"手感）**，叠加**受限视野**：每层楼初始**全黑（未探索）**；玩家走过的区域**在主视角世界内**显示**地形瓦片但色调灰暗（已探索）**；当前视线内（LOS）显示**全彩瓦片 + 敌人 + 可交互物体**（D2 的地图记忆只画地形、不画怪，本作同样"怪只在视野内可见"）。探索进度**按楼层持久化**——死亡后保留。因楼层布局**按存档永久固化**，探索记忆跨死亡/跨探索保持一致（D2 同角色同存档的地图记忆）。**R-44（2026-09-26）**：**HUD 小地图（automap）已整体移除**——上述三态**只在主视角世界内呈现**，玩家**不再有全局小地图**查看探索进度；**尸体 / 已安装绳索口**的**持久标记**设计意图保留，但其**载体随小地图一并失去**（⚠ 待用户拍板，见 §3.4）。**R-45（2026-09-26）**：**新增 `M` 键「地图界面」（独立全屏浏览器）**——**HUD 左上常驻小地图【仍然移除、不恢复】**，但玩家现有**一个全屏地图浏览器**可查看**已探索楼层**的**迷雾地形（已探索亮 / 未探索黑，仅地形、不透视敌人）与持久标记**；**尸体 / 绳索口的持久标记载体就此落定为该界面**（§3.4）；**时间读数亦挂其左上角**（R-43「按 M 显示地图时显示游戏内时间」在本批次以"地图界面"的新形态回归）。**R-20**：迷雾属 **② 存档级持久层**，而**敌人与物品按探索重置**——**"地图记得住、敌人会回来"** 正是 D2 的手感，也是跑尸"认路 + 挑少怪路线"的依据。

## 2. 目标（Goal）
- G1：受限视野制造空间压迫与"探头—交火—退掩体"张力（P1 / P5）。
- G2：探索进度跨死亡保留，奖励空间记忆，降低重复挫败感。
- G3：死亡只**留尸**（携带物移入尸体、可跑尸追回）、**不丢地图**（迷雾保留、永不受探索重置影响），形成"敢探但需规划跑尸"的搜打撤风险节奏。**R-20**：敌人与物品会随探索恢复，**唯有空间记忆（迷雾）是玩家跨探索稳定的资产**——它使跑尸/重探成为**可规划的空间策略**，而非纯惩罚。

## 3. 核心机制（Core Mechanics）

### 3.1 三态瓦片
| 状态 | 渲染 | 显示内容 |
|---|---|---|
| 未探索 Unexplored | 全黑 | 无 |
| 已探索 Explored | 灰暗 / 去饱和地形 | 仅地形瓦片（无敌人 / 动态物体） |
| 可见 Visible | 全彩 | 地形 + 敌人 + 可交互容器 + 掉落 + NPC |

- 瓦片一旦进入过 **Visible** → 转为 **Explored** 并**永久保留**（该层内）。
- Explored 区域离开视线后不再显示敌人/动态，但地形常驻灰暗（空间记忆锚点）。

### 3.2 视野与 LOS
- 视野源：玩家位置 + 视线（LOS，被墙/掩体/关闭的门阻断）。基础半径（⚠待调，建议 ≈ 8–10 tile 半径 @16 px，约相机内圈）。
- 手电 / 灯具附件可扩大半径或形成锥形（呼应 art-bible 手电锥）；夜间 / 底层更依赖光源。
- LOS 计算：grid + 射线（Bresenham / raycast），墙体阻断，半高家具（低桌）不阻。
- **屏外威胁预警（P2-04）**：玩家视野（≈8–10 tile ≈ 128–160 px）小于敌人感知（雇佣兵 360 px），故必须补"**屏外威胁预警**"——HUD 受威胁方向指示 + 受击前的微音效，让玩家在被屏外敌人命中前有可读的反应窗口。**黑暗中可能被伏击是有意的张力设计**，但以"有预警"为前提：普通雇佣兵开火前须有可听/可见警告、精英/Boss 不做屏外狙击（见 enemies-ai §3.4）。**⚠ R-44（不受影响项）**：受威胁方向提示走 **HUD 边缘楔形**（**原就不并入小地图**）→ **不受本批次小地图移除影响**，保持原样。

- **锚点/井道瓦片（R-11 补，裁决 P2-3）**：垂直通道的 4 类锚点瓦片（`floor_crack` / `utility_shaft` / `exterior_breach` / `elevator_shaft`）**均不阻挡 LOS**（地面层特征，非墙体/掩体，故不被 §3.2 射线阻断）；`elevator_shaft` 占 2×2 时其 **4 个 tile 共用同一三态**（一次 LOS 命中即整块转 Visible，不逐格判定）。语义详规见 vertical-traversal §3.3.1。

### 3.3 与死亡惩罚联动（R-07 立 · R-20 改）
- 死亡时（**D2 式捡尸**）：玩家**携带物（背包 + 装备栏武器/护甲）全部移入死亡点的「尸体」**（**不消失**）；玩家在**基地空手复活**，需**跑尸取回**（death-and-corpse）。**楼层探索（迷雾）状态保留**（**② 持久层，永不重置**）。
- **世界状态三层（R-20）**：**同一次探索内**——物品拾取**不回位**、敌人/精英/Boss 击杀**不回位**；**回基地后再次出发（新一次探索）**——**敌人与地面物品全部恢复**（③ 探索级层复位）。**尸体 / 迷雾 / 绳索 / 门锁 / 救援·剧情·Boss 击败里程碑**属 **② 持久层，永不重置**（procedural-gen §3.1 / death-and-corpse §3.4）。
- **R-20 后果**：**跑尸路径上的敌人已复活** → 迷雾（认路）与绳索（跳过楼层、绕过敌群）成为**跑尸的两大核心工具**。
- 基地储藏室物品**不受影响**（安全），是**跑尸装备来源**。设计意图（R-20 更新）：死亡惩罚 = **跑图消耗的食水 / 弹药 + 时间 + 重新肃清路径**；鼓励玩家**用储藏室装备谨慎推进、以楼梯间主通道 + 自建绳索规划多条脱出口**安全取回尸体，而非"用最差装备无脑探图"。

## 6. 边界与异常（Edge Cases）
1. **LOS 穿墙**：墙体 / 关闭门阻断；半高物体不阻。
2. **大房间**：中心可见、角落可能仍黑，逼玩家探头推进。
3. **性能**：迷雾用遮罩纹理 / 轻量数组，不逐敌判定可见性（enemies-ai 休眠已控活跃数）。
4. **切层**：迷雾随楼层加载（持久化），不跨层串扰。
5. **死亡重载 · 世界状态三层（R-20 改 · R-44 补 · R-45 改）**：迷雾保留（**② 持久层**）；携带物移入**尸体**（不回原位）；**同一次探索内**敌人 / 精英 / Boss 击杀**不回位**——但**回基地再出发后全部复活**（③ 探索级层复位，death-and-corpse §3.4）；**已救援 NPC / 剧情进度 / 门锁不撤销**；基地储藏室不受影响；**尸体与已安装绳索口为持久标记**（**R-45：载体 = `M` 键地图界面**，见 §3.4）。**⚠ R-45 已改（原：R-44「载体待定」）**。

**✅ 两项待手测项已收口（2026-10-01 用户 GUI 手测确认 · 无常量改动）**

2. **已探索压暗 α=0.55 在近黑底层（10–1）的区分度**：**2026-10-01 用户 GUI 手测确认「一眼可分」→ 保持 α=0.55**（**未触发** `art-bible §6` R-22 的底层护栏）。
   - **（存档护栏 · 本次未触发）方向提醒（易写反）**：若未来底层复核不足需调整，正确方向为「上调亮度乘算（0.45→0.55）= **下调**黑覆盖 α（0.55→0.45）」→ 已探索**更亮**、与全黑未探索区分度**增大**；**切勿"上调 α"**（上调 α 会让已探索**更黑**、区分度**更差**）。
