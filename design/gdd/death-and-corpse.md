## 1. 概述（Overview）

玩家死亡后，携带物（背包 + 装备栏武器/护甲）**不消失**，而是**留在死亡点的「尸体」**中；玩家在**基地（第 100 层）复活、身上空无一物**，需**重返死亡点取回尸体**（corpse run），出发装备来自**基地储藏室**。**迷雾探索进度保留**。

**R-20 关键修正（世界状态三层）**：地图物品与敌人**不再"永久不回位"**，而是**按探索重置**——
- **同一次探索内**：敌人死亡**不回位**、物品拾取**不回位**（避免来回跑动反复重刷）；
- **回基地再出发（= 新一次探索）**：**敌人（含精英 / Boss）与地面物品、容器全部恢复**；而**尸体 / 迷雾 / 已安装绳索 / 门锁 / 救援与剧情进度属持久层，永不重置**。
- **后果（用户明确接受）**：**跑尸难度显著上升**——尸体附近乃至整条回程路线上的敌人重新站岗，跑尸从"散步"变成"**再杀一遍**"；这**凸显逃生绳索**（唯一能跳过楼层、绕过敌群的手段，且跨探索保留）的价值，并支撑"**大厦逃生**"（一次探索内从 100 层杀到 1 层）的特殊体验。**死亡惩罚因此从"仅消耗"升级为"再肃清"**。

本系统落地用户需求："改为类似暗黑破坏神2 的捡尸模式"；**R-20 进一步明确：D2 的模型是"地图固化、怪物每次重进刷新"——即本作的「探索级重置」**（旧「地图中已被拿取的物品不再复原、惩罚只有消耗」口径**已被 R-20 取代**）。

## 2. 目标（Goal）

- G1：移除"死亡即永久损失装备"的挫败，改为**可追回**的 D2 式跑尸——惩罚保留但不再是物品清零。
- G2：**世界状态三层分离（R-20）**：① 布局层不变；② **持久层**（迷雾 / 绳索 / 尸体 / 门锁 / 剧情进度）跨死亡与跨探索**永不重置**；③ **探索级层**（敌人 / 物品 / 容器）**同一次探索内不回位、跨探索复位**。
- G3：跑尸有**真实成本**：食水 / 弹药消耗 + 时间 + **（R-20）重新肃清路径上的敌人**（呼应 base-survival-npc §A 生存压力 + fog-of-war 迷雾 + 回撤时间 + §3.1 探索级重置）。
- G3b（R-20）：跑尸难度上升**必须是可对抗的**——玩家靠**已安装绳索（跨探索保留）+ 迷雾空间记忆**规划**绕过敌群**的路线，使"跑尸"从随机惩罚变成**空间策略**。
- G4：**多尸体共存**、互不干扰；**尸体免疫探索级复位**；基地储藏室作为跑尸装备来源长期有效（含保底，防死锁）。

## 3. 核心机制（Core Mechanics）

### 3.1 死亡流程

```
HP ≤ 0
  → [Dead]
  → 快照携带物（背包 + 装备栏武器/护甲）
  → 生成 [Corpse @ 死亡点]（floor / cell / tile + 物品清单）
  → 玩家携带物清空（已全部移入尸体）
  → [Respawn @ 基地 floor 100]（空手）
  → [ExpeditionEnd]（本次探索结束；**此时代码不改动 ③ 层**——复位推迟到"再次离开基地"）
  → [RunEnd 结算]（⚠ R-32：**不再产出货币**；原"按里程碑增量计算 `Credits`"（R-11）已随货币删除作废，见 progression §4.1）
```

- **~~结算口径（R-11，裁决 P1-2 · R-20 论证已更新）~~ —— ⛔ R-32 已废止**：原「里程碑/增量制」（仅当 `FloorReached < MaxFloorReached` 时按增量发放、**同深度重复结算恒为 0**，progression §4.1 / §6#13）**随 `Credits` 删除整体作废**——**`[RunEnd 结算]` 不再产出任何货币**（可测断言：结算前后玩家货币余额**仅由携带物决定、不新增**，progression §8 AC34）。**⚠ R-32 后仍有效的实质**：`MaxFloorReached` 保留为**统计 / 成就用途**（progression §4.1.1）。
- **R-20 关键时序（务必区分）**：**死亡 ≠ 立刻复位**。死亡只是**结束一次探索**；③ 探索级层保持死亡那一刻的状态（敌人仍死着、物品仍被拿过）。**只有当玩家"再次离开基地"时，③ 层才整体复位**。这样避免了"死亡结算界面 / 基地整理背包期间地图状态突变"的不一致。

- **尸体生成**：记录死亡 floor / cell / tile + **当次携带物完整清单**（含装备栏）。**尸体属 ② 持久层，免疫 ③ 层复位**——即便玩家死亡多次、探索多次，**所有未取回的尸体始终留在原位**。
- **复活**：基地（第 100 层），身上**空无一物**。
- **世界状态（R-20 改）**：③ 层（物品拾取 / 敌人·精英·Boss 击杀）**在本探索内保持**（不回位）；**下次出发时复位**。② 层（**迷雾 / 已安装绳索 / 尸体 / 门锁 / 剧情与 Boss 击败里程碑**）**一律保留**。

### 3.2 尸体数据结构

```
Corpse {
  corpse_id : UUID
  floor     : int            // 死亡楼层
  cell      : (cx, cy)       // 8×8 cell
  tile      : (tx, ty)       // 精确瓦片
  items     : [ItemRef]      // 背包物品 + 装备栏武器/护甲（完整清单，含唯一标记）
  created_at: timestamp
  state     : UNRECOVERED | PARTIAL | EMPTIED
}
CorpseSet : [Corpse]          // 允许多具共存
```

- 存于 **② 存档级持久层**（见 vertical-traversal §3.7 / procedural-gen §3.1），与**不可变布局缓存**分离；**尸体是唯一"玩家容器"类实体，在 ③ 探索级复位时被显式豁免**（R-20）。

### 3.3 跑尸流程（Corpse Run · R-20 难度上调）

1. 复活后，从**基地储藏室**取用出发装备（储藏室不受死亡影响）。
2. **⚠ R-20：本章节的前提变了** —— 玩家**一离开基地，就是新一次探索**，因此**尸体所在层与整条路径上的敌人已全部复活**。跑尸不再是"走一趟空地"，而是**必须重新打通（或绕过）到尸体层的路**。
3. **两条路线**（这是 R-20 下的核心决策）：
   - **① 楼梯间主通道**：会被**复活的敌群**重新堵住 → 需要**再杀一遍**，消耗大量弹药与血；
   - **② 已安装逃生绳索**（跨探索保留）：可**跳过楼层、绕过敌群**，直达尸体附近 → **R-20 下绳索是跑尸的首选手段**（见 vertical-traversal）。
   - **③ 基地电梯井速降（R-25 新增 · 最优路线）**：若**尸体所在层 ∈ `ExploredFloors`**（玩家死前抵达过该层电梯井），则可在基地电梯井**速降该层**，落点即**绕过整条路径上的所有复活敌群**。**⚠ 这是 R-25 后跑尸流程的最大变化**：
     - **速降层的上界与残留代价**：电梯井只送玩家到**尸体所在层**，**不送到尸体 tile**——玩家落地后仍须在该层**自行移动到尸体位置**（该层的敌人已按 ③ 层复位复活，**包括尸体附近的**）。因此跑尸**从"打通整条楼梯间路径"简化为"肃清单层"**——**难度显著下降，但未归零**。
     - **尸体不在已解锁层时**：退回 ① / ② 路线（若玩家从未抵达该层电梯井就死了，则该层未解锁，无法速降）。
     - **⚠ 返程必须走楼梯间**：**楼层端电梯井只能"脱出返回基地"，不能选目的地**（R-25 硬约束，vertical-traversal §3.9.1）——故取完物品后，玩家可 `[E] 脱出`（**需等倒计时 `(100−floor)×1.0 s`**，见下）**结束本局**，**不必逐层上行**；但**若想继续在深层探索**，则仍须**走楼梯间**（电梯井只能回家）。
     - **⚠ R-25 三次 · 跑尸脱出同样要等倒计时**：路线 ③ 的"取完东西脱出回家"**不是瞬发**——须在锚点邻域**坚守等候 `(100 − floor) × 1.0 s`**（99层=1s，50层=50s，1层=99s），期间**可被攻击、可开火**，**离开锚域则取消**（vertical-traversal §3.9.5）。**对跑尸的含义**：取完尸体后的"最后一程"**也是一场坚守**——若取回装备后血/弹已告罄，**倒计时会成为真正的风险窗口**（这是有意的：跑尸不该是"无痛取回"）。
     - **⚠ 尸体所在层越深，脱出等候越久**：在 1 层跑尸 = 取回后还要**守 99 秒**才能走 → **跑尸的"最后一段"成本随深度上升**，与 R-20「跑尸 = 重新肃清」的惩罚方向一致。
     - **⚠ R-25 单层载入的含义**：跑尸路线 ① 的"逐层换图下行"要触发 **F 次**（生成/载入）——**路线 ③ 的价值正是"省 F 次换图"**（procedural-gen §4.5）。
   - **辅助**：**迷雾空间记忆**（② 层保留）让玩家知道"哪条路怪少"，把跑尸变成**空间规划**而非盲目推进。
   - **⚠ R-25 平衡提示（记录，不改机制）**：路线 ③ 大幅降低了"深度尸体"的取回难度 → **死亡的痛感随之下降**（原本"跑尸要重打通路"是死亡惩罚的重要组成）。当前**判定为可接受**（提高容错是用户明示的方向），但**挂起为阶段 1 试玩观测项**：若"死亡几乎无代价"导致玩家**不再害怕死亡**（削弱 P1 紧迫感），需考虑给电梯井跑尸加限制（如"尸体所在层的电梯井在跑尸时不可用"）。
4. 抵达尸体 tile → 交互 `[E] 取回物品` → 打开尸体（**等同容器**）→ 逐件 / 一键取回（受**背包容量**限制）。
5. 取空 → 尸体 `EMPTIED`（**尸体持久标记清除**、尸体消失）；未取空 → `PARTIAL` 保留余下（暂定）。**一键取回（全取）时直接 `UNRECOVERED → EMPTIED`，不经 `PARTIAL`**（R-11，见 §5 FSM）。**⚠ R-45 已改（原：R-44「automap 标记清除 → 改指"尸体持久标记（⚠ 载体待定）"」）**——**尸体持久标记（载体 = `M` 键地图界面）**清除逻辑不变。
6. **取回后**：若还想继续深入，可**不返回基地**（继续同一次探索，敌人保持已清状态）；**一旦返回基地，下次出发敌情重置**——"取回尸体"与"继续推进"的取舍由玩家承担。

### 3.4 持久化语义（关键 · R-20 三层口径）

| 状态 | 所属层 | 死亡后 | **新一次探索后** |
|---|---|---|---|
| 楼层布局 | **① 不可变层** | 不变 | **不变** |
| 迷雾探索遮罩 | **② 持久层** | 保留 | **保留** |
| 已安装绳索 | **② 持久层** | 保留 | **保留**（跨探索长期投资） |
| 尸体记录（含内容物） | **② 持久层** | 保留，新增一具 | **保留**（免疫复位） |
| 门锁 / 已消耗钥匙 | **② 持久层** | 保留 | **保留**（防死锁） |
| 救援 / 剧情 / Boss 击败里程碑 | **② 持久层** | 不撤销 | **不撤销**（一次性奖励不重复发放） |
| 物品拾取状态 | **③ 探索级** | 本探索内**不回位** | **复位**（恢复为 seed 初始） |
| 敌人 / 精英 / Boss 击杀 | **③ 探索级** | 本探索内**不回位** | **复位**（全部复活） |
| 容器开启状态 | **③ 探索级** | 本探索内保持 | **复位** |
| 玩家携带物 | **探索（run）作用域** | → 移入尸体 | — |

### 3.5 多尸体规则

- **每次死亡 → 生成 1 具新尸体**（各含当次携带物）；**旧尸体保留**、各自独立、互不干扰。
- **跑尸途中再次死亡** → 新尸体出现（含跑尸途中携带物），原尸体仍在。
- **所有未取回尸体均被持久标记**——玩家已知自己尸体的位置（**R-45：载体 = `M` 键地图界面**，见 fog-of-war §3.4）。**⚠ R-45 已改（原：R-44「载体待定」）**——**跨楼层定位 = 在地图界面点选左侧楼层按钮查看该层尸体标记**（直接回应跑尸跨层寻尸）。**⚠ R-44 已改（原：automap 同时标记所有未取回尸体）**。

## 6. 边界与异常（Edge Cases & Anomalies）

1. **尸体层已固化**：楼层布局缓存（① 不可变层）**不含**尸体 / 拾取 / 敌人状态；缓存重建时须**按三层分别处理**——② 持久层回放、③ 探索级层按"当前探索是否已开始"决定回放或复位；**尸体属 ② 层，永不丢失**（procedural-gen §6.9）。
2. **尸体在未探索区**：尸体**持久标记**使玩家知道自己尸体的位置（**R-45：载体 = `M` 键地图界面**，见 fog-of-war §3.4），但周围地形仍需探索；玩家须**实际抵达**（不提供"传送取尸"）。**⚠ R-45 已改（原：R-44「载体待定」）**。**⚠ R-44 已改（原：automap 显示尸体标记）**。
3. **连续死亡**：每死一具；新尸体含**当次**携带物；旧尸体独立保留（§3.5）。
4. **储藏室为空时的兜底**：基地储藏室**不可空到 0**——保底保留「**应急起始装备**」（**起始手枪 + 最低弹药 + 最低药品〔绷带 ×2〕**，不可存入 / 不可丢弃 / 死亡不丢），确保玩家永远能发起跑尸（暂定，待用户复核；R-12：原「近战武器」已改为起始手枪——玩家侧无近战；R-14：补最低药品——**回血只剩"药品 + 双人床"两条**，跑尸路上受伤若完全无药会显著加剧挫败）。玩家亦可**空手**跑尸（仅需取回）。**R-20 注**：跑尸难度上调后，此保底**更为关键**（若跑尸必须再杀一遍，装备与药品不足会直接形成死循环）。
5. **尸体与绳索**：玩家可原路（楼梯间）或自建绳索（vertical-traversal）返回尸体层；绳索口**持久标记**（**R-45：载体 = `M` 键地图界面**）协助寻路（**设计意图保留**：玩家能知道绳索装在哪）。**⚠ R-45 已改（原：R-44「载体待定」）**。**⚠ R-44 已改（原：绳索口 automap 标记协助寻路）**。**R-20 下绳索是绕过已复活敌群的首选手段**（绳索跨探索保留）。
6. **新死亡不覆盖旧尸体**：不会——每具尸体独立，新死亡只生成新尸体。
7. **通关时仍有未取回尸体**：保留在 ② 持久层，可继续取回（不影响通关结算）。
8. **主动放弃 run**：等同死亡——在放弃点生成尸体、**携带物移入尸体**、复活于基地（暂定；结算语义见 progression §6.5）。**放弃同样结束一次探索** → 下次出发敌情重置。
9. **探索级复位不触碰尸体（R-20 新增）**：复位只处理"地面物品 + 容器 + 敌人实体"；**尸体是独立的玩家容器类型，显式豁免**。断言：连续 3 次探索后，第 1 次死亡留下的尸体**仍在原位、内容不变**。
10. **探索级复位不触碰门锁（R-20 新增）**：门锁与"已消耗钥匙"属 ② 层。**反例（必须避免）**：若门重新上锁而钥匙已在上次探索中消耗 → **永久死锁**。故门锁状态**绝不复位**。
11. **探索级复位与"未探索楼层"（R-20 新增）**：复位**幂等**——只对本次探索**实际改动过**的楼层写入；从未进入的楼层本就处于 seed 初始态，无需处理（避免"复位 99 层"造成每层加载开销）。
12. **玩家丢弃物（R-20 立 · R-21 已定）**：玩家**主动扔在地上**的物品，**复位时统一清除**（既不保留也不"复活"），避免垃圾堆积与重复利用；**丢弃物不进尸体、不属任何持久层**。（R-21 用户授权"按推荐"——原 ⚠待拍板 **已收口**。）
13. **现金随尸体掉落（R-21 新增 · ⚠ R-32 改写）**：`现金`（**唯一货币**，**仅交易时使用**，weapons-loot §3.11）作为**普通背包物品**，死亡时**随携带物一起留在尸体中**（不消失、可跑尸取回）。**⚠ R-32**：原"**与 `Credits` 不同**（后者是局外 meta，**死亡不影响**）"的**双货币对比已失效**——**`Credits`（局外货币）已整条删除**（progression §3.2 / §4.1），故**本文件不再有双货币对比**：现金现为**唯一**货币。**设计意图**：把"把带钱回家"做成与"把物资带回家"同级的风险，强化 P3 撤退张力；**也解释了为什么基地空投站（R6 通讯室）是唯一消费点**——钱必须活着带回来（base-survival-npc §B.6 边界 12④）。**断言**：死亡后玩家身上现金**归零**（已转入尸体），**未取回前不可在空投站消费**。

## 8. 验收标准（Acceptance Criteria）

- **AC1**：死亡生成尸体，尸体含**当次完整携带物清单**；玩家复活于基地、携带物为空。
- **AC2**：抵达尸体 `[E] 取回物品` 可逐件 / 一键取回；取空后尸体 `EMPTIED` 且标记清除。**一键全取时 `UNRECOVERED → EMPTIED` 直达（不经 `PARTIAL`）**（§5 FSM）。
- **AC3**（R-20 改）：**探索内不回位、跨探索复位**——① **同一次探索内**已拾取的物品**不回位**、已击杀的敌人**不复活**；② **回基地再出发后**，物品与敌人（含精英 / Boss）**恢复为 seed 初始态**；③ **尸体 / 迷雾 / 绳索 / 门锁 / 剧情进度不受复位影响**（三层断言，见 procedural-gen AC12）。
- **AC4**：**迷雾探索进度保留**（② 层，不变）。
- **AC5**：**多尸体共存**：连续死亡各生成新尸体，旧尸体内容不变。
- **AC6（R-44 改 · R-45 定）**：尸体被**持久标记**（坐标可见；**R-45：载体 = `M` 键地图界面**，见 fog-of-war §3.4），地形迷雾仍自探。**⚠ R-45 已改（原：R-44「载体待定」）**。**⚠ R-44 已改（原：尸体在 automap 永久标记）**。**反例断言补充**：HUD 左上**不存在**小地图（automap）元素（详见 fog-of-war AC7）。
- **AC7**：储藏室作为跑尸装备来源有效；**储藏室不可被掏空至 0**（保底应急套装 = **起始手枪 + 最低弹药 + 最低药品〔绷带 ×2〕**，R-14 补药品）。
- **AC8**（R-20 改）：**死亡惩罚 = 食水 / 弹药 / 时间成本 + 重新肃清路径上的敌人**；**无物品永久损失**（尸体可追回）。**断言**：死亡后**不立即复位**（复位移至"再次离开基地"），避免结算/整理期间地图状态突变。
- **AC9**：尸体层缓存重建后尸体不丢失（② 持久层回放正确）。
- **AC10**：跑尸途中再次死亡 → 新尸体 + 旧尸体并存。
- **AC11**（R-20 新增）：**跑尸的可对抗性**——① 跑尸路径上的敌人**确已复活**（难度上调成立）；② **已安装绳索跨探索保留且可绕过敌群**（玩家有反制手段）；③ **迷雾保留**使玩家可据空间记忆规划路径；④ 三者同时成立，跑尸是**空间策略**而非纯惩罚。
- **AC12**（R-20 新增）：**复位的三条豁免**——① **尸体及其内容物**不被复位清除；② **门锁 / 已消耗钥匙**不被复位（无死锁）；③ **未探索楼层**不被无谓写入（幂等）。
- **AC13**（R-21 立 · ⛔ R-32 作废并替换）：**~~现金入尸与双货币隔离~~ —— ❌ R-32 已废止**（`Credits` 已整条删除，只剩现金一种货币）。**现存断言**：① 死亡时 `现金` **随携带物进入尸体**（玩家身上现金归零），**可跑尸取回**；② **未取回前不可在空投站消费**；③ ~~`Credits` 不受死亡影响（可测断言）~~ —— **不存在 `Credits`**（唯一货币 = 现金，其死亡表现见 ①）；④ **玩家主动丢弃物在探索级复位时统一清除**（§6-12）。见 progression §3.2 / §8 AC33–AC34。
- **AC14（R-45 新增）**：**尸体的跨楼层定位生效且受"只列已探索层"约束**——断言：① 未取回尸体在 **`M` 键地图界面**上以其所在**楼层**的**尸体标记**呈现（**仅坐标，不透视地形 / 敌人**）；② **跨楼层寻尸** = 在地图界面**点选左侧楼层按钮**，右侧切换为该层地图并显示该层尸体的标记（直接回应跑尸的跨层寻尸需求）；③ **⚠ 楼层按钮列表只列已探索楼层**（数据源 `ExploredFloors`）——**尸体所在层若从未抵达则无数据可显示**（该情形下退回"死亡结算界面的即时位置提示"）；④ 取回全部物品后，对应尸体标记清除（承接 AC2）。见 fog-of-war §3.4 / AC8。
