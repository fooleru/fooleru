## 1. 概述（Overview）
战斗系统提供本作全部"对抗"动词：**枪械射击（ADS/弹道/后坐力/换弹/卡壳）**、闪避翻滚、掩体交互、命中判定、**弹药口径与穿透**、伤害结算、硬直、死亡。它是玩家与程序化楼层、敌群、战利品交互的主要界面，直接承载支柱 **P3（前慢后快玩法翻转）** 与 **P5（像素手感）**。设计目标是"可读、紧张、可被练熟"的俯视角射击手感——每一次开火与翻滚都有清晰因果反馈。

> **R-12 范围口径**：**玩家侧无近战系统**（用户决策：近战的手感/武器/动作工作量过大，暂时不做）；**远程枪械手感整体对齐《ZERO Sievert》**（见 `reference-alignment-zero-sievert.md`）。**敌人近战保留**（僵尸扑咬 / 怪物爪击突进是敌人的攻击方式，与玩家有无近战无关）。

## 2. 目标（Goal）
- G1：射击（含 ADS / 后坐力 / 换弹 / 卡壳排障）/翻滚/命中的即时反馈扎实，内部试玩手感通过率 ≥ 80%（呼应 P5）。
- G2：后坐力与硬直构成"可学习的技巧天花板"，让高手与新手拉开差距（呼应 Competence）。
- G3：同一套操作在高层（丧尸贴身）与低层（雇佣兵枪战）产生不同动态（呼应 P3）。
- G4：所有战斗数值可被武器/附件系统注入（无硬编码死值），支撑 loot-to-build（P2）。

## 3. 核心机制（Core Mechanics）

### 3.1 瞄准与射击（R-12 对齐 ZERO Sievert）

- 鼠标准星独立瞄准（与移动方向解耦）；角色朝准星方向开火。
- **ADS（右键瞄准，A2）**：按住右键 = 举镜——准星收拢（精度↑）、视野/移速下降；`AdsTime = AdsBase / (1 + WeaponErgo_m × k_erg)`（工效越高举镜越快；`WeaponErgo_m` = 型号工效 + 配件 ergo 加减，R-19）。
- **弹道 = 实体投射物（A11/②）**：枪械默认发射**有飞行时间的投射物**（可见曳光，落 L2 层 `fx_bullet_tracer`），命中首个有效碰撞体；`ProjectileSpeed` ⚠待调，**阶段 0 实测**——若手感钝化/命中反馈模糊，**允许回退为 hitscan**（同一套代码，`ProjectileSpeed = ∞` 退化）。
- 霰弹类：一次发射 N 个 pellet，每个 pellet 独立投射物 + 各自小幅额外散布。
- **开火前提**：弹匣有弹 + **非卡壳状态**（见 §4.6）；弹药为 0 触发空仓反馈（音效 + 不能射击），不卡死。
- **换弹**：`R`；换弹期间不可开火（可移动）。

### 3.2 近战（R-12：**玩家侧已移出**）

- **玩家近战系统整体移出 T 档**（降为 B 档、不在阶段 0–3 排期）——用户决策：近战的手感/武器/动作设计工作量过大；且参考对标《ZERO Sievert》玩家侧亦无近战武器系统。
- **原本由近战承担的职能**改由 **投掷物（手雷）+ 霰弹 + 翻滚** 接手（省弹 / 破硬直 / 贴身应急），风险与补偿见 `reference-alignment-zero-sievert.md §4`。
- **敌人近战不受影响**：僵尸扑咬（enemies-ai §3.1）、怪物爪击/突进（§3.2/§3.3）仍为敌人主要攻击手段，由 enemies-ai 定义、本系统只消费其"攻击事件"接口。

### 3.3 闪避翻滚（Dodge Roll）
- 触发：按下翻滚键 + 方向；位移 + 无敌帧 + 体力消耗。
- 翻滚中不可射击，但可微调方向（不可 180° 急转）。
- 是应对高威胁（雇佣兵枪线、怪物扑击）的核心生存技。

### 3.4 掩体（M 档完整化；T 档基础）
- **T 档**：静态掩体（墙/箱）阻挡**弹道与投射物**；玩家借地形规避远程。
- **M 档**：掩体吸附 + peek（探头射击）——靠墙自动贴附，露出半身射击并降低受击面。
- **掩体等级由生成注入（R-24 新增 · procedural-gen §4.9）**：家具与墙体在生成时**标注掩体等级**——
  - **硬掩体 Hard**（混凝土墙 / 装甲板 / 柜台）：阻挡所有弹道，**高穿透弹亦不可穿**；
  - **中掩体 Medium**（货架岛 / 餐桌 / 纸箱）：阻挡弹道，**高穿透弹（`pen` 高）可击穿并衰减伤害**；
  - **软掩体 Soft**（沙发 / 床 / 隔帘）：**不阻挡手枪以上弹道**（仅提供视觉遮蔽，**不提供 LOS 阻断**）。
  - **这条与 §4.8 空间风格联动**：S1 蜂窝层家具密（多为软/中掩体，适合霰弹贴脸）；S3/S4 层硬掩体多（适合掩体 peek 对射）。**生成时若未标注掩体等级，默认 Hard**（保守，避免"以为能躲其实被穿"的挫败）。
- ⚠ **不得让掩体等级"隐形"**：玩家必须能**从外观读出掩体强度**（材质/形状/描边，art-bible）——**否则"为什么这枪打穿了那张桌子"就变成不可归因的死亡**（违反 R-22「以死为师」的学习回路）。

### 3.5 命中判定 / 伤害 / 硬直 / 后坐力 / 死亡
- 命中判定见 3.1；伤害/硬直/后坐力公式见 §4。
- 死亡：HP ≤ 0 → Dead；玩家死亡进入 run 结算（progression），敌人死亡触发掉落（weapons-loot）。

### 4.1 伤害结算（R-12 对齐 ZS · R-19 加入射程维度与配件加减模型）

```
// ① 武器属性（含配件「加减」修正 —— R-19 改纯加减模型，对齐 ZS `w_mod.json`）
WeaponDamage_m   = WeaponDamage    + Σ(附件.damage)         // weapons-loot §4.4
WeaponRecoil_m   = WeaponRecoil    + Σ(附件.recoil)         // 越小越好；降后坐件为负值
WeaponAccuracy_m = WeaponAccuracy  + Σ(附件.acc)
WeaponErgo_m     = WeaponErgonomics+ Σ(附件.ergo)
WeaponMagazine_m = WeaponMagazine  + Σ(附件.magazine_size)

BaseDamage_eff = WeaponDamage_m × AmmoTypeMult × DamageMult(Durability)
    // AmmoTypeMult：PS 1.00 / HP 1.25 / BP·AP 0.85 / Sub 0.75   （weapons-loot §3.8）
    // DamageMult(Durability) = 0.75 + 0.25 × (Durability/100)   // 0% → 伤害 −25%

// ③ 射程修饰（R-19 新增 · 见 §4.8）+ R9 研究加成（R-29 新增 · R-30 改注 · 见 §4.1 注）

DamageDealt = BaseDamage_eff × EffRangeDmgMult(dist, WeaponClass) × (1 + ResearchBonus)
    // ⚠ R-30：R9 加成【乘在「装备面板」上】、非玩家本体常数 → 判定【不构成 progression §4.3 G3 红线违规】
    //    （乘法 → 越强武器获益越多 → 拉大稀有度差距；唯一护栏 = 敌人数值按「R9 建成 + 高稀有度型号」上限标定）
    // ⚠ R-30：R9 初始加成 = 林晞的 AffinityInit（默认 60% → 0.60；林晞 20% → 0.20），**不得写死 +60%**

// ④ 护甲穿透判定（取代原"固定吸收 50%"）
ClassThreshold(C) = 10 + (C − 1) × 8                      // C1→10 … C6→50
Pen(ammo, dist)   = AmmoPen × (1 − 0.40 × clamp(dist / FalloffEnd, 0, 1))
if Pen ≥ ClassThreshold:  减免 = 0                          // 穿透，直接打 HP
else:                     减免 = clamp(1 − Pen / ClassThreshold, 0, 0.80)   // 最多减免 80%
DamageToHP = ceil(DamageDealt × (1 − 减免))
ArmorDurability −= k_armor × DamageDealt                    // 吸收即掉耐久
HP -= DamageToHP

// ⑤ 玩家本体上限（R-30 新增 · R8 训练场产出 · 见 §4.1 注 / base-survival-npc §B.4 ⑤bis）
TrainerMod = (R8 训练场已建成) ? clamp(Aff[薇拉] − 0.5, −0.5, +0.5) : 0   // 中性点 50%；未建成 = 0
MaxHP      = BaseMaxHP   × (1 + TrainerMod)      // BaseMaxHP = 100
StaminaMax = BaseStamina × (1 + TrainerMod)      // BaseStamina = 100；**恢复速率 20/s 不变**
    // 🔴 TrainerMod 是 progression §4.3 G3 红线的【唯一有意例外】（直接改玩家本体 MaxHP / StaminaMax）
    // 🔴 TrainerMod **不改变任何"回血渠道"**（回血仍只有药品 + 双人床两条，§6.13 / AC14）
    // 🔴 R-42：**双人床回血速率 = BaseRestRate、恒定、不受好感 / TrainerMod 影响**（见 §6.13 ② / AC14 / AC22⑦）
```
- **无暴击（R-12）**：`CritMult / CritChance` **已移除**，对齐 ZS——ZS 无暴击/爆头伤害轴。伤害差异由 **口径 + 弹药类型 + 穿透 + 配件 + 距离 + 耐久 + R9 研究加成** 制造。
- **R9 研究加成乘区（R-29 新增 · R-30 改注：与"无稀有度乘区"不矛盾，且不构成 G3 违规）**：`ResearchBonus = Aff`（**R9 研究室建成后生效；未建成 = 0**）——即 `武器伤害 = 面板伤害 × (1 + Aff)`、`护甲数值 = 基础 × (1 + Aff)`。**⚠ 它与"不存在稀有度乘区"（R-12 / R-15）完全不冲突**：① **稀有度乘区**指"同型号按稀有度档乘伤害"，本作**从不存在**（`WeaponDamage` 逐型号写死）；② **R9 乘区**是**绑定好感度的经营加成**（好感回落 → 加成同步缩水，断供时下降），**不是"用稀有度换伤害"**；③ 二者**来源不同、生命周期不同**（型号固有 vs 可变好感），故可共存。**⚠ R-30 定性**：R9 加成**乘在「装备面板」上**、**非玩家本体常数** → **判定不构成 `progression` §4.3 G3 红线违规**（**R-30 撤销 R-29 的「有意例外」登记**）；因是**乘法 → 越强武器获益越多 → 拉大稀有度差距**（与 R-15 阶梯同向）。**唯一护栏 = 敌人数值按「R9 建成 + 高稀有度型号」上限标定**；系统口径见 base-survival-npc §B.4 ⑤ / progression §4.3。
- **R8 训练场乘区（R-30 新增 · 玩家本体上限）**：`TrainerMod = clamp(Aff − 0.5, −0.5, +0.5)`（**R8 未建成 = 0**）——`MaxHP = BaseMaxHP × (1 + TrainerMod)`、`StaminaMax = BaseStamina × (1 + TrainerMod)`。**⚠ R8 才是 G3 红线的唯一有意例外**（直接改玩家本体）。**与 R9 成对**：**R9 放大药品回复量（×1~×2）、R8 放大血池（±50%）**，二者**同步放大**（"后期较高的 HP 最大值正好容纳药品靠研究室增加出来的回复量"）——**调数值时必须一起调**（见 base-survival-npc §B.4 ⑤bis）。系统口径见 base-survival-npc §B.4 ③ / ⑤bis。
- `WeaponDamage` 的唯一注入点为 weapons-loot §4.3（**该值按型号逐枪写死、不含稀有度乘区**，避免与新加的弹药/穿透轴双重缩放）。**R-15：稀有度只是型号层级标签，不产生任何运行时乘区**（weapons-loot §3.2）。
- **配件 = 纯加减（R-19 改）**：`Σ(附件.xxx)` 是**属性加减**，直接加到武器自身属性上（`WeaponDamage_m = WeaponDamage + Σ(附件.damage)`）。~~旧「`DamageDealt = BaseDamage_eff × (1 + ΣAdditiveMods) × Π(MultiplicativeMods)` 加乘分离」~~ —— **R-19 已废弃**。依据：ZS 的 `w_mod.json` 是**纯加减**（`acc +25` / `damage −2` / `recoil −22` / `ergo +6`），加减模型更易平衡、更易读，且不会在大后期被乘区放大。数值表见 weapons-loot §3.3。
  - ⚠ **轴的单位待定**：本作属性轴当前是**相对倍率**（如 `Accuracy 1.15`）；若采纳 R-17 方案 A（改为 ZS 的 0–100 绝对值轴），附件数值须同步换算为 ZS 量级（±25 级）。
- `ArmorClass` / `ArmorDurability` 来自 weapons-loot §3.5 护甲槽；`AmmoPen` 来自 §3.8 弹药类型表。
- **✅ 本判定对敌我双方对称（R-23 明确）**：本作的护甲穿透判定**不是玩家专属** —— **敌人同样持有 `ArmorClass / ArmorDurability`**，玩家射出的子弹按**同一公式** ④ 对敌人护甲判定。**这是 R-23 新增的关键口径**（此前文档只写了玩家护甲的消费路径，未明确敌人侧）：
  - **敌人护甲分档**：僵尸/早期敌人 = **Class 1（实质无甲）**；怪物 = Class 2；雇佣兵 = Class 3–4；**机械 = Class 5–6（底层硬门槛）**。完整分档见 **enemies-ai §4.5**。
  - **为什么对称**：① 省一套系统（判定期只认 `ArmorClass` 一个字段，不区分持有者）；② 让"捡到高 Class 护甲"对玩家有**明确可读**的价值；③ 让 **AP 弹的价值可被玩家用同一套直觉推导**（"我的 AP 弹能穿我的护甲，就能穿敌人的"）。
  - **⚠ 连带复核（R-23）**：对称后，**玩家护甲在底层同样会被 Class 5–6 的敌人火力穿透** —— 玩家的"装备升级"与"被穿透"同时发生，**生存压力曲线可能过陡**。已列为**阶段 0 实测项**（enemies-ai §4.5 尾注）。
- **⚠ 敌人护甲的反馈要求（R-23 · 配合 concept §4.1.1「失败可归因」）**：当 `Pen < ClassThreshold`（子弹被挡下）时，**必须有明确的视觉/音效反馈**（如**火花/弹开音 + 护甲等级提示**），让玩家能判断"**是我的弹种不对**"而非"**我枪法不行**"。**这是"以死为师"（R-22）能否成立的前提** —— 玩家必须能从失败中读出**正确的原因**。反馈规格见 ux-spec §3。
- **`FalloffEnd`（R-19 改名，原 `RangeFalloff`）**：取**该武器类射程曲线上"满倍率区间远端锚点"**（步枪 180 / 手枪 150 / SMG 90 / 霰弹 96 / DMR 250 / 狙击 500，§4.8）——让**穿透的线性衰减终点与伤害曲线的有效射程对齐**，避免两个"距离"轴各说各话。
- **护甲 Class 效果随耐久衰减**：`ClassEffective = max(1, ceil(ArmorClass × ArmorDurability/100))`（耐久掉光 → 回到 Class 1 的最低防护）。**此规则对敌我双方的护甲同样生效** —— 即"磨甲流"（用普通弹耗敌人护甲耐久直至 ClassEffective 降到 1）是**规则允许且可预期的战术路线**（enemies-ai §4.5）。

### 4.2 后坐力与准星（核心手感杠杆 · R-12 对齐 ZERO Sievert）

> **🔒 设计原则（R-30 用户拍板 · 勿违）**：**本作不做"游戏内武器熟练度数值"。**
> **用户原话**：「武器熟练度不要做成游戏内的数值，而是**不同的武器要做出不同的手感**，让**玩家本人**去熟练各个武器，否则**所有武器熟练度都到顶以后会产生同质化的手感**。」
> - **❌ 禁止**：任何形式的**玩家级 / 武器级熟练度数值**——经验、等级、技能点、精通度**一律不设**；**字段层面亦禁止改名重生**（`WeaponProficiency` / `weapon_skill` / `gun_level` / `handling_xp` / `mastery` / `proficiency_*` 等**零命中**）。
> - **✅ 要求**：**不同武器必须做出不同手感**，差异落在**手感参数层**——① **后坐力幅值与漂移模式**（上抬节奏 + 横移随机幅度 `DriftDir`）② **准星回正速率**（类级 `ClassRecoverMult` × 单枪 `Ergonomics` **两层**）③ **`AdsTime` / `SwitchTime`** ④ **静止收敛的强度与触发时间**（`SettleBonus` / `StillTime`）⑤ **射速与循环节奏** ⑥ **换弹动作时长与阶段感** ⑦ **卡壳概率曲线**（§4.6）⑧ **重量 → 移速 / 体力惩罚**（**⚠ R-46：其实现 = §4.9 负重系统**——重武器推高 `CurrentLoad` → 触发超重惩罚；**不另设逐枪独立移速乘区**，见 §4.9 二/三 / AC26） ⑨ **音画反馈强度** ⑩ **距离手感曲线**（§4.8）。
> - **为什么（用户理由）**：**若做成数值熟练度，玩家把各武器刷满后 → 手感被拉平 → 全武器同质化**（"用哪把都一样"）。差异必须来自**武器本身的设计**与**玩家本人的熟练**，而不是一个**可以被"刷满"的数值**。
> - **术语纪律（防混淆）**：本项目的"熟练"**只指玩家本人**——
>   | 写法 | 含义 | 状态 |
>   |---|---|---|
>   | ❌「**武器熟练度（数值轨）**」 | 游戏内可刷的数值 / 等级 / 经验 | **已废弃（R-30 整条删除）** |
>   | ✅「**玩家熟练 / Player Skill**」 | **真实玩家技能**：记后坐模式、控枪节奏、距离感 | **保留 = 本作核心成长之一** |
> - **玩家熟练不进数值、不进存档、不可被 meta 购买**——无法交易、无法继承，只能靠玩家自己练（对齐 P3「以死为师」与 SDT 胜任感；与本节"点射 / 控枪 / 站定收敛"的设计意图同向）。
> - **与 G3 红线的关系**：**手感差异不构成任何红线例外**——它不是数值加成，而是**武器固有属性 + 玩家技能**；故 `progression §4.3` 的唯一登记例外仍只有 **R8 训练场**。
> - **设计护栏（可测）**：**两把武器若"仅伤害 / 精度数值不同、手感参数完全一致" → 视为设计不合格**（这正是用户要避免的同质化，只是换了发源地）；**型号差异必须至少落在 2 个手感维度上**（断言见 §8 **AC23**）。

```
// 【口径变更】后坐力【不是】直接加到散布角，而是驱动【准星漂移】（ZS 同构）
// R-19 新增：有效后坐 = 武器（含配件加减）× 【距离后坐倍率】（§4.8 曲线）
Recoil_effective = WeaponRecoil_m × EffRangeRecoilMult(dist, WeaponClass)
每次开火：  RecoilAccum += Recoil_effective × (移动中 ? MoveRecoilMult : 1)   // 暂定 1.35
每帧：      CrosshairOffset 沿 DriftDir 累计位移（漂移幅度 ∝ RecoilAccum）
            RecoilAccum = max(0, RecoilAccum − CrosshairRecover × dt)

// 漂移方向：ZS 为"以上抬为主 + 少量随机横移"
DriftDir = 主体向上（−y，按角色朝向旋转）+ UniformRandom(−a, +a) 横向分量   // a ⚠待调

// 工效 Ergonomics（R-12 新增第二 build 轴）：决定准星回正 / 举镜 / 切枪
CrosshairRecover = RecoverBase × ClassRecoverMult(WeaponClass) × (1 + WeaponErgo_m × k_erg2)   // R-19：加入类级基准
AdsTime          = AdsBase    / (1 + WeaponErgo_m × k_erg)
SwitchTime       = SwitchBase / (1 + WeaponErgo_m × k_erg3)

// 静止收敛（ZS 手感核心：站定 + 瞄久了更准）
if 玩家静止 ≥ StillTime(0.35s，暂定) 且 持续 ADS：
     Settle: 1.0 → SettleBonus(0.55，暂定)          // 漂移与散布同步收窄
else:
     Settle: 立即回升至 1.0                          // 一旦移动立即失效

// 命中判定用的实际散布角（由精度 + 收敛 + 残余后坐力合成）
Spread = BaseSpreadFromAccuracy(Accuracy) × Settle + RecoilAccum × RecoilToSpread
θ      = AimDirection + UniformRandom(−Spread/2, +Spread/2)
```
- `BaseSpreadFromAccuracy`：由武器 `Accuracy` **反推**（Accuracy 越高 → 基础散布越小）；武器属性对照见 `reference-alignment-zero-sievert.md §3`。
- **`ClassRecoverMult(WeaponClass)`（R-19 新增 · 修正一处误记）**：ZS 的**准星回正首先是"类级基准"**（`recover_from_mouse_movement`：手枪 **1.4** 最快 → SMG/霰弹 1.2 → 步枪 1.0 → DMR 0.8 → 狙击 **0.65** 最慢，§4.8 表），**单枪 `Ergonomics` 是叠加在类级基准之上的第二层修正**。~~旧写法「准星回正只由单枪 `Ergonomics` 决定」~~ **R-19 修正**——原写法把手枪级的"回正快"错记成了单枪属性。（依据：`reference-zero-sievert-ammo-armor-mod.md` §1）
- **设计意图**：① 连续泼洒抬高漂移 → 逼出"点射 / 控枪"（G2）；② **工效**决定"举镜快不快、回正稳不稳"→ 构成除"伤害/控枪"外的**第二条 build 轴**；③ **静止收敛**制造"站定点射 vs 移动泼洒"的清晰策略分层（ZS 手感灵魂）。
- ~~原写法「`Spread = BaseSpread + RecoilAccum × RecoilToSpread + MoveSpread×(isMoving) − RecoilControlReduction`」~~ **已废弃**——控枪改由 `Ergonomics` 与附件对 `Recoil / CrosshairRecover` 两侧的修正体现，不再有独立的 `RecoilControlReduction` 直减项。

### 4.3 硬直（Stagger）
```
StaggerThreshold = 0.12 × MaxHP            // 玩家/敌人各自按自身 MaxHP
若 单发 Damage > StaggerThreshold：
    StaggerDuration = BaseStagger × clamp(Damage / StaggerThreshold, 0, 2)   // BaseStagger = 0.20s ⚠待调
```
- 硬直中目标无法行动（移动/攻击中断）；玩家硬直**不可被翻滚取消**（强调"别被打中"）。
- **⚠ R-30 有意连带（`StaggerThreshold` 随 MaxHP 放大）**：`StaggerThreshold = 0.12 × MaxHP` **随 `MaxHP` 自动放大**——**R8 训练场**提高 MaxHP 后，**硬直阈值同步提高 → 更不容易被打断**，这是 R8 增益的**有意组成部分**（**公式保持不变**，不额外引入 `TrainerMod` 项）；**反向**：低好感（`TrainerMod < 0`）→ MaxHP 下降 → **更易被打断**（惩罚的一部分，属有意）。见 base-survival-npc §B.4 ⑤bis / AC33。
- **技巧点**：玩家高伤/重击可打断敌人攻击前摇 → 进攻型解硬直（核心应对怪物扑击）。

### 4.4 闪避翻滚参数
```
RollDistance   = 64 px   (4 tile)
RollDuration   = 0.35 s  (位移速度 ≈ 183 px/s)
iFrame         = [0.05s, 0.30s]   // 起手/收尾留硬直，中间无敌
Cooldown       = 0.80 s  (从翻滚结束计)
StaminaCost    = 25
可用条件：Stamina ≥ 25
```
- **⚠ R-30 有意设计（翻滚次数随 `StaminaMax` 变化）**：`StaminaCost = 25` **固定**，但 `StaminaMax = BaseStamina × (1 + TrainerMod)` 会变化——**`StaminaMax` 50 / 100 / 150 时分别可连滚 2 / 4 / 6 次**。即 **R8 低好感（`TrainerMod < 0`）的"体力差"直接表现为机动能力下降**（翻滚次数减少），这是**有意的设计表达**（不是漏改）；**Stamina 恢复速率 20/s 不变**。见 base-survival-npc §B.4 ⑤bis / AC33。

### 4.5 弹药类型（R-12 新增 · 对齐 ZERO Sievert A6）

> 同口径可有多种弹种，**Damage 与 Penetration 分轴**——"选对弹"比"换更强的枪"更重要（ZS 核心）。

| 弹种 | 伤害倍率 | 穿透倍率 | 附加 | 最佳对手 |
|---|---|---|---|---|
| **PS** 标准弹 | ×1.00 | ×1.00 | — | 通用 |
| **HP** 空尖弹 | **×1.25** | **×0.50** | — | **无甲 / 变异体**（僵尸、怪物） |
| **BP / AP** 穿甲弹 | **×0.85** | **×1.60** | — | **护甲 / 雇佣兵** |
| **Sub** 亚音速 | ×0.75 | ×0.70 | **后坐 ×0.75**、**敌人听觉感知半径 −50%** | 潜行向 / 近距离 |

- `Pen` 代入 §4.1 ③ 的护甲穿透判定；`AmmoTypeMult` 代入 §4.1 ①。
- **换弹种**：野外可通过 `Y` 键切换已携带的弹种（视实现，⚠待定，见 ux-spec §3.8）。
- **设计价值**：给"上/下楼层敌人构成不同"（高层变异体 / 低层雇佣兵）一个**策略性备战**维度——带错弹就是打不动（P3 的深化）。

### 4.6 武器耐久与卡壳（R-12 新增 · 对齐 ZS A8 · **R-19 改消耗维修包**）

```
DamageMult(Durability) = 0.75 + 0.25 × (Durability/100)
AccuracyMult(Durability) = 0.85 + 0.15 × (Durability/100)
JamChance(Durability)  = 0                                  if Durability ≥ 70%
                       = (10 − Durability/10) / 100          if Durability < 70%
                          // 例：Durability 55% → (10 − 5.5)/100 = 4.5%
排障（Unjam，100%）：按 V 键；或换弹（100%）；或强行开火（30% 概率成功，失败则浪费一次开火）
```
- **卡壳态**：卡壳时**不可射击**，需排障；排障期间可移动、不可开火。
- **耐久回复（R-19 改：消耗维修包）**：对齐 ZS 的**消耗品修理**——在**基地工作台（R2）**使用**维修包道具**为武器回复耐久。~~旧写法「工作台免费修满耐久」~~ **R-19 已废弃**。
  - **维修包 = 消耗品**：每次使用消耗 ×1，回复 `condition_gain`（⚠待调，建议 40–60）；**耐久上限受 `condition_max` 限制**——维修包只能把耐久推到某个天花板、**不能修满**，稀缺性得以保留。
  - **分档但不按口径（R-19 拍板）**：ZS 的维修包**按 `caliber[]` 限定**（6 种）；**本作取消口径限定，改为按"武器大类"分三档**——`轻武器维修包`（手枪 / SMG）· `制式维修包`（步枪 / 霰弹 / DMR）· `重武器维修包`（狙击 / 高口径）。理由：本作口径体系与 ZS 不同，且按口径限定会造成"捡到一堆用不上的维修包"的挫败；**分档保留了"备货要对路"的决策，但不惩罚到细节**。**护甲维修包独立**（`repair_armor` 同构）。
  - **来源**：搜刮（军械柜 / 工作台周边）+ 工作台合成（消耗材料）。
  - **野外不可修**（对齐 ZS）：修理与改装**都只在基地工作台（R2）**（`reference-alignment §2-⑥`）。
  - **设计价值**：修理从"免费但麻烦"变成"要花资源"——**让搜打撤多一条消耗轴**（枪越用越旧、修复要备件），与药品稀缺、弹药稀缺共同构成"撤回基地经营"的三重动机（P6）。
- **设计价值**：给"珍惜武器 / 带备用枪"制造理由，让双武器槽真正有意义；也让"撤回基地整备"（P6）多一条理由。

### 4.8 射程曲线（R-19 新增 · 本作此前完全缺失的一整块）

> **来源**：ZS `weapon_glance_stat.json`（**原型参考基准** · 见 `reference-zero-sievert-ammo-armor-mod.md` §1）。**阶段 0–1 可直接照用**；**阶段 2 须按本作「100 层垂直大厦的室内交战距离」重标定**（两级口径 · `reference-zero-sievert-data-index.md` §0）。
> **核心思想**：**伤害不是常数，而是距离的函数**。每类武器有**两条折线**——① 距离 → **伤害倍率**，② 距离 → **后坐倍率**。这就是"霰弹贴脸 2 倍、狙击太近打不中"的来源。

#### 4.8.1 类级基准参数（6 类）

| 类别 | ADS 射程倍率 | **准星回正** `ClassRecoverMult` | `mouse_dis` 范围 | 满倍率远端锚点 `FalloffEnd` |
|---|---|---|---|---|
| 手枪 Pistol | 1.05 | **1.4**（最快） | 10–50 | 150 |
| 冲锋枪 SMG | 1.05 | 1.2 | 10–40 | 90 |
| 霰弹 Shotgun | 1.05 | 1.2 | 15–50 | 96 |
| 步枪 Rifle | 1.05 | 1.0 | 10–30 | 180 |
| DMR | 1.0 | 0.8 | 5–15 | 250 |
| 狙击 Sniper | 1.05 | **0.65**（最慢） | 5–15 | 500 |

> `mouse_dis` 是本作要新引入的手感量：**鼠标准星在屏幕上的可用移动范围**（越大 = 视角可"甩"的范围越大）。**⚠ 语义待阶段 0 实测确认**。

#### 4.8.2 距离 → 伤害倍率 `EffRangeDmgMult`（折线 · 距离单位 = px）

```
手枪   0→1.0   150→1.0   170→0.4   180→0
SMG    0→1.0    90→1.0   130→0.7   150→0.4   160→0
霰弹   0→2.0    64→1.0    96→1.0   130→0.5   140→0
步枪   0→0.3    70→0.3    90→1.0   180→1.0   200→0.4   210→0
DMR    0→0      60→0      70→0.4    90→1.0   250→1.0   270→0.4   280→0
狙击   0→0      90→0     120→0.7   140→1.0   500→1.0   600→0
```
（折点之间**线性插值**；超出末点 = 0，即"打不到"）

#### 4.8.3 距离 → 后坐倍率 `EffRangeRecoilMult`

```
手枪   0→1.0    90→1.0   110→0.75  160→0.85  180→1.0
SMG    0→1.0    90→0.5   110→0.5   130→0.5   150→0.75  160→0.9   170→1.0
霰弹   0→4.0    64→1.5    96→1.35  130→1.5   140→1.5
步枪   0→1.0    70→1.0    80→0.8    90→0.65  180→0.65  200→0.8   210→1.0
DMR    0→1.0    60→1.0    70→1.0    90→1.0   250→1.2   270→1.25  280→1.3
狙击   0→1.0    90→1.0   120→1.5   140→1.75  500→2.0   600→2.0
```

#### 4.8.4 ⚠ 本作特有的风险与护栏（**阶段 0 必须实测**）

1. **「步枪 0–70 px 只有 0.3 倍」与本作的室内战直接冲突** —— 本作在**100 层楼内**作战，玩家视野仅 ≈128–160 px（8–10 tile），**绝大多数交火发生在 40–160 px**。ZS 的步枪曲线意味着**本作最常见的交战距离上，步枪只能打出 30% 伤害**（90 px 才回到满倍率）。
   - **护栏**：阶段 0 **必须实测**；若"步枪在楼内手感软、打不动"→ **回退方案 = 抬高低谷**（步枪 0–70 从 `0.3` 提到 **`0.6–0.7`**，**保留曲线形状**）。
2. **狙击「90 px 内伤害为 0」在本作等于武器废掉** —— 楼层内交战几乎必定 <90 px。
   - **护栏**：**建议直接改**——狙击近距倍率从 `0` 提到 `0.25–0.4`（"近距离打不出优势"而非"完全打不了"）。ZS 的 0 是为了让玩家在**开阔地图**换副武器；本作**没有开阔地图**，照抄会让整族武器在楼内失效。
3. **霰弹「0–64 px = 2.0 倍」非常适合本作**（楼内近战主导），**可直接照用**。
4. **DMR / 狙击的"太近打不到"需要 UI 配合**：射程外应给可读反馈（准星变灰 / 提示"距离过近"），**否则玩家只会觉得"这枪有 bug"**（→ ux-spec 待补一条）。

> **设计价值（为什么值得引入）**：① **同一把枪在不同距离是两把枪** → 逼出"贴脸霰弹 / 中距步枪 / 远距 DMR"的**位置意识**；② **让"楼内环境"本身成为平衡杠杆**（本作没有开阔地，曲线必须重标定——这反而成了本作的差异化点）；③ 与 §4.5 弹种系统叠加：`12×70 SLUG` 独头弹**把霰弹的射程曲线换成步枪曲线**，让霰弹枪能打远——ZS 的聪明设计，本作可借鉴。

### 4.9 移动 · 冲刺 · 负重（R-46 新增）

> **来源**：用户拍板（逐字原话）「屏幕左上角显示玩家状态栏……**第二条显示体力，闪避冲刺时耗费**……**第三条显示负重，当前负重为浅灰色（靠左），剩余负重为深灰色（靠右）**」。**本节补齐本作此前未定义的「冲刺（Sprint）」动作，并定义「超重」对移动维度的结算。** **官方权威**：负重系统定义见 `base-survival-npc §A.3.1`；物品 `weight` 见 `weapons-loot §3.15`。

**一、冲刺（Sprint · R-46 补齐）**
```
SprintSpeed        = MoveSpeed × 1.5 = 135 px/s ⚠待调   // MoveSpeed = 90 px/s（本文件全局常量）
SprintStaminaCost  = 10 / s ⚠待调                        // 持续消耗（按住冲刺键期间）
Sprint 可用条件     ：Stamina > 0 且 非重度超重 且 非 Roll / Stagger / 转场态
Stamina 耗尽        ：自动退出 Sprint（回 Move），不报错、不吞输入
```
- **冲刺耗体力（用户明确要求）**：按住冲刺键加速移动，**持续消耗 `Stamina`**；**松开 / 体力耗尽即回落到走速**。
- **冲刺期间**：**可开火**（腰射，精度受 §4.2 影响）、**不可 ADS**（举镜与冲刺互斥，与 ZS 一致）；**不可翻滚**（沿用 §5.1 互斥）。
- **与饥饿 / 口渴联动**：冲刺属"运动"→ 触发 `base-survival-npc §A.4`「行动附加 Sprint ×1.5」（饥渴衰减加速）；**与体力消耗是两条独立轴、不互相替代**。
- **⚠ 现无"冲刺键"绑定**：具体按键由 `ux-spec` 定义（建议 Shift）；**本文件只定义行为与数值**。

**二、负重对移动维度的影响（R-46）**
```
LoadRatio = CurrentLoad / CarryCapacity                    // 见 base-survival-npc §A.3.1
正常     (r ≤ 1.0)        : MoveSpeed ×1.00
轻度超重 (1.0 < r ≤ 1.2)  : MoveSpeed ×0.85   (−15%)
重度超重 (r > 1.2)        : MoveSpeed ×0.70   (−30%)
                            + Sprint 禁用（不可进入 [Sprint]）
                            + Stamina 自然恢复速率 ×0.5
两档不叠加；仅楼层内生效；基地内（第 100 层）豁免
```
- **只影响移动维度**（移速 / 冲刺 / 体力）；**不影响**开火 / 换弹 / ADS / 命中 / 弹道 / 伤害 / 硬直阈值。
- **生效开关 = "离开基地（进入楼层）"**：**基地内不施加任何超重惩罚**（见 base §A.3.1 四）。
- **与既有 debuff 叠加**：断粮 `<30` 的 **移速 −10%**（base §A.3）与本超重移速惩罚**独立相乘**——`MoveSpeed_eff = 90 × 断粮系数 × 负重系数`；体力自然恢复同时受"重度超重 ×0.5"与既有 `20/s` 基准约束。
- **⚠ 与 §4.2 ⑧ 的关系（消除双乘）**：§4.2 ⑧ 要求"不同武器靠**重量 → 移速 / 体力惩罚**做出手感差异"——**其实现方式 = 本节**（重武器如 SCAR-H 4.3 推高 `CurrentLoad` → 更易触发超重）。**不得**再对"单把枪"叠加一个**独立的移速乘区**（否则同一把枪的"重量"被算两次，且"同时背两把重枪"无从解释）。**"重量手感差异" = 负重系统的涌现结果，不是逐枪硬编码惩罚。**

## 5. 状态机（State Machine）

### 5.1 玩家战斗 FSM
```
[Idle/Move] ──(开火, 弹匣有弹且未卡壳)──> [Shoot] ──> [Idle/Move]
[Idle/Move] ──(按住 RMB)──> [ADS](准星收拢; 移速↓) ──(松开)──> [Idle/Move]
[Idle/Move] ──(按住冲刺键, Stamina>0 且 非重度超重)──> [Sprint](移速×1.5; −10 Stamina/s) ──(松开 / 体力耗尽 / 按 RMB)──> [Idle/Move]  // R-46 新增
[Idle/Move] ──(R 换弹)──> [Reload] ──> [Idle/Move]
[Shoot] ──(触发卡壳)──> [Jammed](不可射击) ──(V 排障/换弹/强行开火)──> [Idle/Move]
[Idle/Move] ──(翻滚键+方向, Stamina≥25)──> [Roll](iFrame) ──(0.35s)──> [Idle/Move]  (Cooldown 0.8s)
[任意可行动态] ──(受击且 Damage>阈值)──> [Stagger](最长0.4s) ──> [Idle/Move]
[任意] ──(HP≤0)──> [Dead] ──> (progression 结算)
[Idle/Move] ──(1/2 切枪, 耗时 SwitchTime)──> [Idle/Move]   // 双武器槽
```
- 互斥：Roll/Stagger/**Jammed** 期间**不可进入 Shoot**；**Reload/ADS 期间不可开火**（可移动，ADS 下移速下降）；**ADS 与 `Sprint` 互斥**（不可同时进入）；**重度超重（`LoadRatio > 1.2`）时不可进入 `Sprint`**（§4.9）；**`Sprint` 期间可开火（腰射）但不可 ADS**；Shoot 可边移动边进行（但精度受 §4.2 静止收敛影响）。
- **R-12**：`[Melee]` 状态**已移除**（玩家近战移出）；新增 `[ADS]` 与 `[Jammed]`。

### 5.2 敌人战斗相关状态
见 `enemies-ai.md`（Detect/Chase/Attack/Ability/TakeCover/Reload/Stagger/Dead）。本系统只消费其"攻击事件"与"受击/硬直"接口。

## 6. 边界与异常（Edge Cases & Anomalies）
1. **空仓开火**：弹药 0 → 仅空仓反馈，不崩溃；自动不切换武器（避免误切）。
2. **翻滚中受击**：iFrame 内完全免疫；iFrame 外正常结算（含硬直）。
3. **同帧多 hit（如霰弹多 pellet / 多个敌人）**：逐发独立结算，HP 可一帧扣到负数 → Dead 只触发一次（防重复掉落）。
4. **护甲溢出（R-12 改写）**：`ArmorDurability` 扣到 0 后，`ClassEffective` 降为 Class 1（最低防护），剩余伤害按 Class 1 阈值判定后扣 HP（不返还耐久）。**ArmorDurability 不为负**。
5. **Boss 无敌帧/阶段切换**：阶段切换瞬间设短无敌，避免"换阶被秒"。
6. **卡墙/非法位移**：翻滚位移做碰撞裁剪，禁止穿墙；若终点非法则吸附到最近合法点。
7. **超量敌人（性能）**：实体数超 procedural-gen 上限时，远端敌人降级为"休眠 AI"（不更新感知），详见 enemies-ai 性能条款。
8. **暂停/存档**：暂停冻结所有战斗计时器；存档仅存玩家状态快照（run 内），见 progression。
9. **转场不可攻击态（R-11 新增，裁决 P2-6）**：**楼梯间过层**与**绳索垂降/攀爬转场**期间（`RopeDescendDuration / RopeAscendDuration`，vertical-traversal §3.5），玩家进入「转场态」——**不可被攻击、不可开火、不可翻滚**，世界侧对该玩家的伤害结算与仇恨获取**挂起**（语义等同一段极短过场，非无敌 buff，**不影响其他实体间的结算**）。转场结束恢复常规战斗判定。vertical-traversal §3.5 引用本条款。
10. **卡壳与排障（R-12 新增）**：卡壳时不可射击；排障（V 键 / 换弹 100% / 强行开火 30%）期间可移动、不可开火；排障未完成时**不可切枪规避**（避免"切枪即清卡壳"的漏洞，⚠待定：若切枪会重置卡壳计时则视为过度放宽）。
11. **弹种切换（R-12 新增）**：野外切换弹种需**占用一个空背包格**承接卸出的弹药（对齐 ZS：背包满时不可换弹种）；无对应弹种则切换失败并提示。
12. **耐久归零**：`Durability = 0` 时伤害 −25%、精度 −15%、卡壳率高，但**武器不销毁**（仍可用，逼玩家回基地修）；是否允许"耐久 0 即报废"为 ⚠待拍板项。
13. **回血渠道与「状态轴」（R-14 立 · R-19 改三轴）**：玩家 HP **只有两条上升路径**——
    - ① **使用药品消耗品**（**三轴 4 品种**：绷带 / 急救包 / 医疗包 / 抗尸毒剂，weapons-loot §3.10）：`HP = min(MaxHP, HP + hp × (1 + ResearchBonus))`；**有用药耗时**，期间**不可开火**、移速 ×`speed_multiplier`；**被打断 → 消耗不返还且不回血**；**HP 已满时**对 `hp > 0` 的品种**拒绝使用**（不浪费药品）——**抗毒血清（恢复最大 HP 类）不受「当前 HP 已满」限制、受「MaxHP 上限已满」限制**（恢复上限与当前 HP 是否满无关；⚠ R-36：原抗尸毒剂「hp=0 解毒」职能已改为「恢复最大 HP 上限、不解毒」；⚠ R-34：普通绷带现 `hp`=+20，归 `hp > 0` 档，HP 满时拒绝使用）。**⚠ R-29：`ResearchBonus = Aff`（R9 研究室建成后生效，未建成 = 0）——即 `药品回复量 = 基础 × (1 + Aff)`**（base-survival-npc §B.4 ③⑤）。**⚠ R-30：此处的 `MaxHP` 含 R8 训练场乘区**（`MaxHP = BaseMaxHP × (1 + TrainerMod)`，见 §4.1）——即**血池（R8）与药量（R9）成对放大**；**但 R8 不改"回血渠道"本身**（回血仍只有本条与双人床两条，§AC14 守住）。
    - ② **基地双人床 · 休息回血**（`bed_rest`，base-survival-npc §B.3.1 / **R-42 双人床功能表**）：**仅基地内、仅双人床**；**回血速率 = `BaseRestRate` = `1 HP / 游戏分钟`（✅ R-43 定值〔= `4 HP / 现实秒`〕→ 满血 100 ≈ 25 现实秒）、恒定、不受 NPC 好感度 / `TrainerMod` 影响**（**⚠ R-42 已改：原「随时间缓慢回复」无速率口径**——R-42 将 R1 房间效率由"缩短休息回血耗时"改为"饥渴消耗折扣"，**回血速率不再随好感变化**，以守 §B.6#10 兜底）。**⚠ R-42：基地内时间静止 → 双人床「休息」= 推进时间 + 按时间比例回 HP + 消耗饥渴**（三者同一动作；**不在基地"干站着"回血**）。
    - **断言：不存在第三条**——医疗室（制药工坊，R4）、厨房（R3）、温室（R7）、研究室（R9）、通讯室（R6，=空投站功能）、NPC、建筑升级**均不改变 HP**（组合断言见 §8 AC14）；**医疗室不治疗**是硬纪律。
    - **R-19 新增：药品是「三轴」而非单轴**（对齐 ZS 拆分"回血 / 止血 / 抗辐射"的思路；**本作第三轴改为「尸毒感染度」**——原创命名，替代 ZS 的 radiation）：

      | 轴 | 含义 | 机制 |
      |---|---|---|
      | **`hp`** | 回血 | 直接抬 HP。**只有医疗包系（绷带 +20 / 急救包 +40 / 医疗包 +60）有这个值**（⚠ R-34：普通绷带现 `hp`=+20，不再为 0）；**抗毒血清不在此轴——它是「恢复 MaxHP 上限」类（见「尸毒感染（二值态 `RotInfected`）」行），不抬当前 HP、不解毒，`hp = 0`** |
      | **`bleed`（出血 / 止血）** | 流血状态 | 受击产生**出血等级** `BleedLevel`；只要 >0 就**按秒持续掉 HP**。药品的 `bleed` 值**降低出血等级**（不直接回血） |
      | **尸毒感染（二值态 `RotInfected`）** | 被变异体感染的永久污染态 | **僵尸 / 怪物（变异体）攻击且造成伤害时，20% 几率使 `RotInfected = true`**（幂等：已感染不再变化；雇佣兵不触发、机械免疫）。**感染为永久态**——**不可被睡觉（双人床）/ 血包（hp 药品）/ 任何药品解除**，**唯一解除条件 = 战胜最终 boss**（「英雄救美的代价」）。**不直接致死**，但感染期间**每日结算 `MaxHP 上限 −5`（持久累积）**（**⚠ R-42：每日结算 = 回到基地时按"本趟经历的游戏日数"结算**），使继续下潜的成本急剧上升。**⚠ R-36：上限下降走 art-bible §7.1 上限刻度通道（损害档 ◀ 三角 + 数字文本 `当前/上限`），不靠变红；抗毒血清可恢复 MaxHP 上限（见 base-survival-npc §B.4 每日结算 / §B.8 AC51 / weapons-loot §3.10）；**⚠ R-37：上限无下限钳制（允许归零）**——每日结算后若 `MaxHP ≤ 0` → **尸变判定**；判定为尸变 = **Game Over（≠ 战斗内死亡）**，见 §6.16 / AC20⑥** |

    - **出血机制（R-19 新增）**：`BleedLevel` 越高，每秒掉血越快（⚠待调，建议 `0.5 × BleedLevel` HP/s）；**出血不会自行停止**——必须用药。这让**绷带从"劣质回血品"变成"必需品"**：重伤后即使不回血，也得先止血。
    - **尸毒感染机制（R-19 立 · R-36 简化重构）**：**只有变异体（僵尸 / 怪物）攻击且造成伤害时才有 20% 几率造成感染（`RotInfected = true`），雇佣兵不造成、机械免疫**——把"高层的尸毒压力 / 低层的枪伤压力"做成**两种不同的伤情管理**（P3 深化：**上层带「绷带 + 抗毒血清」，下层带「医疗包 + 护甲」**，备战清单随楼层翻转）。**感染为永久态**：**双人床只回 `hp`**、**血包（hp 药品）只回血/止血**，均**不解感染**；**抗毒血清只恢复 MaxHP 上限、不解除感染**（见 §6.13 rot 行 / weapons-loot §3.10 / base-survival-npc §B.4 每日结算 / §B.8 AC51）。
    - **`wound`（伤口）系统：R-19 用户拍板「取消」** —— **不引入** ZS 的第四轴（`med_wound_*` 只治伤不回血、且用药期间定住）。理由：三轴已足以构成分层伤情管理，第四轴对单人开发是净成本。
    - **断粮 debuff 联动**：`Satiety/Hydration < 15` 时回血效率 −50%（药品与双人床同减，base §A.3）。**⚠ R-42 区分**：这是**断粮 debuff**（对所有回血来源生效），**与"R1 好感效率"是两回事**——**R-42 后好感度不再影响双人床回血速率**（R1 效率改为"饥渴消耗折扣"，见 §6.13 ②）。
14. **死亡与回血竞态（R-14 新增）**：用药期间 HP 被扣至 ≤0 → **死亡优先**，用药中断、消耗不返还（不得"临死一口药续命"，⚠待定是否给"致死伤害不可被用药抵消"的显式规则）。
15. **出血致死（R-19 新增）**：`BleedLevel > 0` 的持续扣血**可致死**，且**与"最后一击"同样触发死亡流程**（掉落 / 跑尸规则照旧）；**出血不因进入基地而停止**——必须用药（医疗室不治疗，§6.13）→ 因此"带着出血撤回基地"是**合法但危险**的状态。
16. **尸毒感染（二值态 · R-19 立 · R-21 定案 · **R-36 简化重构**）**：感染为 **`RotInfected`（二值）**，**封顶即"已感染"**（无 0–100 计量）；**不直接致死**（只是持续削减 MaxHP 上限）；**基地内不自动衰减**。✅ **R-21 用户拍板：双人床不能解尸毒（感染）**——~~⚠待定是否给双人床"缓慢降低"的兜底~~ **已作废**。**双人床只回 `hp`**；`bleed`（出血）与 `RotInfected`（感染）**只有战胜最终 boss 能解**（base-survival-npc §B.4 / §B.6 #10、weapons-loot §3.10 / §6.18）。**断言**：在双人床休息任意久，`RotInfected` **不变**、`BleedLevel` **不下降**。**⚠ R-36：感染另有"每日 MaxHP 上限削减"危害——`RotInfected = true` 时每日结算 `MaxHP 上限 −5`（持久 debuff，治愈后停降、已降部分默认不回复 ⚠待调；**⚠ R-42：每日结算 = 回到基地时按"本趟经历的游戏日数"结算**；详见 §6.13 rot 行 / base-survival-npc §B.4 每日结算 / §B.8 AC51）。** **⚠ R-37：上限无下限钳制——`MaxHP` 可归零；归零 → 尸变判定 → 尸变结局 Game Over**（**≠ 战斗内 `HP ≤ 0` 死亡**：死亡 = 本局结束、携带物入尸体跑尸可续、回基地继续；尸变 = **整个存档终止**、可读档回退 / 开新档）。**
17. **同帧出血 + 受击竞态（R-19 新增）**：同一帧内"受击伤害"与"出血跳伤"叠加使 HP ≤0 时，**Dead 只触发一次**（与 §6.3 同规则）；**出血跳伤不受翻滚 iFrame 保护**（出血是状态，不是投射物）。
18. **冲刺耗体力与耗尽（R-46 新增）**：冲刺**持续消耗 `Stamina`（10/s ⚠待调）**；**`Stamina` 耗尽 → 自动退出冲刺、回落走速**（不报错、不吞输入）；**冲刺中进入 `Roll`**（若体力足 25）**自动中断冲刺**；**冲刺中受击 → 进入 `Stagger`**（正常结算）；**`Stamina ≤ 0` 时无法进入 `Sprint`**。**⚠ 与"翻滚 −25"共用同一体力池**：冲刺与翻滚**互相挤占体力**（先冲刺腾挪、还是留体力翻滚保命，是一个即时决策）。
19. **超重时的边缘情况（R-46 新增）**：① **超重与断粮叠加**——`MoveSpeed_eff = 90 × 断粮系数 × 负重系数`（**独立相乘**；极端情况（重度超重 + 断粮 `<30`）移速降至 `90 × 0.9 × 0.7 = 56.7 px/s`，⚠待调）；② **超重不影响硬直**——`StaggerThreshold = 0.12 × MaxHP` **与负重无关**（只随 `MaxHP`）；③ **超重跨"基地 ↔ 楼层"切换**——**离开基地进入楼层时惩罚生效、回到基地（第 100 层）即豁免**（可测：同一 `LoadRatio` 两处移速不同）；④ **超重时翻尸体 / 拾取**——**允许拾取**（`CurrentLoad` 可超 `CarryCapacity`，吃惩罚），**不硬拒**（防"跑尸拿不动"卡死）；⑤ **`Sprint` 可用性翻转**——`LoadRatio` **由 ≤1.2 升到 >1.2 时，正在冲刺的玩家立即中断冲刺**（不再可进 `Sprint`）。

## 8. 验收标准（Acceptance Criteria）
- AC1：阶段 0 原型中，移动/瞄准/**ADS**/射击/**后坐力漂移**/翻滚/命中/硬直/**换弹**/**卡壳排障**均可独立演示；内部试玩手感通过率 ≥ 80%。
- AC2：翻滚 iFrame 实测落在 [0.05,0.30]s；冷却 0.8s；体力不足 25 不可翻滚。
- AC3（R-12 改写）：**后坐力表现为准星漂移**——连射时 `CrosshairOffset` 单调增大、停火后按 `CrosshairRecover` 衰减归零（可测曲线）；**移动会重置静止收敛**（§4.2）。
- AC4：硬直阈值与时长按 §4.3 公式生效；玩家硬直不可翻滚取消。
- AC5（R-12 改写）：**护甲穿透判定正确**——`Pen ≥ ClassThreshold` 时减免 0、否则按比例减免（上限 80%）；`ArmorDurability` 不为负，`ClassEffective` 随耐久下降；溢出伤害扣 HP。
- AC6：同帧多 hit 只触发一次死亡/掉落；无崩溃、无重复掉落。
- AC7：空仓、卡墙、暂停等边界（§6）均不崩溃、不卡死。
- AC8：所有战斗数值可由 weapons-loot 注入，无战斗系统内部硬编码死值（支撑 P2）。
- AC9（R-11）：**转场不可攻击态生效**——楼梯间过层 / 绳索垂降攀爬期间，玩家不可被攻击、不可开火、不可翻滚；转场结束恢复常规判定（§6.9）。
- AC10（R-12）：**无暴击**——伤害链中不存在 `CritMult / CritChance`；伤害差异仅来自口径/弹药类型/穿透/配件/距离/耐久（§4.1）。
- AC11（R-12）：**弹药类型生效**——同武器换弹种使伤害与穿透按 §4.5 表变化；HP 弹对无甲目标伤害更高、AP 弹对护甲目标伤害更高（可测断言）。
- AC12（R-12）：**耐久与卡壳生效**——耐久 <70% 起按公式产生卡壳；卡壳态不可射击、排障后可恢复；耐久影响伤害与精度（§4.6）。
- AC13（R-12）：**工效生效**——`Ergonomics` 影响 ADS 时间、准星回正速度、切枪时间（单调关系可测）。
- AC14（R-14 · **R-42 补**）：**回血渠道只有两条（断言）**——构造"无药品 + 停留在基地医疗室/厨房/温室/研究室/通讯室"的场景，HP **不上升**；仅当①使用药品 或 ②在双人床休息时才上升（§6.13）。**⚠ R-42 追加断言**：**双人床"休息回血"的速率 = `BaseRestRate` = `1 HP / 游戏分钟`（R-43 定值），恒定、不受 NPC 好感度 / `TrainerMod` 影响**——构造"同一弹药量、艾拉 Aff = 100% vs Aff ≤ 40%"两组场景，**回血速率完全相同**（因 R-42 把 R1 效率改为"饥渴消耗折扣"，**不再改回血耗时/速率**）；**且"休息"须推进时间**（基地时间静止，见 §6.13 ②）。
- AC15（R-14 · R-19 对齐）：**用药规则生效**——用药耗时内**不可开火**、移速 ×`speed_multiplier`（暂定 0.5；对齐 ZS 的 `speed_multiplier` 字段，`0` = 完全定住）；被打断则**消耗不返还 + 不回血**；**HP 已满时拒绝使用**且不消耗药品；用药中被击杀 → 死亡优先（§6.13 / §6.14）。
- AC16（R-15 立 · **R-19 修正 · R-29 扩充**）：**伤害链中不存在【稀有度】乘区**——断言：伤害结算 = `WeaponDamage(型号) × AmmoTypeMult × DamageMult(Durability) × 射程倍率 × 配件加减 × (1 + ResearchBonus)`，其中 **`ResearchBonus = Aff`（R9 加成，R-29 新增；未建成 = 0）**；**不存在任何 `RarityMult` 项**——**R9 项不是稀有度乘区**（它绑定好感度、随断供下降，来源与生命周期均不同于型号稀有度，见 §4.1 注）。**R-19 修正**：~~"`WeaponDamage` 随型号单调上移"~~ —— 按 ZS `value` 排序后**伤害不再单调**（U 档 AK-47 = 26 > R 档 AK-102 = 22），这是**有意的保真**（`value` 衡量综合价值，不等于单发伤害）；断言改为「`WeaponDamage` 为**逐型号定值**，且**与稀有度无函数关系**」（§4.7 表可测）。**R-30 断言**：`ResearchBonus = 0` **仅当 R9 未建成时**成立（伤害链退化为原式，可测）；**R9 已判定不构成 G3 红线违规**（乘装备面板，见 §4.1 注）；**R9 初始加成 = 林晞的 `AffinityInit`**（**林晞 20% → 0.20**；默认 60% → 0.60）——**不得写死"+60%"**。
- AC17（R-19 新增）：**射程曲线生效**——`EffRangeDmgMult(dist, class)` 与 `EffRangeRecoilMult(dist, class)` 按 §4.8 折线**线性插值**：断言 ① 霰弹 dist ≤ 64 px 伤害 ×2.0、dist ≥ 140 px 伤害 ×0；② 步枪 90 ≤ dist ≤ 180 px ×1.0、dist ≥ 210 px ×0；③ **超出末折点即 0**（打不中，但**不报错、不崩溃**）。⚠ **必须同时验证"楼内距离下的可玩性"**（§4.8.4 护栏）。
- AC18（R-19 新增）：**配件为纯加减**——断言：`WeaponDamage_m = WeaponDamage + Σ(附件.damage)`，**结算链中不存在任何 `Π(乘区)` 项**；卸下附件后属性**精确回退到原值**（加法可逆、无残留）。
- AC19（R-19 新增）：**维修包消耗生效**——修理**必须消耗维修包道具**（`×1 / 次`）、**耐久上限受 `condition_max` 限制**（**不可修满**）；**维修包不按口径限定，按武器大类（轻 / 制式 / 重）匹配**；**野外无修理入口**；未持有对应维修包时**拒绝修理并给出可读提示**。
- AC20（R-19 新增 · **R-35/R-36 扩**）：**药品三轴 + 状态轴生效**——断言：① **绷带 `hp = 0`**（使用后 HP **不上升**，仅 `BleedLevel` 下降）；② **出血**在 `BleedLevel > 0` 时**按秒扣 HP**、**不自行停止**，用药后才停；③ **尸毒感染为二值态**——**变异体（僵尸/怪物）攻击且造成伤害时 20% 几率使 `RotInfected = true`**（**雇佣兵攻击不触发、机械免疫**，可测断言）；**一旦感染不可被睡觉/血包/任何药品解除，仅战胜最终 boss 可解**（构造"已感染 + 用尽所有常规解除手段"场景，`RotInfected` 仍为 true，直至最终 boss 击败）；④ **不引入 `wound` 轴**——不存在任何 `med_wound_*` 类道具或伤口状态；⑤ **（R-36）感染每日 MaxHP 上限削减 + 抗毒血清恢复生效**——断言：`RotInfected = true` 时，**每日结算（每局回到第 100 层）`MaxHP 上限 −5`**（持久累积；构造"连续多日感染"场景，`MaxHP 上限逐日下降、且击败最终 boss 后不再续降）；上限下降**走 art-bible §7.1 上限刻度通道（损害档 ◀ 三角 + 数字文本 `当前/上限`）、**不靠变红**；**抗毒血清**使用后 `MaxHP 上限 +20`（R9 研究室 `ResearchBonus=Aff` 放大至 +40，见 weapons-loot §3.10），**但 `RotInfected` 仍为 true**（不解除感染，可测：用血清后上限回升、感染态不变、每日续降仍发生）；**⑥（R-37）上限归零 → 尸变判定（≠ 战斗内死亡）**——断言：`RotInfected` 每日 −5 使 `MaxHP` 归零（**无下限钳制**）时，**每日结算触发尸变判定**；**判定为尸变 = Game Over**（该存档终止、可读档 / 开新档），**区别于「`HP ≤ 0` 战斗内死亡」**（后者仅本局结束、可跑尸取回装备、回基地继续）；**第一次**判定若存在 `Aff=100` 的 NPC（**排除 NPC#1 艾拉**、多个取编号最小）则**赠予一支既有普通「抗毒血清」（`antiserum`；⚠ R-47：不新增独立物品）并当场使用、立即生效**（`MaxHP` 上限 +20；R9 建成 ≥ +40）→ 上限回升 → 继续游戏（`SerumRescueTriggered` 存档级仅一次）。见 §6.13 rot 行 / §6.16 / base-survival-npc §B.8 AC52–AC53 / progression §5 / §4.1.1。

- AC26（**R-46 新增**）：**「重量手感差异」= 负重系统的涌现结果（消除双乘）**——断言：① 不同型号的 `重量`（`weapons-loot §3.1.1 / §4.3`）**通过 `CurrentLoad` 影响移动维度**，**不对单把枪另设独立的移速乘区**（可测：把同一把枪放入背包 vs 装备，`CurrentLoad` 一致 → 移速惩罚一致；**不存在"按武器 ID 硬编码的移速惩罚"**）；② **同时背两把重枪**（如 SCAR-H 4.3 + AK-47 4.2）**推高 `CurrentLoad`**、**可触发超重**（可测）——若为逐枪独立乘区则无法表达该联动；③ **`weight` 不出现在本文件任何伤害 / 后坐 / 精度 / 工效 / `AdsTime` / `SwitchTime` 结算式内**（§4.9 二/三）。见 §4.2 ⑧ / §4.9 / `weapons-loot §3.15 / AC31`。
