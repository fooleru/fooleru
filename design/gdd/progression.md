## 1. 概述（Overview）

进度系统分两层：**单局 roguelite 进度**（本局楼层/资源/build，死亡即终）与**局外 meta 成长**（跨局货币与解锁，提供"下次更强"的胜任感，呼应 SDT Competence）。设计红线：**meta 解锁提供"选项与便利"，不 trivialize 前期挑战**（否则破坏心流与 P3 翻转）。**⚠ R-30 明确**：该红线**不禁止**"**有条件的、双向的、绑定会衰减好感度的**"加成——本作**唯一登记的红线例外 = R8 训练场**（直接改玩家 `MaxHP` / `StaminaMax`，见 §4.3）；R9 研究室加成**经重新定性后判定为「不违规」**（见 §4.3）。

> **⚠ R-32 墓碑（概述层）**：本段"**局外 meta 成长（跨局货币与解锁）**"与"**meta 解锁提供…**"红线表述中的 **meta 经济部分已随 R-32 删除**——**`Credits` 货币与整个 meta 解锁树整体删除**（见 §3.2 / §4.1 / §4.2）；本作**只有一种货币（`现金 Cash`，仅交易时使用）**，**物资 / 武器 / 武器附件全靠楼层搜刮获得**。跨局成长只余**基地扩张（救援驱动 · 不消耗任何货币）**。上句红线语义收敛为"**装备 / 搜刮不得 trivialize 前期挑战**"。（**✅ 已拍板（R-47 · 2026-09-26 用户确认：当场使用并立即生效）**）

## 2. 目标（Goal）

- G1：单局有清晰目标（下到第 1 层）与即时 build 成长（P2）。
- G2：meta 提供长期动机——"再来一局"有明确回报，且进度可见。
- G3：平衡——meta 不把前期（高层僵尸层）打成无脑；解锁多为"拓宽可能性"而非"数值碾压"。
- G4：存档安全——死亡不丢 meta；无损坏/回滚灾难。

> **⚠ R-32 墓碑（目标层）**：G2 / G3 / G4 中"**meta**"字样系 R-32 前旧口径（指向**已删除的 meta 解锁树与 `Credits` 货币**）——**R-32 后本作无 meta 经济**：**G2** 的"跨局长期动机"现由**基地扩张（救援驱动 · 不耗货币）**承载；**G3** 的平衡红线现主要约束**基地房间效率乘区（R8 / R9）**（见 §4.3）；**G4** 的"死亡不丢 meta"语义收敛为"**死亡不丢基地 / 存档级进度**"。（**✅ 已拍板（R-47 · 2026-09-26 用户确认：当场使用并立即生效）**）

## 3. 核心机制（Core Mechanics）

### 3.1 单局进度（Run）

- 追踪：当前楼层、资源（弹药/医疗）、build（武器/附件/消耗品）、击杀数、用时。
- **世界重置（R-20 改）**：楼层布局**按存档永久固化**（P0-01）；**但敌人与物品按"探索"重置**——一次探索（离开基地 → 返回基地）内**敌人不回位、物品不回位**；**回基地再出发时，敌人（含精英/Boss）与地面物品、容器全部恢复**。**属持久层、永不重置的**：迷雾、已安装绳索、尸体、门锁、救援/剧情/Boss 击败里程碑（三层模型见 procedural-gen §3.1）。可重玩性仍来自开新存档（新 GlobalSeed）。
- 死亡/通关 → 进入结算（**R-07 重写 · R-20 改惩罚口径**）：死亡时**携带物（背包 + 装备栏武器/护甲）全部留在死亡点的「尸体」中**（不消失），玩家**空手在基地复活**，需**跑尸取回**（death-and-corpse）；**保留各楼层迷雾探索进度**（fog-of-war §3.3）；基地储藏室物品不受影响。**⚠ R-20：死亡惩罚从"仅消耗"升级为"消耗 + 再肃清"**——死亡结束一次探索，**下次出发敌人全部复活**，跑尸必须**重新打通或绕过**到尸体层的路（**绳索 + 迷雾记忆**是反制手段）。**~~Credits 结算保留里程碑制（R-11，见 §4.1）~~ —— ❌ R-32 已删除**：原口径「仅当本局抵达深度**超过存档历史最深** `MaxFloorReached` 时按**增量**结算，重复到达同一深度不再产出」随 `Credits` 删除而作废——**`RunEnd` 结算不再产出任何货币**（见 §4.1）；`MaxFloorReached` 仅保留为**统计 / 成就用途**（见 §4.1.1）。

> **⚠ R-32 墓碑（✅ 已拍板（R-47 · 2026-09-26 用户确认：当场使用并立即生效））**：**`Credits`（信用点）已整条删除** —— 本节的**里程碑增量结算**（`ΔCredits_floor` / `ΔCredits_kill` / `ΔCredits_loot`）**与全部公式整体作废**：**`RunEnd` 结算不再产出任何货币**；`MaxFloorReached` 字段**改为统计 / 成就用途保留**（见 §4.1.1）。**理由**：用户拍板「Credits 被现金取代，仅在交易时使用」+「meta 解锁树玩法删除」。**⚠ 本作不得新增任何货币结算**（可测断言：结算前后玩家货币余额仅由携带物决定、不新增，见 §8 AC34）。

> **以下 §4.1 正文（背景段 / 伪代码块 / C1–C3 参数 / 硬约束段）为 R-32 前历史原文，仅作留痕，全部废止、不具规范效力。**

**背景（为什么改 · 已废止）**：若沿用绝对量公式 `Credits = FloorReached × C1 + …`，玩家可**反复下探同一深度并故意死亡/放弃**，每次都拿全额 Credits → 形成**主导刷取策略**，触碰红线「经济失衡 / 主导策略」。
> **R-20 论证更新**：原论证的两个前提（"世界不回位" + "惩罚仅消耗"）**已被 R-20 改变**——现在世界会按探索重置、送死还要重新肃清，**刷取的边际成本上升**。但**里程碑/增量制仍然保留**，因为它防的是**另一个独立问题**："**同一次/同深度重复到达时不应重复发放楼层 Credits**"。该问题与惩罚轻重无关，故制度不变，仅论证前提更新。

```
// 存档级字段（属 ② 存档级持久层，见 §7 architecture / vertical-traversal §3.7）
MaxFloorReached : int        // 本存档历史抵达的最深楼层（越小越深，初始 = 100）

// RunEnd 结算（死亡 或 主动放弃 均触发）
if FloorReached < MaxFloorReached:                       // 打破了历史最深纪录
    ΔCredits = (MaxFloorReached - FloorReached) × C1     // 仅按【增量】发放
    MaxFloorReached = FloorReached                       // 刷新里程碑
否则:
    ΔCredits_floor = 0                                    // 重复到达同一深度 / 更浅 → 【不产出 Credits】

// 击杀与战利品的部分仍按本局实得（不设里程碑，因其本身为消耗性收获）
ΔCredits_kill = Kills × C2
ΔCredits_loot = LootValue × C3
ΔCredits_total = ΔCredits_floor + ΔCredits_kill + ΔCredits_loot
// C1≈10, C2≈2, C3≈0.5 （⚠待调）
// 仅"已抵达楼层"计，鼓励下行深度而非苟活
// 击败终局 Boss（通关）额外奖励 ×1.5（对 ΔCredits_total）
```
> **~~硬约束~~（❌ R-32 已废止）**：`ΔCredits_floor` 恒 ≥ 0，且**同深度重复结算恒 = 0**——这是防"反复送死刷分"的主导策略护栏。**R-20 后此护栏的边际重要性下降**（重置使刷取成本上升），但**仍保留**（防同深度重复结算这一独立问题）。
> **✅ R-32 注：以下护栏不依赖 `Credits`，R-32 后仍然有效**（唯 ② `ΔCredits_floor` 同深度恒 0 一项随货币删除作废）。**⚠ R-20 新增护栏需求（R-21 收口）**：由于敌人与物品**会随探索恢复**，需确认**"重复搜集同一批物资"与"重复击杀 Boss"不会形成主导策略**——护栏：① 物资恢复的是 **seed 初始的同一批**（确定性，不增不减）；② ~~`ΔCredits_floor` 同深度恒 0~~（❌ R-32：随 `Credits` 删除作废，C 项由「现金 / 物资同 seed 不增不减」承担）；③ ✅ **Boss 重复掉落已定（R-21 用户拍板）**：**D2 式**——**概率与物品等级档固定、具体掉落物随机**（R-20 的"首次保底"建议**已作废**），故重复收益**稳定但不递增**、装备成长靠**深度**而非**重刷次数**；④ ✅ **不做浅层豁免**（全局重置，与暗黑破坏神2 一致，R-21）。详见 §6 边界 #14 / #15。
