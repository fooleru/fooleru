# ZS 武器真值基准（源 `weapon.json`）

> 文档：参考基准 ｜ 版本：v0.1（**R-17 新建**）｜ 作者：文策渊（design-strategist）
> **数据源**：`D:\games\Zero.Sievert\ZS_vanilla\gamedata\weapon.json`（ZS base gamedata，文件时间 2024-08-29）
> **交叉验证**：`caliber.json`（口径）· `mod_types.json`（改装类型）· `mod_positions.json`（改装位）· `stat.json`（六类熟练度）
> **用途**：① 为 `weapons-loot.md` 的型号阶梯提供**真值基准**；② 校准 `combat.md` 的伤害/后坐/精度轴；③ 作为本作「照搬 ZS」口径的**唯一事实来源**。
> **纪律**：本文件只记录 ZS 的真实数据，不改写、不美化；一切推断均显式标注。本作的取舍另见 `reference-alignment-zero-sievert.md`。

## 1. 数据源事实

| 项 | 真值 | 出处 |
|---|---|---|
| 武器条目 | **51 条 = 49 把可用 + 2 条占位**（`no_item` / `no_weapon`） | `weapon.json` |
| 武器类别 | **6 类**：`pistol` / `smg` / `shotgun` / `rifle` / `dmr` / `sniper` | `stat.json` 六类独立熟练度 |
| 口径 | **13 种有效**（`caliber.json` 另含 `not_ammo` 占位） | `caliber.json` |
| 改装位 | **11 个**：`stock` `grip` `barrel` `handguard` `magazine` `brake` `scope` `att_1`–`att_4` | `mod_positions.json` |
| 改装类型 | **12 种**（多出 `laser` `foregrip` `silencer` `torch`，本版武器未用到） | `mod_types.json` |

> **⚠ 三个直接冲击本作现有设计的事实**：
> 1. **ZS 有独立的 `dmr` 类（7 把）** —— 本作 GDD 只列 5 类（手枪/冲锋枪/霰弹/步枪/狙击），**缺 DMR**。
> 2. **ZS 没有「稀有度」字段**，物品只有 `value` —— **用户 R-15 的直觉与 ZS 数据结构一致**：分档依据就是 `value` + 威力。
> 3. **ZS 用「化名」而非真枪名**（`EC 101` / `N4o1` / `Skop H`）—— 见 §6。

## 2. 字段语义（含可信度标注）

| 字段 | 实测取值域 | 方向 | 可信度 | 说明 |
|---|---|---|---|---|
| `damage` | 11 – 65 | 越大越强 | ✅ 高 | 步枪仅 14–30；狙击 52–65；霰弹 48–55 |
| `rate_of_fire` | 3 – 75 | **数值越小越快** | ⚠ 中 | SMG 3–5 最小、步枪 4–6、霰弹 10–25、狙击 60–75 最大 → 是**射击间隔**，非每秒发数 |
| `recoil` | 45 – 190 | 越大越差 | ✅ 高 | SMG 最小（45–85）、狙击/霰弹最大（140–190）；`akm` 140 为步枪之最 |
| `precisione` | 20 – 99 | 越大越好 | ✅ 高 | **0–100 绝对值**，非倍率；霰弹 20–40 最低、狙击 94–99 最高 |
| `ergo` | 12 – 85 | 越大越好 | ✅ 高 | 手枪 62–85 最高、狙击 12–40 最低 |
| `magazine` | 2 – 64 | 越大越好 | ✅ 高 | 霰弹 2–18、狙击 5–10、AK 系 30、`pp19_bizon` 64 |
| `fire_mode` | 3 值枚举 | — | ✅ 高 | `automatic` / `semi_automatic` / `bolt_action` |
| `caliber` | 13 种 | — | ✅ 高 | 见 §4 |
| `value` | 2 500 – 65 000 | — | ✅ 高 | **唯一分档依据**（无 rarity 字段） |
| `weight` | 0.5 – 5.5 | — | ✅ 高 | 负重系统用 |
| `mods{}.needed` | true / false | — | ✅ **高・关键** | `true` = **构成部件**（不可缺）；`false` = **可选附件位** |

> **⚠ 与本作现有写法冲突的三处**：
> - 本作写「射速 rps 8.5 / 10.0 / 10.5，**越大越快**」→ ZS 的 `rate_of_fire` **方向相反**（越小越快），且非 rps。
> - 本作写「精度 0.80 / 1.15（**相对系数**）」→ ZS 是 **0–100 绝对值**。
> - 本作写「附件槽**上限 4**」→ ZS 实测**最多 6**（`r700_modern`）。

| 14 | 未写 `fire_mode` | ZS 三值枚举 AUTO / SEMI / BOLT | ⚠ 需补字段 |

> **阶梯对应（R-15 立 · R-19 改序）**：R-15 旧序 `AK-47 → AK-74U → AK-102 → M4A1 → SCAR-H`；**R-19 改按 ZS `value` 升序** → `AK-74U → AK-47 → AK-102 → M4A1 → SCAR-H`（**AK-74U 最廉价**，与 ZS `equipment_1` 起始武器 `ak_74u_1` 一致）。
> → ZS 可对应为 `EC 74U → AKM → EC 101 → N4o1 → Skop H`（**5 档几乎一一对应**，仅 AK-47 / AK-102 需换名）；**⚠ R-19 后 `damage` 不再随档位单调**（`AKM` 伤害 > `EC 101`），属**有意保真**——`value` 与 `damage` 两轴不同步，见 weapons-loot §3.1.1 / §4.3。

## 8. 建议采纳方案（待用户拍板）

| 方案 | 做法 | 优点 | 风险 |
|---|---|---|---|
| **A（推荐）** | **字段轴 + 数值量级照搬 ZS 真值**；型号名**自创化名**（自造化名体系，不抄 ZS、不用真名）；补 DMR 类 | 数值有据可依、发布无商标风险、与 R-12「照搬 ZS」一致 | 需要一轮命名工作 |
