## 1. 六类武器的「基准参数 + 射程曲线」（本作完全缺失，重要度最高）

`weapon.json` 中大量字段写作 `"{use_weapon_type}"`，其真值就来自本表——**按武器类别取默认值，单枪可覆盖**。

| 类别 | mouse_dis 范围 | ADS 射程倍率 | 准星回正 `recover_from_mouse_movement` | `player_ignore_dis` / max | damage_glance_flat | NPC 后坐系数 |
|---|---|---|---|---|---|---|
| **手枪 Pistol** | 10–50 | 1.05 | **1.4** | 24 / 2 | 0.5 | 0.02 |
| **冲锋枪 SMG** | 10–40 | 1.05 | **1.2** | 24 / 2 | 0.5 | 0.02 |
| **霰弹 Shotgun** | 15–50 | 1.05 | **1.2** | 24 / 2 | 0.5 | 0.02 |
| **步枪 Rifle** | 10–30 | 1.05 | **1** | 0 / 1 | 0.5 | 0.02 |
| **DMR** | 5–15 | 1 | **0.8** | 0 / 1 | 0.5 | 0.02 |
| **狙击 Sniper** | 5–15 | 1.05 | **0.65** | 0 / 1 | 0.5 | 0.02 |

**射程 → 伤害倍率曲线 `eff_range`**（`[距离, 倍率]` 折线，距离单位与游戏内一致）：

- **手枪 Pistol**：`0(1) → 150(1) → 170(0.4) → 180(0)`
- **冲锋枪 SMG**：`0(1) → 90(1) → 130(0.7) → 150(0.4) → 160(0)`
- **霰弹 Shotgun**：`0(2) → 64(1) → 96(1) → 130(0.5) → 140(0)`
- **步枪 Rifle**：`0(0.3) → 70(0.3) → 90(1) → 180(1) → 200(0.4) → 210(0)`
- **DMR**：`0(0) → 60(0) → 70(0.4) → 90(1) → 250(1) → 270(0.4) → 280(0)`
- **狙击 Sniper**：`0(0) → 90(0) → 120(0.7) → 140(1) → 500(1) → 600(0)`

**射程 → 后坐倍率曲线 `eff_range_recoil`**：

- **手枪 Pistol**：`0(1) → 90(1) → 110(0.75) → 160(0.85) → 180(1)`
- **冲锋枪 SMG**：`0(1) → 90(0.5) → 110(0.5) → 130(0.5) → 150(0.75) → 160(0.9) → 170(1)`
- **霰弹 Shotgun**：`0(4) → 64(1.5) → 96(1.35) → 130(1.5) → 140(1.5)`
- **步枪 Rifle**：`0(1) → 70(1) → 80(0.8) → 90(0.65) → 180(0.65) → 200(0.8) → 210(1)`
- **DMR**：`0(1) → 60(1) → 70(1) → 90(1) → 250(1.2) → 270(1.25) → 280(1.3)`
- **狙击 Sniper**：`0(1) → 90(1) → 120(1.5) → 140(1.75) → 500(2) → 600(2)`

> **⚠ 关键洞察（本作目前完全没有这套机制）**：
> 1. **每类武器都有一张「距离 → 伤害倍率」折线表** —— 伤害不是常数，而是随距离变化。
>    - **霰弹**：0–64 距离内 **2.0 倍**（贴脸爆发），130 降到 0.5，**140 归零**；
>    - **步枪**：0–70 距离只有 **0.3 倍**（近距离打不出伤害！），**90–180 才是 1.0 满倍率**，210 归零；
>    - **狙击**：**90 距离内伤害为 0**（太近打不到），120–500 满倍率，600 归零；
>    - **DMR**：60 内为 0，90–250 满倍率，280 归零。
> 2. **还有一张「距离 → 后坐倍率」曲线** —— 步枪在中距离后坐最小（0.65），狙击越远后坐越大（1→2）。
> 3. **`recover_from_mouse_movement` 才是「准星回正」的类级基准**（手枪 1.4 最快 → 狙击 0.65 最慢）。本作把它误记为单枪 `Ergonomics` 的绝对值。
> 4. **`npc_recoil_value_multiplier = 0.02`** —— **NPC 的后坐力只有玩家的 2%**（敌人几乎无后坐）。本作 enemies-ai 未涉及此点。

## 4. 武器改装件（`w_mod.json`，214 条）
