## 0. CP1 定性（一句话）

**喂给玩家「搜 → 打 → 撤」的单局 3–5 分钟最小手感骨架，验证移动 / 射击 / 超重 / 死亡的重玩动机，零叙事、零生成、零存档、零 NPC。**

**不做的事**：基地、NPC、好感度、尸毒、房间建造、商店、地图界面、过场演出、终局——一律推迟。手感骨架跑通后再逐系统接入。

## 1. CP1 验证目标（可观测、可手测）

| # | 验证项 | 通过门槛 | 依据 |
|---|--------|----------|------|
| G1 | 移动手感 | 走 / 冲刺 / 翻滚三态切换顺滑，冲刺消耗可感、翻滚清晰可读、超重视觉反馈立刻可辨 | combat §4.9 / art-bible §7.1 |
| G2 | 射击手感 | 手枪单发能命中 + 杀死 1 只僵尸（HP 60–80）需 3–5 发、换弹有硬直、有命中反馈 | combat §4.1 / weapons-loot |
| G3 | 敌人压力 | 1 只僵尸从感知到达成攻击 ≤ 4 秒；2–3 只同屏玩家须主动退；不形成无脑风筝 | enemies-ai §3.2 |
| G4 | 负重反馈 | 拾取物品 → 负重条 + load 数变化即时；超重（>1.2）移速可见下降 + 出现"无法冲刺"提示 | base-survival-npc §A.3.1 |
| G5 | 死亡循环 | HP=0 → 死亡结算（占位）→ 一键重开（< 2 s 进新局，零存档） | death-and-corpse（仅结算框架） |

任一不达标 → 调参再测，不扩范围。

## 2. 做清单（cp1 必交付）

### 2.1 玩家（Player · CharacterBody2D）
- **基础数值**（依据 `base-survival-npc §A.4` + `combat §4.9`）：
  - `BaseMaxHP = 100` · `BaseStamina = 100` · `StaminaRegen = 20/s`
  - `MoveSpeed`（走路基准 · ⚠待调，建议 80 px/s）
  - `SprintSpeed = MoveSpeed × 1.5`（R-46 用户确认）
  - `SprintStaminaCost = 10/s`（R-46 用户确认）
  - `DodgeStaminaCost = 25`（固定，AC22）
  - `CarryCapacity = 40 wg`（R-46 用户确认，⚠待调）
- **状态机**：`Idle → Walk → Sprint → Dodge` + 战斗中 `Aim → Fire → Reload`
- **超重结算**（cp1 只接两档，不接基地豁免）：
  - `LoadRatio = CurrentLoad / CarryCapacity`
  - `≤1.0` 正常 · `≤1.2` 轻度（×0.85 移速）· `>1.2` 重度（×0.70 移速 + 禁冲刺 + 体力恢复 ×0.5）
  - ⚠ 翻滚**保留**（防死亡锁，R-48 #11 收口）

### 2.2 武器（cp1 只 1 把）
- **C 档手枪**（weapons-loot §3.1 / 稀有度边框 = C 灰）
- 弹匣容量 ⚠待调（建议 12 发）
- 单发基础伤害 ⚠待调（建议 18，3–5 发杀僵尸）
- 换弹时间 ⚠待调（建议 1.8 s）
- 弹药类型：普通 9mm
- **不做**：稀有度轴多元 / 配件 / 耐久 / 射程曲线（占位简化为线性衰减即可）

### 2.3 敌人（cp1 只 1 种）
- **僵尸 Zombie**（enemies-ai §3.2 全套参数）：
  - HP `60–80` · 速度 `45 px/s` · 伤害 `15–18` · 同屏 `2–3` 只
  - 感知 视 `60 px` / 听 `180 px`（听觉主导、隔墙听到跑动/开枪）
  - FSM：`Idle → Detect → Chase（直冲无掩体）→ MeleeAttack` 循环
  - 前摇 `0.4 s` · 后摇 `0.3 s` · 攻击间隔 `1.0 s`
  - **20% 尸毒触发**：cp1 可先不接（只占位一个 `RotInfected = false` 字段、不结算 −5）—— 验证手感不需要终局倒计时
- **不做**：怪物 / 雇佣兵 / 机械 / Boss / 精英（R-23 四层保留设计，cp1 不动）

### 2.4 关卡（cp1 只 1 张手工房）
- **1 张测试房** · 320×180 内部分辨率、tile = 16 px → 整屏 20×11.25 tile
- 含：**起步区 / 中段走廊 / 1 件硬掩体 / 2–3 只僵尸生成 / 3–4 件可拾取物**（含 1 件足以触发重度超重的占位"重物"）
- **不做**：程序化生成（S1–S5 全部推迟）、电梯井、垂直骨架、迷雾
- **手工摆的就把"我下潜的每一段距离"和"开枪该不该"做出来即可**，验证手感不验证 P4 多样性

### 2.5 HUD（cp1 落 R-46 三段式）
- **左上玩家状态栏三行**（art-bible §7.1 / D-29 五项收口）：
  - 第一行 生命条：`[鲜绿 · 当前 HP · 靠左][血红 · 受伤损失 · 靠右][深渊黑 · 尸毒吃掉上限 · 最右]`
  - 第二行 体力条：常驻（含上限刻度占用同一条）
  - 第三行 负重条：`[浅灰 · CurrentLoad · 靠左][钢灰 · 剩余 · 靠右]`，满槽刻度 x=46（≈80%）+ 右侧 12 px 溢出区
- **超重视觉**：轻度档不上角标、靠形（移速变慢），重度档上 8×8 角标 + 形（cp1 可暂用引擎绘占位形，不出最终 PNG）
- **不做**：右上下楼层数 + 时间读数、地图界面、背包界面（物品只占位掉地上、走过去拾取即可）

### 2.6 输入（cp1 最小集）
- `WASD` 移动 / `Shift` 冲刺 / `Space` 翻滚 / `LMB` 射击 / `R` 换弹
- **不做**：`Tab` 背包、`M` 地图、交互键、改造 / 配件 UI

### 2.7 死亡循环
- `HP ≤ 0` → 简单死亡画面（占位文字 + 重开按钮）
- **不做**：跑尸、尸体容器、存档级字段、跑尸计时
- 重开 → 重置玩家状态 + 重新摆僵尸（同上一关）

## 4. 技术约束（cp1 硬门槛）

- Godot 4.7.2 stable · GDScript
- 内部分辨率 320×180（窗口可放大到 1280×720，禁用 smoothing 验证像素硬度）
- 4 层资源架构（art-bible §L0/L1/L2/L3）→ cp1 至少 L0 背景占位 + L1 玩家 + L1 僵尸 + L2 子弹 + L3 HUD
- 帧率目标 60 FPS，玩家 NaN 防护、僵尸同屏 ≤ 3
- 无外部资源依赖（cp1 全用占位色块 / 引擎绘图 / 字体走 Godot 默认）

## 5. 占位 / 临时简化清单

- **资产占位**：玩家 = 16×16 灰方块；僵尸 = 16×16 红方块；子弹 = 2×2 黄点；掩体 = 中灰矩形
- **音效占位**：开枪 = 短促方波；命中 = 短噪声；翻滚 = 低频 sweep（或先全无音）
- **僵尸模型简化**：仅 1 个 FSM 脚本，无动画状态、用色块缩放表示前摇
- **死亡结算**：纯文字占位
- **超重视觉**：重度档角标先用引擎绘的"!"字符占位，不出最终 PNG

## 6. CP1 完成条件（DoD · Definition of Done）

- [ ] 6 项验证目标（G1–G5 + 重开 ≤ 2 s）全部手测通过
- [ ] 1 张测试房可零崩溃连续重开 10 次
- [ ] 超重三档视觉反馈可辨（正常 / 轻度 / 重度）
- [ ] HUD 三段式生命条在满血 / 受伤 / 尸毒占位三种态正确显示
- [ ] 输入延迟 ≤ 1 帧（VSync 关闭测试）
- [ ] 设计文档依据可追溯（每个数值带文档锚点）
